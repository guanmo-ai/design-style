# 沙画 · 从候选图到全片

2026-11-12。主人看完第八轮三个手绘候选（马克笔 / 沙画 / 水彩）：“还不错，记得做的丝滑一点。动效尽量顶尖一点，至少要媲美毛绒还有孟菲斯，不过你不用被他们给束缚，也不用被这个项目给束缚……找到项目束缚你的地方，都可以提出来。”

三部里先做沙画：它是“画面不切换，只变形”的风格，一镜到底本身就是接力，最适合测“丝滑”；而且灯箱 + 暖光天然是电影感。

## 先想的三件事

1. **沙自己怎么动：沙守恒。** 擦掉的沙不会消失，被推到两边（沙脊）和指尖 / 掌缘前面（越推越大的一堆，手抬起时留在末端）。沙脊刚堆起来又窄又高，十几帧后塌宽——动作停了，沙还在动（对应毛绒的“身体停了毛没停”）。
2. **接力：同一盘沙。** 月亮 → 眼睛 → 眼泪 → 涟漪 → 一阵沙雨盖成卡片 → 按钮 / 进度环 / 滑杆 / 开关 → 两掌推平整盘 → 倒出片名。不切镜头，前面每一幕在最后都还留着淡淡的影子。
3. **设计师拿走：** 透光公式 T = e^(−k·h)、三档沙厚的实测颜色（#E7C698 / #633712 / #150903）、指痕截面（扫描线从这一帧的沙里实时取样）、“亮是擦出来的”用在界面状态上。

## 这次没照默认骨架做的地方（以及为什么）

- **没有“代表作”章、没有规则卡章、没有手机框。** 规则直接长在动作里：截面面板读的是正在画的那一圈涟漪；界面是在沙上擦出来的，不是放进手机框里的截图。
- **镜头不动。** 真的沙画是固定机位俯拍灯箱；画面的运动全部来自手。好处是没有缩放带来的颗粒闪烁。
- **没用 kit 的 HUD。** 它的标题字体（站酷庆科黄油体）和乱码解码是毛绒的气质；这里换成志莽行书标题 + “沙粒”解码（前沿是 ·:•，像沙落定），出字的声音登记仍走 `typefx.js`。

## 引擎（`film/sandfilm.js`）

- 沙 = 960×540 的厚度图；渲染时双线性放大到 1920×1080，乘上每个像素固定的颗粒噪声，查表算透光，再加一层泛光。
- 三种手法：`push`（手指 / 手掌推：中间推空 → 两边沙脊 + 前面一堆，**总量严格守恒**，测过：518400 → 518400.0000）、`pour`（倒沙）、`morph`（一抹 / 一阵沙雨）。
- 每一帧 = 帧号的纯函数：所有手法按开始时间排好，“动作结束 70 帧（沙脊塌完）以前的前缀”存快照，这一帧 = 快照 + 还在进行的手法。顺序渲染时几乎不重算。
- 速度：多数帧 0.2—1 秒；收束两掌（半径 300）推过时约 5 秒 / 帧。

## 过程里改过的

| 问题 | 原因 | 改法 |
|---|---|---|
| 手掌推过的地方干净得像橡皮擦 | 每一步都按“留 30%”拿，十几步叠下来几乎拿光 | 按覆盖次数开方：每步只拿一部分，总共留下 keep |
| 掌前的沙堆成一根黑柱 | 堆的形状太窄太高 | 月牙更宽、更弯，一部分沙从掌边溢到两侧 |
| “总沙量”从 100% 掉到 99.2% | `side` 参数把 15% 的沙直接丢了 | 推走的 = 两边 + 前面，一粒不少；`side` 只管沙脊软硬 |
| 界面画在涟漪上看不清 | 亮的东西擦在亮的地方 | 先下一阵沙雨把涟漪盖成一张暗卡片，再擦 |
| 片尾片名发灰 | 两掌把沙推到两侧又堆回画面；字是擦出来的，亮上加亮 | 两掌把沙全推出画面（整盘变亮），片名改成**倒**上去的暗字——最后一笔反过来 |
| 收束 7 秒 / 帧 | 沙脊的落沙范围算成了整张图 | 落沙范围 = 沙脊外沿 |

## 没做 / 没验证

- 看的是静帧和连续帧，没看过播放；配乐只核对了时长和响度（−14 LUFS），没听过。沙沙声的质感、钢琴和弦乐是不是“够电影”，要主人听。
- 播放键的三角形倒在旋开的亮盘里，被旋转的沙纹吃掉了一半，按钮读起来更像一个旋涡。
- 只有 16:9。抖音要竖版，见下一节。
