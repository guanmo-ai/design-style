# 沙画 · 从候选图到全片

2026-11-12。主人看完第八轮三个手绘候选（马克笔 / 沙画 / 水彩）：“还不错，记得做的丝滑一点。动效尽量顶尖一点，至少要媲美毛绒还有孟菲斯，不过你不用被他们给束缚，也不用被这个项目给束缚……找到项目束缚你的地方，都可以提出来。”

三部里先做沙画：它是“画面不切换，只变形”的风格，一镜到底本身就是接力，最适合测“丝滑”；而且灯箱 + 暖光天然是电影感。

## 先想的三件事

1. **沙自己怎么动：沙守恒。** 擦掉的沙不会消失，被推到两边（沙脊）和指尖 / 掌缘前面（越推越大的一堆，手抬起时留在末端）。沙脊刚堆起来又窄又高，十几帧后塌宽——动作停了，沙还在动（对应毛绒的“身体停了毛没停”）。
2. **接力：同一盘沙。** 月亮 → 眼睛 → 眼泪 → 涟漪 → 一阵沙雨盖成卡片 → 按钮 / 进度环 / 滑杆 / 开关 → 两掌推平整盘 → 倒出片名。不切镜头，前面每一幕在最后都还留着淡淡的影子。
3. **设计师拿走：** 透光公式 T = e^(−k·h)、三档沙厚的实测颜色（#E7C698 / #633712 / #150903）、指痕截面（扫描线从这一帧的沙里实时取样）、“亮是擦出来的”用在界面状态上。

## 这次没照默认骨架做的地方（以及为什么）

- **没有“代表作”章、没有规则卡章、没有手机框。** 规则直接长在动作里：截面面板读的是正在画的那一圈涟漪；界面是在沙上擦出来的，不是放进手机框里的截图。
- **镜头不动。** 真的沙画是固定机位俯拍灯箱；画面的运动全部来自手。好处是没有缩放带来的颗粒闪烁。
- **没用 kit 的 HUD。** 它的标题字体（站酷庆科黄油体）和乱码解码是毛绒的气质；这里换成志莽行书标题 + “沙粒”解码（前沿是 ·:•，像沙落定），出字的声音登记仍走 `typefx.js`。

## 引擎（`film/sandfilm.js`）

- 沙 = 960×540 的厚度图；渲染时双线性放大到 1920×1080，乘上每个像素固定的颗粒噪声，查表算透光，再加一层泛光。
- 三种手法：`push`（手指 / 手掌推：中间推空 → 两边沙脊 + 前面一堆，**总量严格守恒**，测过：518400 → 518400.0000）、`pour`（倒沙）、`morph`（一抹 / 一阵沙雨）。
- 每一帧 = 帧号的纯函数：所有手法按开始时间排好，“动作结束 70 帧（沙脊塌完）以前的前缀”存快照，这一帧 = 快照 + 还在进行的手法。顺序渲染时几乎不重算。
- 速度：多数帧 0.2—1 秒；收束两掌（半径 300）推过时约 5 秒 / 帧。

## 过程里改过的

| 问题 | 原因 | 改法 |
|---|---|---|
| 手掌推过的地方干净得像橡皮擦 | 每一步都按“留 30%”拿，十几步叠下来几乎拿光 | 按覆盖次数开方：每步只拿一部分，总共留下 keep |
| 掌前的沙堆成一根黑柱 | 堆的形状太窄太高 | 月牙更宽、更弯，一部分沙从掌边溢到两侧 |
| “总沙量”从 100% 掉到 99.2% | `side` 参数把 15% 的沙直接丢了 | 推走的 = 两边 + 前面，一粒不少；`side` 只管沙脊软硬 |
| 界面画在涟漪上看不清 | 亮的东西擦在亮的地方 | 先下一阵沙雨把涟漪盖成一张暗卡片，再擦 |
| 片尾片名发灰 | 两掌把沙推到两侧又堆回画面；字是擦出来的，亮上加亮 | 两掌把沙全推出画面（整盘变亮），片名改成**倒**上去的暗字——最后一笔反过来 |
| 收束 7 秒 / 帧 | 沙脊的落沙范围算成了整张图 | 落沙范围 = 沙脊外沿 |

## 节奏和丝滑（`smooth.py`）

| 版本 | 结果 | 改了什么 |
|---|---|---|
| 预览 1（30fps） | 跳变 16 处、死区 1 段（第 100—148 帧：浪头画完、手掌还没来） | 开场加一群鸟一只只倒上去（八分音符）、倒影上几下碎光，手掌提前到 100；章节字 / 参数 / 进度条改成 12 帧淡出（原来是一帧消失，整屏跳）；眼白一抹、沙雨卡片、收束两掌都放慢 |
| 预览 2 | 死区 0；剩下的“跳变”是眼白和沙雨的大面积连续变化（逐帧平均差 ≈1.3，看连续帧没有突跳） | 保留 |

## 没做 / 没验证

- 看的是静帧和连续帧，没看过播放；配乐只核对了时长和响度（−14 LUFS），没听过。沙沙声的质感、钢琴和弦乐是不是“够电影”，要主人听。
- 播放键的三角形倒在旋开的亮盘里，被旋转的沙纹吃掉了一半，按钮读起来更像一个旋涡。
- 只有 16:9。抖音要竖版，见下一节。

## 这一期发现的“项目束缚”（给主人决定）

1. **只出 16:9。** 目标里有抖音，但抖音是 9:16 竖屏；现在整套出片（1920×1080、HUD 位置、联系表）都默认横屏。建议每期出两版：X 横版 + 抖音竖版（重新构图，不是裁切）。
2. **画面上的字太多，适合 X 的设计师，不一定适合抖音。** 规则、参数、章节标题对设计师有用，但抖音的爆款沙画几乎没有字。建议出一个“纯享版”（只留片名和署名）给抖音，“标注版”给 X。
3. **15—20 秒的上限。** 沙画这种讲故事的风格，25—30 秒能多变形两次（这次砍掉了“眼睛 → 侧脸”）。建议按风格放宽到 30 秒。
4. **“每次出字都有声音”。** 抒情的片子里一串“嗒嗒嗒”会打断情绪；这次把出字声压低了。建议改成“出字有声音，但音色跟风格走”。
5. **kit 的 HUD 带着毛绒的气质**（标题字体、乱码解码），不改就每期长得一样；这次自己写了沙粒落定的出字。可以把 HUD 的字体和解码字符做成参数。


## v2：主人审片后重做（2026-11-12）

主人看完 v1：“非常差，整个背景居然都是不变的……动效没有达到顶尖，跟毛绒还有孟菲斯差的太远……BGM 非常差，甚至还有噪音的感觉。”

**为什么差（复盘）：**
- 灯、镜头、构图 19 秒不变，动的只是局部的手指笔画——“背景不变”。毛绒是 40 万根毛一直在飞，背景色、光、镜头每章一起换。
- 动作只有一种速度（手指慢慢划），没有大动作、没有节奏变化。
- 配乐：给每一个手法配了一段带通噪声（“沙沙声”），几十段叠在一起就是噪音；乐队只有钢琴和弦乐，没有鼓和旋律。

**v2 怎么改：**
- 引擎换成粒子：`grains.js`。两百万粒沙，每一幕是一张厚度图，沙粒在幕与幕之间飞（wind / vortex / burst / pour / storm 五种编舞）；配对按风向排序，多出来的从画外补；每粒沙的出发时间按它在风里的先后错开，所以换幕是一道沙浪。
- 每一幕可以分层，层有自己的动作：船漂、鸟飞、瞳孔转、鲸跃、水花散、进度流、开关拨、播放键按、句号落下。
- 灯箱颜色每章接力；镜头全程在动（对数推拉 + 旋转，Catmull-Rom 连续）。
- 渲染：全分辨率沙粒网格（一粒沙一个点）+ 一次 1-2-1 模糊；空中的沙分两层（低的清楚、高的失焦）。
- 配乐照毛绒：鼓、沙锤、贝斯、竖琴分解和弦、马林巴 + 钢片琴主旋律，每两拍换一个和弦；换幕是竖琴刮奏，沙落定是钢片琴，**没有任何噪声类音效**。

**过程里修的：** 配对时画外的备用沙混进排序，沙带会整条飞出去再飞回来（改成可见的沙和可见的沙配对）；瞳孔炸开 4 帧从黑到粉（出发先后改成按真实距离、镜头最大 6 倍）；字体没加载完就画了片名（改成字体到了再画每一幕）；内联注释吞掉了一行代码导致页面卡死。

**结果：** `smooth.py` 跳变 0 · 死区 0；平均每帧变化 4.0（v1 是 0.35），最大 32（瞳孔炸开那一下，毛绒是 19）。沙粒是压不掉的细节，CRF 18 有 118 MB，改用 CRF 27（40 MB，逐帧对比看不出差别）。

**仍然没验证：** 没看过播放、没听过配乐（只核对了时长和 −14 LUFS）。
