# 沙画 · 分镜（v2）

## 先想三件事

1. **沙自己怎么动：沙会飞。** 两百万粒沙，每一粒都是一个点。换幕不是淡入淡出，是整盘沙飞起来、落成下一幕——一道沙浪从画面一边扫到另一边（每粒沙的出发时间按它在风里的先后错开）。低的沙是清楚的小点，飞高的沙离镜头近、失焦成软的大斑。
2. **从头接力到尾：同一批沙 + 一盏换颜色的灯 + 一直在动的镜头。** 月亮 → 眼睛（月亮就是虹膜）→ 钻进瞳孔 → 炸开成红色的海和跃出的鲸 → 一条沙带讲两条规则 → 倒进一台手机 → 沙暴卷成片名。灯：琥珀 → 月光蓝 → 血红 → 白 → 青 → 金。
3. **设计师拿走：** 越厚越暗（T = e^(−k·h)、三档沙厚的颜色）；沙守恒（一指分开，两边堆高）；界面状态 = 沙的多少（进度是沙流过去、开关是圆钮拨过去、按钮的三角是空出来的）。
