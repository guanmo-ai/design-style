# 沙画 · 分镜

## 先想三件事

1. **沙自己怎么动：沙守恒。** 灯箱上的沙不会消失，只会被推走。手指划过：中间推空（亮）、推出去的沙堆在两边（沙脊）和指尖前面（一小堆，手指抬起时留在笔画末端）。手掌推过：前沿推起一道越滚越大的沙浪。倒沙：沙粒落下、溅开、连成一片暗。沙脊刚堆起来时又窄又高，十来帧后塌宽一点——这是“动的东西身上更慢的东西”。全片所有动作都是这三种手法 + 这一条守恒。
2. **从头接力到尾的东西：同一盘沙。** 不换场景、不切镜头。月亮变成眼睛，眼泪落进海里变成涟漪，涟漪变成按钮和进度环，最后一掌推平，写出片名。灯一直亮着，镜头只是很慢地呼吸。
3. **设计师拿走：** 透光公式 T = e^(−k·h) 和三档沙厚对应的颜色（实测取样的 hex）；指痕截面（亮芯 + 两道暗脊，扫描线实时取样）；“亮是擦出来的”用在界面：按钮、进度环、开关。

## 时间（60fps，120 BPM，一拍 30 帧）

| 帧 | 章 | 画面 |
|---|---|---|
| 0—210 | 00 沙画 | 第 0 帧就是封面（月夜海面，浪头正画到一半）。指尖卷完浪头 → 两道副线 → 手掌从左推过海面，一道沙浪滚过去 |
| 210—480 | 01 月亮 → 眼睛 | 月亮中心倒沙成瞳孔（沙粒溅开）→ 上下眼睑两指划出 → 眼白一抹变亮 → 虹膜放射线一根根倒上 → 高光一按 → 睫毛 → 一滴眼泪顺着脸流到海面 |
| 480—720 | 02 沙守恒 | 眼泪落点一圈圈涟漪（一指一圈）。扫描线横穿涟漪，左下实时画出截面 h(x) 和透光 T(x)；三档沙厚 → 三个颜色 |
| 720—930 | 03 界面 | 一掌清出一块：涟漪变成播放键，一指绕出进度环（0→72%），右边擦出一个开关、拖着圆钮滑过去 |
| 930—1140 | 收束 | 一掌从右到左推平整盘沙，沙浪滚过全屏 → 手指写出“沙画” → 最后一点（句号）落在拍上 + 署名 观默 |
