# 超级平面 · 方向（第二版，2026-11-18）

主人看第一版：“稍微好一点吧，不过也没有达到最顶尖的场景。”“我需要的是全球最顶尖的画质，能够在设计上达到全球最顶尖的，动效也要做到顶尖。”

## 第一版为什么不够

拿第一版和真实的顶尖作品并排看（参考见下），差在四件事：

1. **空间是假的。** 干净的 CG 白盒子、灰胶囊小人、代码现做的材质。顶尖作品的空间都是真的、旧的、粗的：剥落的墙皮、锈的铁柱、木屋架、积灰的水泥地。**完美的平面形状压在粗糙的真实空间上**，这个反差才是看点。
2. **东西太多。** 色带 + 字 + 黑点 + 柱子 + 窗影，一张图讲五件事。Rousse 和 Varini 每张只有**一个形状、一到两种颜色**。
3. **光是平的。** 没有真正的天光、反弹光和空气。参考里都是从高窗进来的自然光，光里有灰尘。
4. **构图是摆的。** 参考几乎都是一点透视、对称、纵深很长，形状正对镜头、占画面中心。

## 这一版只讲一件事

**一座巨大的旧厂房里，刷着一个完美的平面图形；只有站在一个点上才看得完整。**

- **环境去饱和**：灰混凝土、旧石膏、锈铁、旧木头；**漆只用一种饱和色**（信号红，或群青、明黄，按构图选），片子后段才让四色带同时出现。
- **光**：真实的天光从高窗打进来，空气里有薄雾和灰尘，光柱看得见；漆是哑光的，被光照到的地方和阴影里的地方明暗不同——证明它是刷上去的。
- **镜头**：一点透视、对称、纵深长；35 mm 左右；一个很小的人做比例尺。
- **材质**：ambientCG / Poly Haven 的 CC0 实拍贴图（`blender/fetch_assets.sh`）。
- **渲染**：Blender Cycles 路径追踪 + 降噪。图形用“投影机”贴上去：投影机就是那个对点的机位。

## 动起来（定图之后再做）

镜头在厂房里滑行，碎在柱子、屋架、地面上的色块看起来毫无关系；在拍点上镜头走到那个点——**碎块“咔”地拼成一个完美的形状**；然后形状变成标题、变成导视、变成手机里的界面。全片的看点只有这一个动作，把它做到最好。

## 三个构图（先出小样给主人挑）

- **A · 厂房纵深**：长长的旧厂房，两排锈铁柱、木屋架、高窗光柱。一个巨大的红色正圆刷在柱子、屋架、地面和尽头墙上，从这里看是一个完美的圆；圆心里尽头站着一个人。
- **B · 混凝土中庭仰视**：粗野主义的多层中庭，从底层往上看。同心的四色圆环碎在每一层楼板边、楼梯和墙上，从这里看是一个完整的靶心；顶上是天光。
- **C · 字**：同一座厂房，四个巨大的字“超级平面”刷在柱子、地面、墙上，从这里看可以读；漆是明黄。
