# 蜂窝布局 · 分镜（18.5 秒 · 1080p60 · 120 BPM，一拍 = 30 帧）

## 先想三件事

1. **它自己怎么动：一面透镜。** 中心一圈原大，往外位置按 tanh 收、大小按 sech² 缩（大小 = 位置的导数，所以越挤越小但不重叠）。整片蜂窝被甩着流过透镜（惯性 τ = 0.5 s），停下时吸附到一格上（临界阻尼 0.17 s）。全片的物理只有这三样：透镜、惯性、吸附。
2. **什么接力到尾：同一片 169 颗格子。** 从头到尾不换：圆变六边形、变线框、变数据色块、缩进手表、最后收成七颗。换章是这片格子变过去，不是切过去。
3. **设计师拿走什么：** 中心距 150 / 图标 132 / 缝 12%；平区原大 1:1；往外 `s = 1 − tanh²((r − r0)/k)`；吸附 0.17 s；点开 = 图标长成一整屏；六边形为什么省料；它在哪里用（Apple Watch 主屏、六边形数据图）。

这期没有用“代表作一章一件 / 规则卡 / 手机章”的默认骨架：规则直接画在透镜上（第 02 章），“在哪见过”就是同一片格子缩进手表、摊成地图。

## 分镜

| 帧 | 秒 | 章 | 画面 | 声音 |
|---|---|---|---|---|
| 0—150 | 0—2.5 | 开场 | 第 0 帧就在甩：左边标题，右边整片蜂窝流过透镜；60 帧换个方向再甩；120 帧吸附 | 第 0 帧一记底鼓 + 风声；吸附“咔” |
| 150—330 | 2.5—5.5 | 01 为什么是六边形 | 像转表冠一样放大、透镜摊平，圆一颗颗变成六边形、缝合上、变成蜂蜡的琥珀色；再变回去 | 表冠的一格格“嗒嗒”；变形一串亮音 |
| 330—510 | 5.5—8.5 | 02 透镜 | 格子变成线框；虚线圈出“原大”的平区，量出中心距 / 图标 / 缝；整片慢慢流过去，看得见经过中心变大 | 每条标注一声“叮” |
| 510—690 | 8.5—11.5 | 03 吸附 · 点开 | 甩 → 吸附到一张照片 → 照片长成一整屏 → 缩回原位 | 风声 → “咔” → 上扬 → 下落 |
| 690—900 | 11.5—15 | 04 在哪见过 | 整片缩进一块手表（Apple Watch 主屏）→ 摊开成一张六边形数据地图，颜色一波波扫过 → 变回图标 | 手表“咚”；地图一串马林巴 |
| 900—1110 | 15—18.5 | 收束 | 所有格子往中心收，最后剩七颗六边形“啵”地弹开（1020 帧，第 34 拍）；标题 + 署名“观默” | 上升音 → 重拍 + 镲 + 砸字 |
