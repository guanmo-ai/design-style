# 蜂窝布局 · 分镜 v3（14.5 秒 · 1080p60 · 120 BPM，一拍 = 30 帧）

## 先想三件事

1. **它自己怎么动：一面透镜。** 中心一圈原大，往外位置按 tanh 收、大小按 sech² 缩（大小 = 位置的导数，所以越挤越小但不重叠）。整片蜂窝被甩着流过透镜（惯性 τ = 0.5 s），停下时吸附到一格上（临界阻尼 0.17 s）。全片的物理只有这三样：透镜、惯性、吸附。
2. **什么接力到尾：同一片 169 颗格子。** 从头到尾不换：圆变六边形、变线框、变数据色块、缩进手表、最后收成七颗。换章是这片格子变过去，不是切过去。
3. **设计师拿走什么：** 中心距 150 / 图标 132 / 缝 12%；平区原大 1:1；往外 `s = 1 − tanh²((r − r0)/k)`；吸附 0.17 s；点开 = 图标长成一整屏；六边形为什么省料；它在哪里用（Apple Watch 主屏、六边形数据图）。

这期没有用“代表作一章一件 / 规则卡 / 手机章”的默认骨架：规则直接画在透镜上（第 02 章），“在哪见过”就是同一片格子缩进手表、摊成地图。

## 分镜（v3：每一章一个完全不同的画面，9 个转场）

v3 用一片格子穿越八个场景，各章切换底色、质感和构图。

| 帧 | 秒 | 画面（底色） | 怎么转进来 | 声音 |
|---|---|---|---|---|
| 0—66 | 0—1.1 | 封面：黑底，一团图标流过透镜 | 第 0 帧就在甩；换方向再甩；吸附 + **涟漪** | 底鼓 + 风；“咔”；落水“咚” |
| 66—180 | 1.1—3 | 照片墙：**白底**，六边形照片铺满，放大镜扫过去 | **钻进一格**：镜头冲进吸附的那颗，里面是下一个世界 | 上冲的风 → 低音 + 镲；沙沙的亮声 |
| 180—272 | 3—4.5 | 蜂巢：**琥珀**，满屏蜂蜡，慢慢推近 | **波浪变形**：照片从中心一圈圈变成蜂蜡 | 一串往上的亮音 + 和弦 |
| 272—392 | 4.5—6.5 | 蓝图：**蓝图纸**，白色线框；虚线圈出原大、量中心距；甩一下看透镜 | **翻牌**（从中心往外） | 翻牌一串“嗒”；标注“叮” |
| 392—520 | 6.5—8.7 | 吸附 · 点开：**黑底**图标 → 照片长成一整屏 | **转 60°** + 翻牌回图标；甩 → 吸附 → **涟漪** → **点开** | 风；“咔”；上扬 |
| 520—630 | 8.7—10.5 | 手表：**浅色影棚**，像产品照，表里也甩一下 | **转 60°**，照片缩回表盘 | 下落；手表“咚” |
| 630—722 | 10.5—12 | 数据地图：**纸白**，像报纸信息图，颜色一波波扫过 | **翻牌** | 翻牌；马林巴 |
| 722—870 | 12—14.5 | 收束：**黑底**，地图收成一点、攒光，810 帧（第 27 拍）七颗弹开；标题 + 署名“观默” | **收成一点 + 弹开** | 上升音 → 重拍 + 镲 + 砸字 |
