# 蜂窝布局 · 制作过程（2026-11-18）

> 记录，不是规则。

## 网格与界面

蜂窝网格常见于 Apple Watch 主屏、六边形数据图等界面。短片围绕相邻单元的缩放和排列展开，并将同一组格子变形成多种场景。

## 三件事

1. **它自己怎么动：** 一面透镜（tanh 收位置、sech² 缩大小）+ 惯性 + 吸附。
2. **接力：** 同一片 169 颗格子，从头到尾不换。
3. **设计师拿走：** 中心距 / 缝、平区、收缩曲线、吸附时长、点开的做法、为什么是六边形、在哪用。

这期没用默认骨架（代表作 / 规则卡 / 手机章）：规则直接画在透镜上，“在哪见过”是同一片格子缩进手表、摊成地图。

## 改过的地方

| 问题 | 怎么改 |
|---|---|
| 探索稿 0.7—3.6 秒几乎不动（第一次甩停了以后，吸附只挪一点） | 加第二次换方向的甩，再吸附；全片一直有一点点漂 |
| 第 0 帧甩得太快，图标全糊 | 甩提前开始，第 0 帧已经在减速 |
| 蜂蜡第一版中间压得太暗，像一片发光的橙色圆斑 | 改成上深下浅的竖向渐变 + 一圈亮的蜡壁 |
| 线框太淡 | 线加粗加亮，里面留一点点照片 |
| 收束：七颗早早到位、等着落定，弹一下几乎看不见 | 先和大家一起收成中心一小团、落定前一拍往里缩（蓄力），第 1020 帧欠阻尼弹开（冲过头约 12%） |
| 收成一点的那 0.43 秒被量成“死区” | 中心攒一团光，跟着上升音变亮，弹开时散掉 |
| 手表侧键的橙色条太像某一款真表 | 改成中性灰的表冠竖纹 |

## v2：节奏更快、多转场

第一版每章 3—4 秒，大半时间在等字出完；换章大多是淡入淡出。v2：

- 18.5 秒压到 16 秒，章节起点都在拍点上（120 / 270 / 420 / 570 / 735，落定 870 = 第 29 拍），每章最多两行字、字出得更快。
- 换章换成四种蜂窝自己的转场：**涟漪**（尺寸按 `1 + 0.32·e^(−t/13帧)·sin` 从中心往外传，波速 38 px/帧）、**翻牌**（每颗 12 帧，横向缩放 |cos πp|，过一半换内容；按离中心距离最多晚 24 帧）、**转 60°**（三次，共 180°；六边形转 60° 和原来重合）、**波浪变形**（同样按距离错开）。
- 全屏蜂蜡那一段加一个慢推近，手表里也甩一下——不留停住的段落。
- 配乐跟着重排和弦和旋律；加了涟漪、翻牌、转动的声音。

## v3：每一章一个不同的画面

v2 已经有 9 个转场，但每章都是“黑底 + 一团图标”，看起来是同一个画面在变。v3：

- 16 秒压到 14.5 秒；8 个画面各有自己的底色和质感：黑底图标、白底照片墙（放大镜扫过）、琥珀蜂巢、蓝图纸线框、黑底点开、浅色影棚的手表（地面影子）、纸白数据地图、黑底收束。底色在章与章之间平滑过去。
- 新转场“钻进一格”：镜头冲进吸附的那颗图标（外面的世界放大 5 倍糊过去），图标里面就是下一个世界，从 0.3 倍长到原大。
- 字的面板跟着底色走：浅底用深字，深底用浅字。
- 修了一处：钻进去的最后一帧，里面那个世界的底色还是黑的，闪了一帧——底色表从照片墙的白色开始。

## v4：时长回到 18 秒、字重做、10 个画面

- **提高画面密度。** 18 秒、10 个画面，每 1—1.5 秒换一次，转场都在拍点上。新加两个画面：三色对称（跟着鼓点两下“咔嗒”转 60°，带回弹和涟漪）、手机里选兴趣（手表直接变形成手机，手指点三下，点中的弹大、打勾）。
- **重新设计文字：** v3 是“小标签 + 粗黑大标题 + 一行说明，垫一块暗色渐变面板”，像 PPT。v4 改成：一个主角字（数字为主，会计数）+ 一行等宽小字（带一根短线）+ 一两行 Medium 中文；整行从遮罩里滑上来、滑出去（quart-out 20 帧）；不垫面板，字出现时那一块的格子缩小退开——“给字让位”本来就是布局在做的事。
- 角上的 HONEYCOMB / 页码去掉了：三色对称那章压在白色六边形上看不清，每章的等宽小字已经说了是第几章。
