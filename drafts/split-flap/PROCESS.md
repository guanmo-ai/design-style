# 翻牌显示 Split-Flap · 制作过程

一支 16 秒的翻牌墙动效短片。从任务书到成片的记录。

## 方向（任务书定的两条）

- **第 0 帧**：一整面翻牌墙，巨大像素字「翻」已落定、「牌」正被一道斜波写出来，波前几百块牌翻到一半。
- **只属于它的物理**：每块牌是一叠按固定顺序排的卡片，**只能往前翻**，一张 4 帧。到站 = 起跑 + 张数 × 4 帧。牌是掉下来的（θ ∝ t²），撞挡片回弹 4%，掉时影子压在下半张上。

## 怎么做的

**一条规则，不 K 帧。** 画面（`scenes.js` 的 `target(id, f)`）只回答“第 id 块牌在第 f 帧想要哪一张”。什么时候真的翻到、翻过哪些牌、落定时间，全由 `wall.js` 的 `state()` 从那条规则算出来——波浪、涟漪、最后零星几块还在翻，都是算出来的。配乐的每一声“嗒”也取自同一套落定时间（`landings()`）。

**渲染**（`flap.js`，WebGL2 实例化）：每块牌 = 上半张 + 下半张 + 正在掉的那张 + 一根轴，都是同一个薄盒子绕铰链转。顶上一排灯做衰减照明 + 高光，掉落的那张反着顶光、亮一下。背后是带凹槽的深色机壳。每帧渲 8 个子帧（时间 + 亚像素一起抖）累加 = 运动模糊 + 抗锯齿；快翻的牌因此自带拖影。每帧是帧号的纯函数，断点续渲。

**一帧多少秒**：云端 4 核、SwiftShader。1920×1080、8 子帧、60 列 × 26 行（约 4700 个实例/子帧），**约 2.3—2.9 s/帧**；全片 960 帧后台渲约 36 分钟。预览（2 子帧、半尺寸）约 0.5 s/帧。

**接力**：同一面墙从头到尾。镜头一次连续推拉——全景斜看 → 推到“00:05”的最后一位看清一张牌怎么掉（铰链、厚度、中缝、影子、回弹、ghost 显示 θ∝t² 的落点间距越来越大）→ 连续拉回全景看整面墙刷新。没有硬切。

**章节**（发挥的部分，任务书只定了方向）：开场波写字 → 黄球砸墙、涟漪把两个字散成字母雨 → 机场出发大屏一列列刷 → 推到倒计时特写 → 拉回、大屏整体上移一行 → 波扫回「翻牌 SPLIT-FLAP」，「观默」两块从空白翻过整副 42 张，最后「默」单独落定、顶灯闪、镜头往下咚一下。

## 交片前的两个检查（原文）

```
$ python3 ../../_lib/smooth.py split-flap-film.mp4
960 帧 · 相邻帧平均差 3.89（中位 2.79，最大 10.15 @ 第 929 帧）
跳变 15 处：[449, 450, 451, 452, 483, 484, 515, 516, 546, 547, 578, 579, 580, 929, 930]
死区 0 段：[]
```

逐个核对：449—452 / 483—484 / 515—516 / 546—547 / 578—580 全是倒计时每张牌落定的那一下（翻牌本来就是“静止—啪—静止”，每 ~31 帧一次，是有意的重拍）；929—930 是最后一块落定 + 镜头往下咚。**没有计划外的跳变，死区 0。**

```
$ python3 ../../_lib/cover.py split-flap-film.mp4
第 0 帧：亮度 76 · 对比 64 · 细节 15.4 ｜ 全片好帧：对比 67 · 细节 14.0 ｜ 前 0.2 秒变化 3.05
没有低级错（不空、不弱、0.2 秒内在动、前 2 秒没停）。
```

第 0 帧细节量（15.4）比全片好帧（14.0）还高，不空不弱，0.2 秒内在动。

压缩：2-pass H.264 ~12 Mbps，24.1 MB（≤ 25），yuv420p + faststart。从成片解码了第 96 帧（球砸墙、整列数字高速翻）和第 760 帧（结尾波），快翻的牌仍清楚，没有糊成马赛克——这是任务书点名的风险。

## 哪 2 秒最没把握

**倒计时特写的“停顿”（约 7—9 秒）**。翻牌的美学就是“静止—啪—静止”：每张牌翻完 4 帧，要停约 0.4 秒等下一拍。这一段是全片动得最少的（联系表量到相邻帧差 ~1.1，但死区仍是 0）。我让它不平的办法：镜头一直在很慢地绕（每次停顿里大数字的透视和高光都在移）、ghost 轮廓标出落点、标注一行行打出来、刚落定的数字带残余运动模糊。自己看静帧觉得够了，但**这一段到底会不会显得“等”，要主人看了动起来才知道**；如果平，我会把镜头的绕动再加大一点，或在停顿里让相邻格偶尔翻一下。

## 没做 / 没验证

- **没放规则卡章、没放手机章**（任务书要求）：设计师能拿走的数直接用“小号等宽字 + 一根线”钉在正在发生的牌上。
- Claude 看的是静帧和连续帧，**没看过播放**；配乐只用程序核对了时长（16.0 s）、响度（-14 LUFS）和分段音量曲线，**没听过**——报告里不写“好听”，只写量到的数。
- 中文在点阵里的大小：「翻」「牌」各占 26×22 格（任务书要求 ≥ 20×20），缩到宽 360 的缩略图里仍认得出（已看）。
