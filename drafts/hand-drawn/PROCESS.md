## 做法

**同一只猫、同一个夜晚、三种画法。** 六张图共用一只可以摆姿势的猫（`cat.js` 只出多边形），画法各写各的。这样比较的是画法，不是题材；做片子时也可以直接拿它当主角。

**笔触都是带种子的函数**（`lib.js`）。同一个种子出同一张图，换种子就是“手重描了一遍”——动起来时线的抖动（每秒 8—12 次换种子）不用另外写。

| 画法 | 关键做法 | 数字 |
|---|---|---|
| 墨线 `ink` | 折线沿法线加低频噪声（手抖），再按“起笔渐粗、收笔渐细”拉成一条带子 | 线宽 3—14 px；手抖 1.5 px、波长 70 px；起笔 15% / 收笔 30% 渐细 |
| 网点 `halftone` | 斜网格上画圆，半径 = 格距 × 0.72 × √色调 | 格距 9—14 px；角度 15°—60°，每层颜色换一个角度 |
| 色版错位 | 颜色画在一层、墨线画在另一层，合成时颜色层偏 (5, 4) px；墨线下面再垫一层青 (−4, −1) 和一层红 (4, 2) | 偏移 4—5 px（1080p） |
| 边缘光 | 形状剪裁后先涂亮色，再把同一个形状偏移几个像素涂回黑：露出来的那一条就是光 | 上方冷光偏 (5, 8)，下方暖光偏 (−3, −6) |
| 蜡笔 `crayon` | 先画实心笔画，再乘一张“纸的颗粒”蒙版（半分辨率噪声 + 全分辨率噪声 + 一点大尺度起伏）。每根线画两遍：宽的涂得虚，窄的涂得实 | 颗粒密度 0.42（虚）—0.95（实）；线宽 6—24 px |
| 乱线填色 `zigzag` | 多边形 × 扫描线求交，连成一笔来回涂；线头随机冲出边或者没涂到边 | 行距 10—17 px；冲出 6—26 px |
| 蜡笔轮廓 | 整组形状一起描边，再把形状内部挖掉：只剩外轮廓那半条线。描两遍，第二遍故意不重合 | 线宽 6—9 px |
| 2D 特效 | 火舌 / 水柱 = 一条 S 形中线 + 半径曲线（根粗尖细）；烟 = 一串圆，每个圆带一道月牙暗面；断开时从里面挖洞 | 每种 2—4 层平涂；五张关键帧 起 / 胀 / 爆 / 断 / 散，停 2 / 4 / 6 / 8 / 8 帧（24 fps） |

## 踩过的坑

- **猫第一版像黄鼠狼**：身体太长太细，腿是没有关节的管子。改短身体、加深胸腔、头放大 1.22 倍、头改成有棱角的轮廓、逆着运动方向的一侧加毛尖，才像猫。毛尖一开始等距等大，像锯条；改成间距和大小都随机才行。
- **冲击帧第一版猫看不见**：黑猫画在黑底上。冲击帧要“黑白反过来”，但主角和背景必须一黑一白——把白色的锯齿星放大到整只猫都落在里面。
- **边缘光不能一条腿一圈**：每个零件各做一遍边缘光，身体里面全是亮线。要把躯干、脖子、头并成一组再做，光才只出现在外轮廓。合并多个多边形时绕向要统一（`HD.norm`），不然重叠处会被挖空。
- **`.gitignore` 里有 `out`**：出图目录不能叫 `out/`，用的是 `images/`。
- **乱线一张 90 秒**：每一笔蜡笔都新建一张 1920×1080 的图层再乘颗粒。静帧无所谓，做片子不行——见下面。

## 后面接着做时

- **速写本乱线（主人点名后面做）**：先解决速度。蜡笔颗粒改成只在笔画的包围盒里算，或者整个挪到 WebGL（颗粒当成一张贴图在片元着色器里乘）。目标一帧 2 秒以内，才渲得动 15—20 秒的片子。动法：轮廓线每秒 8—12 次换种子重描；光锥的线一根根甩出来；爆炸的线从中心往外长，越靠中心越粗。
- **漫画墨线 / 手绘特效**：主人觉得不够“电影”。我的判断（不是主人说的）：差在角色和空间——猫的结构简单，背景是平面的布景。要更像院线，得有真正的三维空间和光（用 3D 渲出来再叠墨线和网点），这是另一套做法。
- 特效表里的五张关键帧可以直接当动画的关键帧用，中间补帧时注意“快进慢出”。
