# 手绘三支 · 怎样才能爆、视觉怎样才顶尖（2026-11-17）

主人第五轮：“手绘动画开头那个要删除，跟后面不是一个风格，最好看的放在前面。铅笔原画没有看出视觉的顶尖，怎么震撼人呢？你这样怎么可能推到爆款？你好好分析一下怎么样才能推到爆款？视觉怎么才能顶尖？厚涂风格挺好看，但还没做到很顶尖，BGM 也不够好。”

## 一、X 上设计 / 动效视频是怎么爆的

一条视频在 X 上爆，要连着过三关。只要一关没过，后面做得再好也没用。

1. **第 0 帧，0.5 秒：停不停手。** 时间线上自动播放、静音。别人只看到一张会动的封面，这张图本身要比他刚划过去的十张都好看，或者“看不懂这是怎么做到的”。**一定要把全片最好看的那一刻放在第 0 帧，不要“先铺垫”。**
2. **3—8 秒：看不看完。** 要有一个“哇”的转折，让人想看下去：揭秘（一张画拆成七层纸）、尺度跳变（推到笔触里 / 拉出来是整面墙）、质变（线稿变成写实、平涂变成油画）、或者一个让人想再看一遍的动作。字幕讲道理是减分的：人是来看“哇”的，不是来上课的。
3. **结尾：转不转、存不存。** 转发是因为“这个太厉害了，我要给别人看”（工艺震撼，“这是代码画的？”）；收藏是因为“以后用得上”（色板、参数、方法）。所以最后一屏要么是一个能截图收藏的“干货卡”，要么首尾相接、自然循环让人看第二遍。

再加两个乘数：

- **配乐**：好的音乐能让同一段画面的完播率差一大截。合成器做的乐器一听就“便宜”，这是我们 BGM 一直不过关的根本原因之一（另一个是高频太刺，已经修了）。所以用 Sonilo 这种真乐器质感的生成配乐，再由我混音效、对切点。
- **“没用 AI 生成画面，全是代码画的”**：这是我们最大的传播点。但只有画面本身已经顶尖时它才成立；画面一般，这句话没有人关心。

## 二、“视觉顶尖”具体是什么（能检查的几条）

1. **明暗有大结构**：有真正的黑和真正的亮（主体被光照到，背景压暗或逆光），一眼看得出主体。铅笔 v3 的问题就在这：整屏米白、线是浅灰，没有黑，手机上就是一张白纸。
2. **细节的密度**：静帧放大也经得住看，每一寸都有东西（笔触、颗粒、纹理、光斑）。
3. **光**：逆光的镶边、体积光、光斑、发光，这些是“电影感”的主要来源。
4. **纵深**：前中后景分层、视差、景深虚化，镜头真的在三维空间里走。
5. **运动设计**：起势、收势、跟随、过冲；镜头和主体有不同的节奏；每一刻都有东西在动，但只有一个主角。
6. **风格统一**：一支片子只用一套画法（手绘动画 v3 就是在这里翻车：稻田是水粉写实的积雨云，后面是分色平涂）。
7. **有一个“不可能”的瞬间**：普通人想不到、也做不到的那一下。

## 三、三支片子各自怎么改

### 手绘动画（这一轮已改成 v4）

### 铅笔原画（需要换方向，建议如下）

v3 的问题不是节奏，是画面本身不够震撼：一只简笔面粉袋在白纸上跳，再怎么切场景也只是“教学演示”。铅笔真正让人震撼的有两种：

- **A · 照片级的石墨（推荐和 B 合用）**：几千上万根排线一层层叠出体积，深黑像天鹅绒、高光是留白的纸。网上播放量最高的铅笔内容就是“看他一笔笔画出一只写实的眼睛 / 老虎”。这件事我们能用厚涂那套“参考帧 + 方向场 + 一笔笔画”的引擎做，只是把油彩换成排线、纸纹和侧光。
- **B · 走进一个用铅笔画出来的三维世界**：镜头在一个整个由交叉排线画成的城市 / 原野里飞（明暗 = 排线的密度，轮廓 = 石墨线，线每秒重画 12 次在“沸腾”），换场景是推进一扇窗、钻进一页纸。这是“一张素描活过来”的感觉，是三支里最可能出“不可能的瞬间”的方向。技术上：用仓库里已有的 three.js 场景（`drafts/_3d` 的山谷小火车、街角模型）加一个排线着色器，渲染成铅笔画。

建议的片子：第 0 帧是一张照片级的石墨画（高反差、深黑），1 秒后它开始动，镜头推进画里，变成一个铅笔画的三维世界飞过去，三四个场景，最后拉出来回到桌上那张纸。先出第 0 帧和一个 3 秒小样给主人看，过了再做全片。

### 厚涂（风格对了，往“顶尖”再推）

- **开场换成最震撼的一下**：贴着画布的微距——一刀厚油彩被刮刀推开、侧光扫过，能看到颜料的起伏和高光——1 秒后拉开才是整张画。现在的开场是“一张已经画好的画”，少了“厚”这个字最直接的冲击。
- **母版分辨率提到 3 倍**，推近时笔触和刷毛纹更清楚（现在 2 倍，推到 2 倍时有点糊）。
- **参考帧做得更好**：现在麦田、浪、雪山的参考帧比较粗（程序画的形），笔触盖上去以后能看出形是简单的。要加大气（雾、光柱）、更复杂的形和更强的明暗。
- **节奏**：雪山那一段加片尾停了快 7 秒，太长；片尾提前、再加一幅（比如夜里的海港灯火）让后半段也有新东西。
