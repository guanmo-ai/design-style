# 黏土 Clay · 分镜


## 先想三件事

1. **这种材料自己怎么动？** 塑性：按下去不回弹（和毛绒正相反），体积不变（压扁 s，另外两边各 ×1/√s；搓长、变细），被切开时截面露出它是怎么揉、怎么卷的。全片只有这一种物理：每个动作都“留下来”，没有弹簧回弹（只有落地时 ≤5% 的一点沉）。
2. **什么从头接力到尾？** 同一团泥：“黏土”两个字 → 塌成一根泥卷（同一个距离场，lMix 从 1 混到 0）→ 滚 → 切成片 → 片躺在手机屏上变成按钮 → 倒带拼回泥卷 → 立回“黏土”。没有硬切。
3. **设计师能拿走什么？** 每个动作配一行能抄的数（左下）：压扁 62% → 另外两边 ×1.27；长 ×1.45 → 粗 ×0.83；0.3 mm 钢丝一拍一刀；按下去的形状就是按钮的状态。外加四套泥的配色（珊瑚 / 薄荷 / 葡萄 / 蜂蜜，各 4 色）和一种界面用法（待办：做完就按一下，按扁的就是做完的）。

## 时间轴（60 fps · 120 BPM · 一拍 30 帧 · 共 12 秒）

| 帧 | 画面 | 背景 | 声音 |
|---|---|---|---|
| 0—60 | 第 0 帧就是封面：大理石纹的“黏土”（黏 = 珊瑚，土 = 葡萄）。土先往上提一点，第 15 帧被按扁到 62%（留在那），第 45 帧黏被按到 72%；镜头往前推，按的那下往下“咚” | 暖灰 | 两下圆底鼓 + 噗；“按 PRESS” |
| 72—118 | 两个字塌成一根泥卷（三套泥接在一起：蜂蜜主体，右头一圈圈 葡萄 / 薄荷 / 珊瑚） | → 鼠尾草灰 | 往下的弹簧音 |
| 118—212 | 往镜头这边滚，越滚越长越细；螺旋纹跟着转；镜头绕到右头 | | 刷过去；“搓 ROLL” |
| 240 / 270 / 300 / 330 | 一拍一刀：钢丝落到底的那一拍切开，片先分开一条缝，像被重力拉倒一样越倒越快，落地沉一点；已经倒下的片往前让一格 | | 嘶 + 咔 + 软落地；“切 CUT” |
| 350—400 | 镜头升到正上方；桌上亮起一块手机屏，四片泥正好是待办里的四个按钮 | → 淡紫灰 | |
| 420 / 435 / 450 / 465 | 八分音符：一片一个指纹，按扁、不回弹；旁边的待办被划掉 | | 啵 + 噗；“印 PRINT” |
| 500—548 | 倒带：指纹退回去、片立回去、泥卷滚回原处 | | 反向镲 |
| 548—596 | 泥卷立成“黏土” | → 黑场 + 一池光 | 弹簧音 |
| 600 | 两个字一起被砸扁一点（收束：一个动作 + 一个声音）；CLAY、署名“观默” | | 重击 + 镲 |
| 600—720 | 镜头慢慢绕过去（不留死区） | | 余音 |

## 这次没用默认骨架

没有代表作章、规则卡、手机章：主人要快节奏。四条规则各是一个动作（按 / 搓 / 切 / 印），“用在界面上”是第四个动作本身（泥片就是按钮）。
