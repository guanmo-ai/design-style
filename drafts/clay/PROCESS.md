## 这种材料自己怎么动（给片子用）

黏土是**塑性**的：按下去不回弹（和毛绒正相反），体积不变（压扁 s → 另外两个方向各撑开 1/√s；搓长 4 倍 → 细一半），每碰一下都留下指纹。
第二版把“好看”押在两件只有黏土才有的事上：

1. **几色泥没揉匀的大理石纹**——纹是在物体自己的坐标里算的，所以切开、压扁、搓长时纹跟着走。
2. **切开**——切泥线一拉，截面上露出螺旋（搓成卷再切）。“切东西”是 X 上最稳的解压类内容。

片子的设想（还没做）：同一团泥接力到底——揉（四色叠在一起，揉三下出纹）→ 搓成卷 → 切泥线一刀刀切下去，每片截面都是一个字 / 一张图 → 被拇指按扁成界面里的按钮。转场都是“对泥做一件事”，不是切镜头。

## 渲染器 `clay.js`

一个光线步进着色器，没有贴图：

- 文字：距离场挤出成厚片（圆角、鼓起、边缘轻微扭曲），可以平放或站着，每个字可按体积守恒压扁。
- 球 / 扁饼（椭球）、泥条（胶囊串，按 8 段一组的包围球筛）、圆柱段（泥卷）、木头工具。
- 拇指坑：椭球拇指肚按进去 + 坑沿鼓起 + 坑底指纹；可选“饼”（窄泥条被按一下会摊开）。
- 钢丝切：平面以上的部分整块滑开（`cut`），纹在截面上接得上。
- 材质：哑光 + 薄油光，明暗交界和阴影里更饱和；大理石纹（颜色 ≥ 10）、螺旋（≥ 20）。
- 景深（输出时按深度散焦）、界面底板（`panels`，泥的影子落在上面）。

## 踩过的坑

| 现象 | 原因 | 做法 |
|---|---|---|
| 整个场景是一块灰盒子 | GLSL 的 `pow(负数, 2.0)` 是 NaN | 平方自己乘 |
| 只有字，球和泥条都不见 | 建占位纹理时把 1 号纹理单元上的数据纹理换掉了 | 占位纹理先建，再绑数据 |
| 字面有台阶 | R32F 在 SwiftShader 上不能线性过滤，退成最近邻 | 距离场存 R16F |
| 桌上一圈圈等高线 | 包围盒外的距离估得太小（盒边只有 0.05），阴影射线一出盒就被“挡住” | 盒子四周留 0.7 的边，盒外返回 `到盒距离 + 0.6` |
| 黑色锯齿楔形阴影 | 改进版软阴影在距离跳变时 d 算成 0 | `y` 限制在 `0.5h` 以内 |
| 框外的字场穿模 | “到框距离 + 框边距离”是上界 | 改成两个下界取大 |
| 字底一道亮缝 | AO 不算桌面，贴桌的底边当成没遮挡 | AO 采样也取到桌面的距离 |
| 字顶一圈棱线 | 鼓起用了 `clamp`，有折角 | 换 `smoothstep` |

## 片子 `film/`

- `film.html`（页面 + 字）、`scenes.js`（每帧的场景，帧号的纯函数）、`timeline.js`、`audio.py`、`make.sh`。
- **测速**（云端 4 核、SwiftShader）：第一次画一帧有 ~3 秒是着色器编译，之后才是真实成本。1080p 每帧 15 秒、960×540 每帧 4 秒；空场景（只有地面）就要 1 秒，每多一类物体（字 / 球 / 圆柱）多 1—1.6 秒——每次求距离都要把所有东西过一遍。阴影 / AO 步数减半只省 10%。
- 所以片子在 1152×648 渲（约 7 秒 / 帧，720 帧约 1.5 小时），浏览器放大到 1920×1080 截图，字是 1080p 的；同一时刻只放需要的东西（字只在 lMix > 0 时算，泥卷段只在 lMix < 1 时算）。
- 试过但没用：把贵的分支写成“最多跑一次的循环”想让 SwiftShader 跳过——没用，省时间的其实是编译。

## 没做 / 没验证

- 配乐只核对了时长和响度（−13.9 LUFS），没听过。
- 看过的是静帧和连续帧，不是播放。
- 俯视时片上的指纹很浅（看得出按扁，指纹本身不明显）；地面上离泥片很近的地方有很淡的一圈圈阴影纹（软阴影步进的痕迹）。
- 封面左上写了 `NO. 029`，是按现有最大期号 028 往后排的，开做时再确认。
- 字体：ZCOOL 庆科黄油体（OFL）、Fredoka（OFL）、Noto Sans SC（OFL）、Geist Mono（OFL）。
