## 动的方法（都在 `scene.mjs`）

- **落地**（`poseAt`）：位置三次缓入缓出，高度是抛物线 `zmax·4p(1−p)`；落定后角度按 `e^(−u/5)·cos(0.85u)` 抖两下，压扁 5% 再弹回。
- **影子**（`drawShadow`）：偏移 = 5 + 0.62 × 高度（px），越高越虚越淡。规则 03 标的数字就是这条公式。
- **翻面**：`turns` 圈；翻到背面露出同一轮廓的纸背，侧面压暗。规则 01 换字体就是翻面时换一张脸。
- **震动**：重的落地记在 `THUMPS`。镜头往下一沉再弹回；别的纸片按 `距离 / 95` 帧的延迟跳一下，高度随距离衰减、越大的纸跳得越低；崩出几片纸屑（`confetti`）。
- **撕底纸**（`background`）：五次，第 90 / 268 / 437 / 661 / 885 帧开始，各 24 帧，方向右、下、左、上、右。
- **镜头**（`camera`）：每章从 1.012 慢推到 1.05，章末回弹；每章歪一个角度（−1.1° / +0.9° / −0.7° / +1.1°）；有鼓的段落每拍往里顶 1.1%。
- **外框和标注**（`hud`、`slap`）：纸条从 1.5 倍拍到 1 倍，字一个个打出来（一字一声），离场往左甩。画在屏幕坐标里，不跟镜头缩放。
- **剪刀**（`scissorsAt`）：关键帧之间缓动，每次合拢前先张开；剪标题时在词之间跳着走。

## 文件

| | |
|---|---|
| `kit.mjs` | 字体、随机、纸纹、剪的 / 撕的轮廓、把纸片烤成贴图（正面、背面、剪影、两档影子）、网点照片 |
| `pool.mjs` | 全片所有纸片 |
| `scene.mjs` | 站点表（每张纸片依次落到哪）、姿态、底纸、镜头、外框、`render(ctx, t)`、给声音用的 `events()` |
| `render.mjs` | 出单帧 / 联系表 / 挑帧拼图 / 成片 / `events.json` |
| `mix.py` | 截出配乐、合成纸声、混到 -14 LUFS |
| `make.sh` | 一键出片：`cd drafts/dada/film && bun install && bash make.sh` |
| `v1/` | 第一版（20 秒、120 BPM、代码合成的卡巴莱进行曲）的场景和配乐脚本 |
