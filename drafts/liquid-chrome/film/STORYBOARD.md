# 液态金属 Liquid Chrome · 分镜（全片 18 秒）

1920×1080 · 60fps · 120 BPM（一拍 = 30 帧）· 1080 帧。画面 `film.html`（复用 `../chrome.js` 的光线步进渲染器），时间轴 `timeline.js`，配乐 `audio.py`（读同一份时间轴）。出片：`bash make.sh`。

**这一期最有用的一招：** 它自己没有颜色，颜色全是它照到的世界——所以动起来的不只是形状，还有倒影。
**签名物理：** 表面张力。两滴一碰先长出“颈”再合成一滴；合完了晃三下（衰减振荡）；拉长的柱子永远断成一串差不多大的珠（瑞利–普拉托）。
**接力元素：** 同一滩水银。字从里面站起来 → 化成四颗珠 → 合成一颗 → 拉成柱 → 断成五颗 → 收成一颗倒进手机 → 落回水银 → 字又站起来。全片不硬切。

## 渲染上踩过的坑（给下一期）

- SwiftShader 上同一份大着色器，**空背景也要 2 秒 / 帧**。做法：同一份代码编译两遍——“背景版”编译期去掉光线步进，只画背景和地面；完整版只在液体（以及它在地面里的倒影）投到屏幕上的矩形里画。
- 液滴 / 液丝 / 波纹的数据**不要放 uniform 数组**，放进一张 64×12 的浮点纹理里 `texelFetch`。
- 每组图元一个包围盒，射线离得远就整组跳过；整个场景一个包围盒，射线碰不到就不走。
- 最后约 1—4 秒 / 帧（字多的帧更慢），两页并行。
