## 怎么跑
本目录已经位于 `drafts/gummy2/`，页面复用同分支的 `../_lib/glkit.js`。在仓库根目录运行：
```
cd drafts && node _lib/shot-gl.cjs gummy2/cover.html out.png 1920 1080 1 "w=1920&h=1080&spp=8&tiles=6"
```
参数：`spp` 采样数（抗锯齿 + 运动模糊），`warm=1` 先热身再计时，`dbg=1/2/3/4` 看厚度/散射/透射/菲涅尔，`aper/bloom/streak/exposure/thr` 覆盖后期。

## 借的光（已定）
1. 《天国之日》(1978, Néstor Almendros) 的魔幻时刻逆光：太阳压在地平线上、就在主角身后（右耳上方），薄处透亮、厚处深红。
2. 《银翼杀手 2049》(Deakins) 华莱士办公室的晃动水光：光穿过软糖在地上聚成彩色焦散，出口面加细小起伏做成亮丝；视频里软糖晃，地上的光跟着晃（动效签名）。
3. 长焦低机位 + 远处一片软糖田（域重复）虚成一盏盏灯 = “世界”，不是黑棚。

## 渲染器（shader.js / gummy.js）
自写光线步进，不用 three.js transmission（上一轮像塑料的原因）：菲涅尔反射 → 折射进去走内部真实路径 → 比尔–朗伯吸收（越厚越深）→ 内部单次散射（逆光发光）→ 全反射再走一段 → 背面折射出去看见地面/天空/软糖田柔光；地面：太阳穿过软糖的彩色影子 + 焦散，湿地面反射 + 太阳竖直光带。后期：景深（散射式 gather）、泛光、保色相色调映射（红不会变橙）、S 曲线、颗粒。

## 实测速度（云端 SwiftShader，4 核无显卡）
- 1920×1080：场景约 19 s / 采样，后期约 2 s，首帧编译约 8 s。960×540：约 5.8 s / 采样。
- 结论：云端做 60fps 片子太慢（900 帧 × 1 采样 ≈ 5 小时）。按 DESIGN_NOTES 的分工交 Codex 在 Mac 显卡渲（估计 0.1–0.3 s / 采样）；云端只出静帧和低分辨率小样。
- 已做的优化：散射改 3 点 × 8 步粗估厚度；地面反射里的软糖用便宜着色；透过软糖看到的软糖田换成柔光带。刚试的“只在包围球内步进”几乎没提速（5.82→5.77 s），瓶颈还没定位——下一步用 dbg 分区计时（地面 sunThrough / floorAO / 反射追踪 / traceField / 软糖内部）。
