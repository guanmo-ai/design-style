# 光绘 Light Painting · 制作过程

一个词到成片。方向来自任务书：第 0 帧 = 发光的大字 + 一圈炸开的火花；物理 = 画面是快门开着这段时间里所有光加起来。

## 一条物理，全片都从它推出来

`scene.js` 把每个光源的一生写成一串**等时间间隔的样本**（位置、功率、颜色、宽度，全是时间的纯函数）。`light.js` 画第 f 帧，就是把落在快门窗口 `[t − T, t]` 里的样本两两连成带宽度的胶囊，加法混合累加到 RGBA16F，再 ACES + 三层泛光。

- **亮度 ∝ 1 / 速度**：一段的能量 = 功率 × 它在窗口里的时长，摊到它在屏幕上的面积（`E · s² / (L·σ + σ²)`，着色器里算）。走得慢 → 面积小 → 亮；停住 → 过曝点；甩过去 → 细线。笔画轻重没有另画。
- **快门 T 是唯一的换章旋钮**：T 拉长，整幅都在；T 收短，最早的光先消失，字从起笔被吃掉一路追到光点。换章不剪辑、不淡入，只调 T（`shutterT(f)`，几段之间在对数里平滑过渡）。
- **接力**：从头到尾同一颗光（`segs` 一条连续的段链）：写字 → 收快门剩光点 → 绳上转成光球 → 拉成 48 灯光棒扫出字（时间摊成空间）→ 炸成钢丝棉 → 变小写签名。片尾 T 拉到 20 秒，整部片子的光回到同一张照片。

火星：每颗的轨迹是出生时间的闭式函数（抛物线 + 落地弹跳 e 0.45 + 滑行），`spark()` 预先把分段算好再取样。第 0 帧那一圈约 1500 颗、高潮约 2500 颗。

## 一帧多少秒

云端 4 核、无显卡、SwiftShader。1920×1080：火星多的帧约 0.9—1.4 s，光少的帧 0.5—0.7 s，片尾全曝光（样本最多）约 2 s。全片 960 帧单页约 16 分钟。把火星密度（`sr`）和主光点粗细做成查询串，先低密度联系表定节奏再调。关键一步：仓库 `node_modules` 的 Playwright 版本和云端预装 Chromium 对不上，加了 `pw.cjs` 预加载改用 `/opt/pw-browsers/chromium`（`make.sh` 和所有渲染都 `node -r ./pw.cjs`）。

## 审片（便宜到贵）

低密度全片联系表（每 30 帧）→ 关键动作连续帧（收快门、换章、钢丝棉）→ 全质量单帧（第 0 帧、片尾）→ 正片。
改过三轮（第三轮见下面“最没把握”）：① 第 0 帧一开始整屏过曝、字糊成一团——降主光点功率、收火星亮度、提泛光阈值到 1.6、把镜头压低到水边（字在上半、火星铺满、水里再倒映一倍）。② “哪 2 秒最平”= 光棒吃掉到钢丝棉点燃那一下（f615—650），`smooth.py` 报了 12—16 的跳变；把那段的镜头运动提前到 f606 开始连续推、收快门过渡拉长，跳变消失。

## 两个数字检查（成片）

```
smooth.py：960 帧 · 相邻帧平均差 2.72（中位 1.97，最大 12.80 @ 第 812 帧）· 跳变 2 处 [900, 901] · 死区 0 段
cover.py：第 0 帧 亮度 99 · 对比 74 · 细节 8.6 ｜ 全片好帧 对比 74 · 细节 10.6 ｜ 前 0.2 秒变化 0.55 · 没有低级错
```

- 跳变 [900, 901] = 快门“咔”合上那一下（曝光闪一下 + T 冻结），有意的，不是硬切。
- 第 0 帧对比/细节不低于全片好帧，前 2 秒不停。

## 这次没按默认骨架做

没有规则卡章、没有手机章、没有左上章节 / 右上进度外框。全片的“章”就是快门 T 的收放，规则和数直接标在正在发生的画面上（标注线锚在光点 / 光球 / 光棒 / 钢丝棉上）。右上角用快门读数代替进度条。

## 没做、没验证的

- **Claude 看不了播放、听不了声音。** 看过的是静帧、连续帧、联系表；配乐只核对了时长（16.0 s）、响度（−14.0 LUFS）和音量曲线（−14 ~ −17 dB，f420 收快门处 −21 的低谷是有意的留白），**没听过**。甩光的“呼”音量接了画面的速度曲线、火星“滋啦”接了出火星速率、快门“咔”落在小节线上——都对了帧号，但音色好不好听要主人听。
- **最没把握**：第 0 帧缩到宽 360（手机信息流）时，「光绘」两个字和满天火星叠在一起。交片前做了第三轮：写字那一段的光点加粗 36%、功率加 50%（到光球之前平滑回到正常），火星压暗 25%——缩略图上字比之前清楚，但“读得出标题”仍是临界的；要不要再往“字更大、火星更少”推，请主人看缩略图定。
- 签名“观默”在片尾是一颗小光点连笔写出来的（f812—892），落在右侧钢丝棉圈里；最后一帧另有片尾署名行“每天一个设计风格 · 观默 @guanmo_ai”。
