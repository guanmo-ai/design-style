# 马克笔 · 从候选图到全片

2026-11-13。第八轮三个手绘候选（马克笔 / 沙画 / 水彩）主人说“三部一部一部做”，沙画先做（在分支 `claude/focused-lovelace-p3sy7e`）。这一期主人的话：“要顶尖的动效设计，节奏不能太慢，对设计师有帮助，第一目的是推特爆款”；做到一半补了一句：“BGM 和音效也要做好……在这个项目一定要限制好”——已写进 `docs/DESIGN_NOTES.md` 必须守的第 5 条。

沙画 v1 的教训一起带着：“整个背景居然都是不变的”“BGM 非常差，甚至还有噪音的感觉”。

## 先想的三件事

1. **马克笔自己怎么动：墨量 = 停留时间。** 渲染器（`film/ink.js`）不是画一条带子，而是让扁头沿路径**按时间**盖章：慢 → 章密 → 深、积墨；快 → 章稀 → 浅、露纤维；落笔前停 → 一团墨晕开。扁头角度固定，笔宽随走向变是自己出来的。一笔先画进遮罩（自己叠自己不变深），再 multiply 到纸上（两笔叠才深一档）。刚落下的墨更湿、有反光，十几帧里渗开、变干——笔走了墨还在动。
2. **接力：一张纸。** 第 0 帧是画完的整张（封面 = 速查卡），拔帽、倒放回白纸，再一笔笔画回来，最后扣帽。镜头骑着笔尖走、跟着设计师的习惯转纸；换章 = 换一支笔。
3. **设计师拿走：** 四条规则（一笔一层 · 白是留出来的 · 停得越久墨越深 · 最后一笔才是白）、试色条 ×1 ×2 ×3、真实的作画顺序。

## 这次没照默认骨架做的地方

- **没有代表作章、规则卡章、手机章。** 马克笔效果图本身就是“作品”，规则写在纸上、紧挨着它正在发生的那一笔；候选阶段画过车企官网 / 配置器，但 18 秒里塞手机会把“画画”这条主线切断，这次没放。
- **没用 kit 的舞台和 HUD**：平面风格，自己画；出字的声音照 `typefx` 的格式登记（`[帧, 字数, 每字帧数, 种类]`），配乐用 `song.text_cues`。
- **封面就是片尾**：首尾同一张画（不是必须，这一期顺手就有）。

## 节奏（主人：“节奏不能太慢”）

- 一笔 4—6 帧（0.07—0.1 秒），和十六分音符同一个格子；蓝底 18 笔一小节扫完。
- 18.5 秒里镜头没有停过：推、拉、跟笔、转纸（−7° 到 +4°）、宏观 3.2 倍、拉回全景。
- 第一版预览里蓝铅笔结构那一段（约 1.2 秒）大半是空白的纸，压到 0.65 秒；车“活过来”那一冲从 54 像素加到 120 像素、镜头“咚”加倍。

## 过程里改过的

| 问题 | 原因 | 改法 |
|---|---|---|
| 第一版正片第 757 帧单帧变化 26.6，勾线那一段镜头左右甩 | 镜头“跟着笔”，而针管笔在门缝、车灯、轮辐之间来回跳；之字形扫底色时镜头也跟着上下晃 | 跟笔分横向 / 纵向两个权重：之字形只跟前进的方向；勾线只跟那一笔绕车身的长线（锁定到这一笔，不跟后面的小笔）。量镜头：方向反转 62 次 → 2 次，最大加速度 111 → 13 |
| 蓝铅笔结构那 1.2 秒大半是白纸 | 6 根线各 6—16 帧 | 压到 4—11 帧，整片提前 25 帧 |
| 车“活过来”看不出来 | 往前冲 54 像素，在 1.4 倍镜头里不明显 | 120 像素 + 镜头“咚”加倍 + 速度线 8 → 11 道 |
| 积墨那一团是个方块 | 停顿时把扁头的章越盖越厚 | 停顿改成一团圆的墨往外渗（半径 ∝ √停顿帧数），扁头章只轻微变厚 |
| 蓝底穿过车身 | 候选图里蓝底是躲开车身的 | 蓝底裁在车身外面（evenodd），裁剪跟着车身一起动 |

## 配乐（必须守的第 5 条）

- 一整首歌：144 BPM，G — D — Em — C，底鼓 / 拍手 / 十六分闭镲 / 沙锤、八度贝斯、电钢琴反拍、四小节的主旋律（拨弦 + 马林巴 + 方波，最后两小节升八度），积墨那一下和扣帽前一小节鼓停。
- 每一笔一声“笔头擦纸”：**不是宽带噪声**——主体是一道调到当前和弦音（×4 泛音）的窄带，加一点高频纤维声和落笔的“嗒”，包络就是这一笔的速度曲线，压在鼓下面。
- 每个大动作一个声音：拔帽“啵” · 倒带（倒放的磁带停转 + 倒放镲 + 一笔笔倒着擦）· 第一拍全乐队 + 镲 · 换笔“嗖” · 积墨的和弦鼓起来 + 铃 · 批注箭头“嗖”上去 · 白点钢片琴往上走 · 引擎一轰 + 底鼓 + 镲 · 扣帽“咔哒” + G 大调全和弦。手写批注一个字一声。
- 新工具 `drafts/_lib/audiocheck.py`：和主人认可 / 否掉的片子并排量。

| 片子 | LUFS | 噪音感（频谱平坦度） | 高频占比 | 律动 |
|---|---|---|---|---|
| 毛绒（主人：好） | −14.1 | 0.007 | 0.004 | 0.26 |
| 新艺术运动（通过） | −14.4 | 0.046 | 0.041 | 0.30 |
| 沙画 v1（主人：“噪音的感觉”） | −13.9 | 0.058 | 0.040 | 0.16 |
| **马克笔** | −14.0 | 0.012 | 0.009 | 0.35 |

## 结果

`film/marker-film.mp4`：18.5 秒 · 1080p60 · 29 MB；封面 `film/cover.jpg`（第 0 帧）；联系表 `film/contact.jpg`（每 30 帧一张）。
`smooth.py`：跳变 0 · 死区 0 · 平均每帧变化 4.7 · 最大 17.7（毛绒是 19）。`audiocheck.py`：−14.0 LUFS、峰值 −0.5 dBFS、噪音感 0.011、律动 0.39（拍长 0.83 秒 = 两拍）、无空洞。

## 没做 / 没验证

- 看的是静帧、连续帧和联系表，没看过播放；配乐只核对了数字（上表），**没听过**——擦纸声的质感、旋律好不好记，要主人听。
- 只有 16:9 横版；抖音竖版没做（沙画那一期提过的束缚，仍然成立）。
- 网页 / App 的落地没进片子（候选图 `png/ui.png` 有）。


## v2：主人看完 v1 后重做（2026-11-13）

主人：“还可以，但是你这个动效好像有点一般……全部就只有这一个东西吗？……那一些界面呢？一些网页呢？……18 秒就介绍这一个东西，有点太普通了……我要推的爆款……一些顶尖的动效你没有做出来，而且全篇就这一个东西，有点枯燥。”

**为什么 v1 普通（复盘）：** 18 秒只有一张纸、一辆车，镜头再怎么动，画面的“内容”只有一种；规则写在纸上，但没有一个“大到吓人”的动作；界面完全没出现，设计师看完不知道这个风格落到产品里是什么样。

**v2 改了什么：**
- 一支笔走三个地方：纸（概念车）→ 网页（官网首页 + 四件产品的卡片）→ 手机（配置器，换色 = 换一支笔重画）。五样东西：车、运动鞋、耳机、躺椅、台灯。
- 换站是**巨笔**：放大 3.4 倍的马克笔扫出一道 820 宽的颜色，镜头骑着它走，设备落到这道颜色上。两道巨笔交叉 = 规则 ①，白色巨笔 = 规则 ④。
- 界面里的动作都是马克笔自己的：首页手稿 8 倍速回放、按钮是一笔色块、长按 = 笔停在纸上（墨一圈圈渗开，规则 ③）、四张卡片同时画、进度条一笔画满、开关打开 = 结构线画上去。
- 更快：18.5 → 13.5 秒，一笔 0.4—1.5 帧（回放）到 3 帧（纸上）；手机段从 4 秒压到 3 秒（四种颜色减到三种，镜头把手机放到画面中间）。
- 配乐：同一首 144 BPM 的歌，加了巨笔（风 + 低音擦纸 + 小节线上的镲 + 底鼓）、设备落地“咚”、长按时鼓停和弦鼓起来、点击、卡片滑走、开关、进度条；同一个十六分音符格子里的多笔只出一声。

**过程里修的：** 页面最后的 `</script>` 丢了（页面不报错、直接不初始化）；卡片组名写死成 `card3`，删掉一种颜色后找不到组；浏览器落地后空白了 15 帧（首页大字和回放提前）；标题最后一个 R 没写完镜头就走了（镜头多停两拍）。

**v2 结果：** `film/marker-film.mp4`，13.5 秒 · 1080p60 · 15 MB；`smooth.py` 跳变 0 · 死区 0 · 最大 22.5（第 650 帧，白色巨笔扫到小节线那一下，有意的重拍）；`audiocheck.py` −14.1 LUFS、峰值 −0.3、噪音感 0.008（毛绒 0.007）、律动 0.26、无空洞。仍然没听过、没看过播放。


## v3：六个场景（2026-11-13）

主人看完 v2：“确实好一些了，但没有惊艳到我，是不是还有其他场景呢？你可以做到 20 秒内……我不是很喜欢只有一个场景的地方，感觉什么都没有。我要的是顶尖哎，你觉得这能算顶尖吗？”

**Claude 的回答：不算。** v2 从头到尾是同一张米色桌面，三站之间大片是空桌子；巨笔和设备落地都发生在画面边上，没有一个动作是占满整个画面的。

**v3 改了什么：**
- 六个场景，各有底色、主角、构图、镜头：暗的工作室（汽车）→ 青（球鞋）→ 牛皮纸（建筑两点透视）→ 紫（官网）→ 黄（App）→ 橙（海报）。
- 换场 = 一组铺满屏幕的巨笔，颜色就是下一个场景的底色；扫完以后布景带着弹簧从画外进来（先测出来的问题：布景一帧出现，`smooth.py` 量到 160 的跳变）。
- 新加的两样：球鞋（规则 ③：笔停在鞋头上墨晕开）、建筑（规则 ①：同一支灰笔一遍 / 两遍 / 三遍，标在楼的三个面上）。
- 片尾海报 = 封面：整屏扁头大字、白色高光、四条规则写全。
- 19.3 秒（主人：“20 秒内”）。

**过程里修的：** 建筑那一场画不完、压到了下一场（加了“整体按比例压快”，镜头关键帧一起缩）；球鞋的轮廓像车顶（改成鞋头低、后跟领口高、厚中底）；手机两边的色块是方块像故障（改成三道长笔）；海报的白色高光是整根竖线（改成短的一笔）；署名被躺着的笔挡住（挪到副标题那一行）。

**v3 结果：** `film/marker-film.mp4`，19.3 秒 · 1080p60 · 20 MB。`smooth.py`：死区 0；换场那一帧的硬切已经没有了（第一次全片在 50 / 400 帧量到 35 和 160，原因是巨笔有纤维纹、没完全盖住上一个场景，扫完那一帧上一个场景突然消失 → 扫完前 8 帧新底色从下面透上来）。剩下的 25 处“跳变”都在巨笔扫过的那十几帧里（一道 760 宽的笔几帧盖住三分之一屏幕，有意的重拍）和片尾笔飞回来；最大 28（毛绒 19）。`audiocheck.py`：−13.9 LUFS、峰值 −0.1、噪音感 0.007（和毛绒一样）、律动 0.31、无空洞。仍然没听过、没看过播放。
