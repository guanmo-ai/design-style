| 方向 | 图 | 怎么做的 |
|---|---|---|
| A · 从纸上站起来 | `png/A-popup.jpg` | `grab.cjs` 从 `../film/film.html` 渲出纸上的车（分开渲：蓝底 + 铅笔 / 车 / 地上的影子）→ `a_popup.py`：车的轮廓做距离场 → 鼓起来的高度 → 法线 + 打光（漫反射、高光、轮廓光、贴地处暗一点）→ 整辆车抬起 150 像素、车头翘 5.5°，纸上留下蓝底和铅笔线，影子落在纸上越远越虚 |
