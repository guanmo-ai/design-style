# 马克笔 Marker · 分镜（全片 18.5 秒）

1920×1080 · 60fps · 144 BPM（一拍 = 25 帧，一小节 = 100 帧，第一小节的重拍在第 50 帧）· 1110 帧。
画面 `film.html`（镜头、笔、批注、HUD、运动模糊）+ `ink.js`（墨迹渲染器）+ `board.js`（整张纸上的 140 笔和它们的时间），配乐 `audio.py`。
出片：`bash make.sh`（云端约 20 分钟）；预览 `PREVIEW=1 bash make.sh`（约 4 分钟）。

## 开工前想的三件事

1. **马克笔自己怎么动？** 墨量 = 笔头停留的时间。扁头沿路径按“时间”盖章，不按距离：走得慢的地方盖得密 → 深、积墨；快的地方稀 → 浅、露出纤维纹；落笔前停一下 → 起笔一团墨，停得越久越大。扁头在纸上的角度固定，所以“横着宽、竖着窄”是盖出来的，不是写进去的。墨落下以后还在动：刚落的那一截更湿（深一点、有一道反光），十几帧里往外渗开、反光退掉——笔走了，墨还没停（对应毛绒的“身体停了毛没停”）。
2. **什么东西接力到底？** 一张纸。第 0 帧是画完的整张（就是封面），拔帽、整张倒放回白纸；之后镜头骑着笔尖把同一张纸重新画一遍；最后拉回全景，扣上笔帽——最后一帧和第 0 帧是同一张画。章节之间不切：换章 = 换一支笔（上一支从右下角飞走，下一支飞进来），镜头跟着笔走、转纸（设计师画的时候会转纸）。
3. **设计师能拿走什么？** 四条规则写在纸上，每条旁边就是它正在发生的那一笔：① 一笔一层、叠一遍深一档（试色条 ×1 ×2 ×3，正片叠底）② 白是留出来的 ③ 停得越久墨越深 ④ 最后一笔才是白。外加真实的作画顺序：蓝铅笔结构 → 底色 → 车身三遍 → 玻璃轮胎影子 → 针管笔勾线 → 白。

**没按默认骨架：** 没有代表作章、没有规则卡、没有手机章。原因见 `../PROCESS.md`。

## 每一项是怎么保证丝滑的

- 笔的位置：画的时候 = 笔尖；两笔之间按“上一笔的末速度 → 下一笔的初速度”做三次 Hermite 插值，速度连续，抬起的高度随距离变（影子跟着分开）。
- 镜头：关键帧（可以跟着某支笔，往前看 6 帧）之间用 smootherstep，再用 σ = 7 帧的高斯核磨平；缩放按对数走。
- 倒放：纸上“画到哪”的时间 τ(f) 用 smootherstep 从“画完”回到 0，所以收回去是先慢、后快、再慢下来接上第一笔。
- 车一冲：位移 = u²·e^{2(1−u)}（从 0 起步、速度连续）减一个小的回弹；俯仰角跟着加速度走。
- 运动模糊：每帧 3 个子帧（快门 180°）。
