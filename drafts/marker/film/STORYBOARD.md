# 马克笔 Marker v3 · 分镜（全片 19.3 秒，六个场景）

1920×1080 · 60fps · 144 BPM（一拍 = 25 帧，一小节 = 100 帧，第一小节的重拍在第 50 帧）· 1160 帧。
画面 `film.html`（场景合成、换场、镜头、笔、界面、批注、HUD、运动模糊）+ `ink.js`（墨迹渲染器）+ `gen.js`（笔画生成器：字母、车、产品）+ `scenes.js`（六个场景各自的笔画、布景和镜头），配乐 `audio.py`。
出片：`bash make.sh`；预览 `PREVIEW=1 bash make.sh`。v1（一辆车）、v2（一张桌面）见 git 历史。

## v3 想的三件事

1. **马克笔自己怎么动**（沿用）：墨量 = 停留时间。慢 = 深、停 = 积墨、横宽竖窄、刚落的墨渗开反光退掉。
2. **接力：一支笔，六个场景。** 每个场景有自己的底色、主角、构图和镜头。换场景 = 一组铺满屏幕的巨笔（6 道、每道 760 宽，放大 4.6 倍的笔扫过去），**这组巨笔的颜色就是下一个场景的底色**——底色本身就是马克笔扫出来的，看得见纤维纹。扫完以后纸 / 卡片 / 浏览器 / 手机带着弹簧从画外进来。
3. **设计师拿走：** 四条规则各长在一个场景里（② ④ 汽车、③ 球鞋、① 建筑、④ 海报），外加马克笔在五种用途里的样子：汽车效果图、产品（球鞋）、建筑透视、官网、App；片尾海报把四条规则列在一起（也是封面）。

## 丝滑

- 换场的硬切藏在巨笔后面：巨笔铺满屏幕的那一帧才换场景，新场景的布景从画外弹进来，不是一帧出现。
- 每个场景的镜头：关键帧 → smootherstep → σ = 7 帧高斯；缩放按对数走。
- 场景内容画不完时整体按比例压快（球鞋 0.86、建筑 0.57、App 0.83），保证最后一笔在下一组巨笔开扫前 10 帧画完。
