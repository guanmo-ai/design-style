# 马克笔 Marker v2 · 分镜（全片 13.5 秒）

1920×1080 · 60fps · 144 BPM（一拍 = 25 帧，一小节 = 100 帧，第一小节的重拍在第 50 帧）· 810 帧。
画面 `film.html`（镜头、设备、界面、笔、批注、HUD、运动模糊）+ `ink.js`（墨迹渲染器）+ `board.js`（整张桌面上的 525 笔：车、四件产品、字母、巨笔，和它们的时间），配乐 `audio.py`。
出片：`bash make.sh`；预览 `PREVIEW=1 bash make.sh`。v1（18.5 秒、只有一辆车）见 git 历史 `02e774e`。

## v2 想的三件事

1. **马克笔自己怎么动**（沿用 v1）：墨量 = 停留时间。慢 = 深、停 = 积墨、横宽竖窄、刚落的墨渗开反光退掉。
2. **接力：一支笔，三个地方。** 纸 → 网页 → 手机，每一站之间是一道**巨笔**：一支放大 3.4 倍的马克笔在桌面上扫过一道 820 宽的颜色，镜头骑着笔尖走，下一台设备“咚”地落到这道颜色上。两道巨笔交叉的地方深一档——规则 ① 放大到整个画面；最后一道是白色的巨笔——规则 ④ 放大到整个画面。
3. **设计师拿走：** 四条规则，每条都长在它正在发生的那个东西上（① 两道巨笔的交叉 + 试色条 ×1 ×2 ×3；② 车身肩线下的留白；③ 网页按钮长按 = 笔停在纸上；④ 白色巨笔）；以及马克笔风格在网页和 App 里实际怎么用：手稿当首页大图并回放、按钮是一笔色块、卡片里的产品手稿、换色 = 换一支笔重画、进度条是一笔画满。

## 丝滑

- 笔：两笔之间按末速度 → 初速度做三次 Hermite；间隔超过 40 帧先离场再回来。巨笔的笔也一样，只是放大 3.4 倍。
- 镜头：关键帧（可以跟着某支笔）→ smootherstep → σ = 7 帧高斯磨平；缩放按对数走。巨笔落到小节线时、设备落地时镜头往下“咚”一下（单向，7 帧衰减）。
- 设备落地：弹簧（ζ 0.5），从上方 90 单位、0.86 倍落下来，过冲约 5%；设备里的笔画和界面跟着设备的变换一起动、一起裁剪。
- 手机换色：旧卡片和新卡片按 smootherstep 同时滑，14 帧。
