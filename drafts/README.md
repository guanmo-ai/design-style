## 超级平面第二版 · 第一步：参考 + 三个构图小样（2026-11-18）

主人看完第十二轮后同意“只做一个、先磨一帧”的做法：先给参考板和 3 个构图小样，挑一个再精修。方向写在 [`supergraphics/DIRECTION.md`](supergraphics/DIRECTION.md)：拿第一版和 Georges Rousse、Felice Varini、Sea Ranch 的真实作品并排看，差在空间是假的（干净 CG 白盒）、东西太多、光是平的、构图是摆的。

- 换成 **Blender Cycles 路径追踪**（`pip install bpy`，5.3）+ ambientCG / Poly Haven 的 CC0 实拍材质和天空（`supergraphics/blender/fetch_assets.sh`，素材不入库）。
- 漆用镜头的画面坐标算遮罩：从这个机位看是完美的形状，同时保留墙面的凹凸，被光照、被遮挡。
- **实测**：960×540、32 采样 + 降噪约 30—40 秒一帧，64 采样约 58 秒；1080p 估计 2—4 分钟一帧。出静帧够；做片子要把光烘焙进场景再动镜头，或者交给有显卡的机器。
- 三个小样（`supergraphics/png/v2/comps.jpg`）：A 厂房纵深 + 一个红色正圆（门洞是圆心，人站在里面）；B 混凝土中庭仰视 + 四色同心环；C 厂房 + 四个黄字。

新艺术运动的候选图见 `art-nouveau/png/`，短片以连续生长的鞭线组织画面。

- **画面** `art-nouveau/film/`：**整支片子只有一根线。** 它从标题拱的左脚出发，顺时针绕一圈——鞭线（曲率梳）→ 穆夏的光环 → 吉马德的地铁口（黄昏，灯亮）→ 蒂芙尼的台灯（夜里，玻璃一块块嵌进去，灯亮）→ 手机机身和界面（三条规则 + 色板）——再回到标题脚下卷进去；片尾拉远，整支片子就是一根鞭线。分镜见 [`art-nouveau/film/STORYBOARD.md`](art-nouveau/film/STORYBOARD.md)，过程见 [`art-nouveau/PROCESS.md`](art-nouveau/PROCESS.md)。

## 第七轮：毛绒 Plush 全片（2026-11-10，未占期号）

全片为 20 秒、1080p60，使用一首连续的配乐。

- **画面** `plush/film/`：从头到尾同一批 409,600 根毛——毛球砸下来 → 炸开拼成「毛绒」→ 缩回去只剩一根，再 ×8、×8…… 长回四十万根 → 奥本海姆《皮毛早餐》（1936）→ Steiff 泰迪熊（1902，九个零件“啵”出来）→ Kangol 毛毛渔夫帽（抛起来翻一圈）→ 五条规则（同一颗球自己演示：根深尖浅 / 乱一点 / 逆光镶边 / 慢半拍 / 一按就倒）→ 倒进手机（点赞、开关、加载）→ 拼回「毛绒」。分镜见 [`plush/film/STORYBOARD.md`](plush/film/STORYBOARD.md)。
- **签名物理**：每根毛是一根弹簧，毛尖 = 身体的运动 ⊗ 弹簧的冲激响应。零件只管自己动，毛的“晚半拍、冲过头、抖回来”是算出来的，不是一根根 K 的。
- **渲染器** `_lib/fur/fur.js` + `_lib/kit/shapes.js`（2026-11-11 起，通用的部分拆进了 [`_lib/kit/`](_lib/kit/README.md)）：真的一根根画（每根一条带锥度的细带，Kajiya–Kay 光照，成撮，逆光镶边），云端软件渲染 3.8 秒 / 帧。踩的坑写进了 [`docs/GPU_MOTION.md`](../docs/GPU_MOTION.md)。
- **可以摸的 demo** `plush/demo.html`：有显卡的电脑直接打开，鼠标拨毛、拖着甩，四个滑块对应四条规则。
- 和前几期不一样的地方：布景没有用“黑场 + 聚光灯”，换成了糖果色无缝背景（毛绒要的是软和亮）；色彩接力是粉 / 蓝 → 驼 / 绿 → 金 / 紫 → 荧光绿 / 洋红 → 奶油白。

成片：[毛绒](plush/film/plush-film.mp4)。四张风格图、tokens、时间轴与中英文阅读页见 [正式目录](../styles/025-plush/README.md)，网站期号为「风格 018」。

**推荐：赛博朋克。** 第一帧最有电影感（霓虹、雨、倒影，正对 015 总结的“开头往电影感靠、主角要大要亮”），推特上最容易停住手指；代表作横跨电影、动画、游戏、城市、穿搭、界面，一章一个领域很好排。要守住一条：故障撕裂只在重拍上出现，不能一直抖。

**其次膨胀风。** 最“当下”、最轻松可爱，充气滤镜能直接给设计师拿走；但代表作偏新，历史纵深不如前两个。**城市流行**画面最好看、配乐最好做（80 年代日系 funk），但动作偏慢，要靠视差和水花撑住“惊艳”。

## 欧普艺术 Op Art（1955—1970）· `op-art/`

| 海报 | 速查卡 | App 概念 |
|:-:|:-:|:-:|
| <img src="op-art/images/preview/poster.svg" width="260" alt="海报" /> | <img src="op-art/images/preview/cheatsheet.svg" width="260" alt="速查卡" /> | <img src="op-art/images/preview/app-ui.svg" width="260" alt="App 概念" /> |

- **一句话：** 看久了，它就会动——只改一个参数（线宽、间距、相位），平面就鼓起来、流起来。
- **对设计师有用的地方：** 五种带参数的方法，可迁移到品牌图形、动态 logo、加载动画和图案：线宽调制 · 网格扭曲 `r′ = r·(1 + a(1 − r²/R²)²)` · 摩尔纹 · 相位错位 · 同明度对比（红 `#E5322D` × 青 `#008C7E`，相对亮度都 ≈ 0.19）。
- **色板：** 黑 `#0B0B0B` · 白 `#F3F1EB`（黑白 90%）· 红 / 青只成对出现
- **字：** Archivo 900（wdth 108—125）· Space Mono · Monoton（点缀）· Noto Sans SC
- **动效设想（15 秒）：** 白屏里条纹出现，标题靠相位错开显形 → 整片条纹像 Riley《Current》一样流动 → 平的棋盘被一个参数推成一颗球（Vega）并转动 → 两组同心圆滑过、流出摩尔纹 → 等宽线靠线宽调制转成圆柱 → 同明度红青“颤”一下收尾。全片不搬形状，只改参数。
- **安全线：** 每秒闪烁 ≤ 3 次（WCAG 2.3.1）；大面积高频条纹不要剧烈运动；提供减少动态效果的静帧版本。

## 1-bit 抖动像素 Dither（1984—今天）· `dither/`

| 海报 | 速查卡 | App 概念 |
|:-:|:-:|:-:|
| <img src="dither/images/preview/poster.svg" width="260" alt="海报" /> | <img src="dither/images/preview/cheatsheet.svg" width="260" alt="速查卡" /> | <img src="dither/images/preview/app-ui.svg" width="260" alt="App 概念" /> |

- **一句话：** 只有黑和白；灰，是点的密度。
- **对设计师有用的地方：** 4×4 拜耳的十七级灰（第 n 级点亮阈值 < n 的格子）、一行公式 `ink = luma < (bayer[y%4][x%4] + 0.5) / 16`、同一颗球四种算法对比（阈值 / 拜耳 1973 / Floyd–Steinberg 1976 / Atkinson 1984）、两色主题（纸墨 · 掌机 · 磷光 · 蓝晒）、阴影 = 50% 棋盘格。
- **色板：** 墨 `#1B1A17` · 纸 `#E8E3D3`（全片只有这两种）
- **字：** Silkscreen（像素标题，按 8px 原生尺寸的整数倍放大）· Space Mono · Noto Sans SC（大号中文在 `make_svgs.py` 里现场栅格化成点阵）
- **动效设想：** 一镜到底钻进一个像素：格子从 8px 长到满屏，途中亮出每格的阈值；被推近的那一格里是缩小 240 倍的整张画，推到底正好回到第 0 帧，无缝循环。光绕球转一圈，点阵一直在“爬”。所有渐显都用拜耳溶解，不用半透明。
