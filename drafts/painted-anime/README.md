# 水粉背景（吉卜力式的手绘背景画风）· 候选图（2026-11-11）

主人：“我希望的是一些成熟院线的画风，或者大家比较喜欢的画风，能够做好视频、顶尖的视频的……比如吉卜力风格，你去试一试，把吉卜力风格做出来。”

这里提取的是**画法**——日本动画电影里手绘水粉背景的那一套：饱和的蓝天、顶到画框的积雨云、一笔一笔铺出来的草和树、亮面暖暗面冷。景是原创的，**没有用任何一部片子的角色、镜头或构图**（必须守的第 7 条）。

| [B · 黄昏的站牌](images/dusk.jpg) | 同一套画法，只换光：太阳在海平面下，云从下面被照成金和粉，暗面是紫的；近处全是剪影，只有一盏灯是暖的 |

**还没做片子，等主人看图。**

## 怎么出图

```bash
node drafts/painted-anime/render.cjs summer dusk   # → images/<场景名>.jpg，1920×1080，一张 5—7 秒
```

## 文件

- `paint.js`：画法。`brush` 一笔（几根并排的鬃毛线）/ `wash` 按颜色函数铺满一块 / `lobes` + `paintLobes` 一堆球各自带亮面暗面（云、树）/ `grass` 一根根的草 / `block` 平涂色块再扫几笔 / `ramp` 色阶。
- `scenes/summer.js`、`scenes/dusk.js`：两张图。
- 用到 `../hand-drawn/lib.js` 里的噪声、折线、纸纹。

制作过程和数字见 [`PROCESS.md`](PROCESS.md)。
