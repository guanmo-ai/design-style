# 新浪潮 New Wave Typography · 制作过程

## 主人怎么说的

- 2026-11-17：先选新浪潮，“做的顶尖一点”“全球最顶尖的动效，快节奏的，要多个场景切换。BGM 也要顶尖”。
- 第一版出来后：“BGM 好像有噪音啊”，要一段提示词去用 AI 生成。Claude 先给了合成器流行、预告片大片感两套，主人：“不是很喜欢这个风格”“大片感……有点完全不符合这个影片了吧”。回到画面重新想（每拍一个动作 → 音头要干脆；片子是一层层叠的 → 音乐也由几条短的节奏型叠起来；套印错位 → 两条节奏型错开再对齐；纸白配三原色 → 要亮），给了“极简主义钢琴脉冲”的提示词。
- 主人生成了两首（Minimalist Design Pulse、Precise Geometric Phasing），“你自己选一个合适的吧，然后去把它做好”。

## 从一个词到成片

1. **风格图先行**：第九轮候选做了三张风格图（黏土风 / 达达 / 新浪潮），新浪潮那张（`png/cover.png`，`cover.py`）就是片子的第 0 帧和最后的收束画面。
2. **先定“它自己怎么动”**：新浪潮的东西都是灯箱上的胶片，只会被推（弹簧）、被叠（乘法）、被错开（套印、台阶、字距）。全片只用这一条物理，转场也是：新的一张片子推进来、网点长大连成黑、线网扫过去、镜头穿过圆片 / 字怀 / 一颗网点。写在 `film/STORYBOARD.md`。
3. **骨架这次没用**：没有“代表作一章一件 + 规则卡 + 手机章”。主人要快节奏、多场景，所以五条规则每条就是一场，用动作演出来（叠、台阶、字距、网格、网点），“用起来”是六个一拍一换的版式蒙太奇（海报、唱片、杂志、App、网页、票）。
4. **技术路线**：Canvas 2D（平面风格，不用舞台），`render(ctx, f)` 是帧号的纯函数；快的甩、推、冲加运动模糊（同一帧在快门内渲 3—16 个子帧取平均，见 `scenes.js` 末尾的 `BLUR`）。实测约 0.05 秒 / 帧，1200 帧一分钟渲完，所以画质不用妥协。
5. **审片顺序**：抽样帧 → 全片低密度联系表（每 15 帧）→ 转场的连续帧（每 3—4 帧）→ 第 0 帧全质量 → 正片。

## 审片里改掉的

| 看到的问题 | 改法 |
|---|---|
| 第 0 帧小字还在“解码”，封面不完整 | 封面里的字提前到第 −60 帧开始（第 0 帧已全在，不出声） |
| 冲进圆片、钻进字怀、推场时运动模糊是一层层的残影 | 这几处子帧加到 14—16 |
| “叠”那一场黄三角太高，三层叠出一大块黑 | 三角往下挪，三层叠的部分只剩一小块 |
| 冲进圆片的那几帧圆里只有一片青（S1 的片子还没进来）；缩小的 S1 露出边 | 第一张片子提前到圆还在放大时就甩进来；S1 先铺满纸再缩放；片子的起点挪到更远的屏外 |
| 字距 +800 时 W 被切出画面 | 改成 +700，最后一下弹簧阻尼加大 |
| 收束只是封面再放一遍，不像高潮 | 加“套准”：整幅画面像三块没对准的印版（RGB 各偏一点），NEW 砸下时偏得最多，“新浪潮”那一拍咔地对准；最后品红条砸下，一圈品红网点从署名冲出去 |
| 封面和收束有一秒多画面偏静 | 胶片每两拍被轻推一下（冲激响应），跟着鼓 |
| 蒙太奇 12 帧一推，`smooth.py` 报 30 处跳变 | 放宽到 16 帧（仍卡在拍点上），跳变降到 16 处 |

## 第二版：画面排到音乐上

选了 **Minimalist Design Pulse**：段落最清楚——0—3.7 秒钢琴前奏、第 8 拍节拍整个进来、第 24 拍换段、第 39 拍最后一击、余音到 20 秒；另一首段落不分明，最后一下在 18.5 秒以后，留给署名的时间太短。

量法（librosa）：音头的峰在 ¼ 拍网格上拟合，一拍 0.4613 秒（130.07 BPM，27.678 帧），第 0 拍在 0.066 秒，残差中位 4 毫秒；调性 D 大调。
不动音乐，动画面：`timeline.js` 里每个时间点都改成“第几拍”换算出来的帧（`FB(b) = 3.96 + 27.678 b`），场景里写死的帧号也都换成按拍算。几个对上的点：b8 推到“台阶” = 节拍进来；b24 网点连成黑 = 换段；b36 NEW 砸下；b39 品红条砸在署名下 = 最后一击。S1 少了一拍、S4 多了一拍，收束提前两拍，最后 2 秒是余音，镜头慢慢推近 3.5%（不留死区）。

音效全部重做（`audio.py`）：调好音的 D 大调短音，几乎不用噪声；“气声”里的噪声压到原来的三分之一，主要靠滑音。成片音轨的 RMS 和原曲几乎一样（0.1495 / 0.147），音效在音乐下面。

第二版量出来：1200 帧 · 死区 0 段 · 跳变 15 处，全在拍点转场上（221—225 = b8 推进，371 = 钻出 O，409 = 字距撑开，658—662 = b24 连成黑，889 = 蒙太奇推进，970—972 = b35 推进）。

## 第一版的配乐（已不用）

`film/audio.py`：80 年代新浪潮合成器流行（和这个风格同年代、同名）。128.57 BPM，一拍正好 28 帧。A 小调，Am – F – C – G 每两拍换一个。门限混响的军鼓（自己写的 `gated_snare`）、十六分八度贝斯、方波琶音（开头四拍滤波慢慢打开）、锯齿铺底、主旋律八拍一句（E E D C · A C D E · G G D），04—05 场主旋律让给音效。

音效跟着画面：片子甩进来“唰”、叠出颜色一个和弦音、十个字落台阶一级一个下行音、字距一开一合的滑音、块吸到栏线“咔”、b24 一拍空 + 低频“嗡”、收束倒放镲 → 砸字 → 最后一个大和弦。屏幕上每次出字都有一声（`events.json`，来自页面登记）。

响度 −14 LUFS；频段分布和毛绒那一期的配乐接近（略亮）。**Claude 听不了声音，只核对了时长、响度、频谱和音量曲线；好不好听要主人听。**
