# 新浪潮 New Wave Typography · 分镜

20 秒（1200 帧 @60）· 1920×1080 · Canvas 2D（平面风格，不用舞台）

> 第二版（2026-11-17）：配乐换成主人用 AI 生成的 Minimalist Design Pulse（D 大调 · 130.07 BPM · 一拍 27.678 帧，第 0 拍在第 3.96 帧）。下面的拍号都按这张网格：帧 = 3.96 + 27.678 × 拍（`timeline.js` 里的 `FB(b)`）。第一版是 128.57 BPM、一拍 28 帧。

## 先想三件事

1. **这种风格自己会怎么动？**
   新浪潮的东西都是**灯箱上的胶片**：一层层半透明的色片、网点片、线网片、照排的字。它们只会做三件事——
   **滑**（胶片在灯箱上被推过去，带惯性、冲过头、回来）、**叠**（两张片子重叠的地方乘出第三种颜色）、**错**（套印没对准、字往下走一级台阶、字距被撑开）。
   全片的物理只有这一条：*所有东西都是一张片子，被推、被叠、被错开。* 转场也是：下一场是一张新片子滑进来盖住上一张，或者网点长大连成一片、再缩小露出下一张。
2. **什么东西从头接力到尾？**
   12 栏的瑞士网格（160 px 一栏）从第 0 帧到最后一帧都在，每一场的东西都吸在它的线上；三张胶片（品红、青、黄）每一场都换个形状再出现；转场全部是“穿过去”（穿过青色圆片、穿过字母 O 的字怀、退出一颗网点），没有直切。
3. **设计师能拿走什么？**（全是能写成数的）
   - 叠：乘法叠色。M `#EC1C8C` × C `#12A8D8` = `#11127A`；M × Y `#FFD21F` = `#EC1711`；C × Y = `#128A1A`
   - 台阶：每一级下降 ¼ 字高
   - 字距：−150 ↔ +700（1/1000 em，同一个词两种极端）
   - 网格：打碎，但每一块的边都还对得上一根栏线
   - 网点：半径 r = 0.58 · 网格 · √深浅，网格转 45°
   - 用起来的样子：海报、唱片封面、杂志跨页、App、网页、票

这次没按“代表作一章一件 + 规则卡 + 手机章”的骨架：主人要快节奏、多场景，所以五条规则每条就是一场（用动作演出来，不是卡片），“用起来”是六个一拍一换的蒙太奇。

## 声音

第二版：主体是 AI 生成的 Minimalist Design Pulse（两架钢琴交错的极简脉冲 + 干净的电子节拍，本身就是“叠”和“错位”）。画面排在它的拍子网格上，不剪、不拉伸音乐；上面只加很轻的、调好音的 D 大调音效（出字轻点、台阶木琴、叠色钟琴、砸下低频），几乎不用噪声。
