# 生成艺术 Generative Art · 分镜（开头 8 秒小样）

1920×1080 · 60fps · 120 BPM（一拍 = 30 帧）· 480 帧。全片一条物理规则：**色带只顺着风走，碰到别人就停**。
画面：`film.html`（Canvas 2D 流场 + 占用网格，纯 CPU）；时间轴：`timeline.js`；配乐：`audio.py`（读同一份时间轴 + `events.json`）。

**画在弹琴**：每条色带出生 = 一个木琴音，音高由它在画面上的高度决定（越靠上越高），按 16 分音符对齐、只用 C 大调五声——音乐和画是同一套规则生成的。

| 帧 | 拍 | 画面 | 独有动作 | 声音 |
|---|---|---|---|---|
| 0—90 | 1—3 | 第 0 帧：生长前沿已推到画面中间，几百条色带同时往右长，粗的带着笔头和虚线（接下来要走的路） | 前沿从左往右推满画面，每条按自己的风向弯 | 木琴“画在弹琴” + 拨弦反拍 + 律动鼓组 |
| 90—180 | 4—6 | 规则 1：**顺着风走** `angle = noise(x, y) × 2π`。色带退成淡色，方向场的箭头一片片翻出来 | 箭头从斜对角一波波弹出、转到自己的方向；一个红点被放下，顺着箭头走出一条线 | 箭头翻出来是一串由低到高的细碎“嗒”；红点每走一段一个木琴音往上爬 + 上滑音 |
| 180—270 | 7—9 | 规则 2：**碰到别人，就停下** `gap = 5px`。镜头推近一条被挡住的粗色带 | 它先缩回去，再带着安全距离圈长回来，撞到前面那条时停住：头被压扁、抖两下，挡路的那条描边闪一下，弹出 STOP | 缩回的下滑音 → 生长的上滑音 → 撞停“咚” + 回弹的“啵嗡” |
| 270—390 | 10—13 | 规则 3：**大的先长，小的补缝** `sort(by: width)`。全部收回，再按粗细分三批长回来 | 每条从中点往两头长；第一批只有几条粗的（慢），第二批中号，第三批细线一下填满缝（啪） | 粗的低音、细的高音，越来越密；最后一拍上扬 |
| 390—440 | 14—15 | **换一个种子**：黄色卡片上 `0x2A7F` 的数字滚成 `0x80A1` | 整张画倒带收回（右边先收），停半拍，新的一张从中心炸开（蓝黑白） | 数字滚动的“嗒嗒”，磁带停转，空半拍，重拍 + 冲击 |
| 440—480 | 15—16 | 标题卡弹进来：**生成艺术 / GENERATIVE ART / 不画画，写规则。** 署名“观默” | 卡片带一点倾斜回正 | 和弦 + 一串钟琴 |

## 全片（开头通过后再做，约 20 秒）

1. **规则 4 · 色板加权**：同一张流场换四套色板（数量就是权重条），一键切换；给设计师看“比例决定气质”。
2. **规则 5 · 同一个种子 = 同一张画**：左右两屏同一个种子同步长，完全一样；改一位数，右边整个变掉。
3. **落到界面**：流场生成器（拖滑块整张重长、历史缩略图）+ 钱包（每张卡的图案由种子现算，点“重新生成”色带重新长）。
4. **收尾**：卡片飞回画布，画面收成第 0 帧的生长前沿，署名“观默”。
