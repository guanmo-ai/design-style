# 湿拓 Marbling · 任务书

短名 `marbling` · 分支 `claude/film-marbling` · 建议 90 BPM（一拍 40 帧）

**第 0 帧**：俯视一整盘颜色，**满画面出血**：左边大半盘已经梳成细密的羽纹（孔雀 / nonpareil），**一把梳子正拉到画面中间**，梳齿后面拖着刚成形的人字纹，梳子右边还是一圈圈没梳过的同心圆“靶子”。湿的反光。片名「湿拓」大字压在上面（像一张贴在盘上的纸签，缩到宽 360 要读得出）。一眼看到：颜色炸、细节密、有东西正在被拖动。

**只属于它的物理**：**颜色不混，只互相推开**——水面上的颜料是一层不可压缩的膜，每一个动作都保面积，而且都有闭式公式（Lu / Jaffer 等人的 mathematical marbling）：
- 滴一滴（圆心 C、半径 r）：`P′ = C + (P − C)·√(1 + r² / |P − C|²)`。面积匀速流出，所以 **r ∝ √t**（开头快、后面慢，不用另设缓动）。
- 划一道（过点 A、方向 M、法线 N）：`P′ = P + z·u^d·M`，`d = |(P − A)·N|`；z 是拖多远，u（0—1）是带动范围。梳子 = 等距的很多道。
- 还可以有：绕一点的漩涡、波浪线。
每个动作都能精确求逆，所以画法是**倒着查**：对每个像素，把动作表从后往前逆变换回去，落在哪一滴里就是哪个颜色。副产品：**放大多少倍边缘都是锐的**——可以把镜头连续推进一根羽纹里 20 倍，里面还有细节。

**接力**：从头到尾同一盘颜色。建议的弧线（可以改）：第 0 帧是梳到一半的成品 → 梳完，一张纸盖下去、揭起来，颜色被纸带走，盘里只剩清水 → 从第一滴重新来：滴、滴、滴（一圈推一圈，每滴一个音，音高跟大小走）→ 来回耙 → 梳 → 一根针拉出几道卷 → 镜头推进羽纹深处再拉回 → 最后一张纸盖下去揭起来：这张纸就是成品（一张海报 / 一本书的环衬），上面是「湿拓 MARBLING」和“观默”。

**设计师能拿走的数**（标在画面上）：两条公式、r ∝ √t、动作的顺序（滴 → 耙 → 梳 → 卷）、梳齿间距、色板。色板建议：钴蓝 `#1F3FD8`、朱红 `#F0452B`、姜黄 `#F6B81A`、松石绿 `#19B5A5`、粉 `#FF7AA8`、墨 `#17140F`、奶白 `#F4EBDD`（水面底色）。

**渲染建议**：WebGL2 片元着色器，动作表传 uniform 数组（≤ 100 个动作），每像素倒着循环一遍；抗锯齿用 2×2 超采样或按逆变换的导数做解析边缘。**先量一帧多少秒**（SwiftShader，见 `docs/GPU_MOTION.md`），太慢就降内部分辨率或减动作数。正在进行的动作要看得见“工具”：滴管落下的那一滴、梳齿、针尖（带一点水面的弯月形高光和影子）。梳子拉动是一个进行中的动作：位移沿拉的方向有一个前沿，不要整条线同时动。水面：一条很柔的高光带、轻微的颜料颗粒；纸：纸纹 + 揭起来时的弯曲和影子。

**配乐**：流动、松弛、原声——卡林巴 / 竖琴 + 水滴声；梳子拉过去是一串滑音（音高跟着梳子的位置走）；纸揭起来是一声很轻的“唰”。

**风险**：羽纹太细的地方压缩会糊，成片解码核对；“纸盖下去 → 清水”那一下画面会突然变空，要让它是一个连续的揭开动作，不要出现死区或整屏跳变。
