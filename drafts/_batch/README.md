# 一次做多支片子（2026-11-13 起）

主人 2026-11-13：要一次做 15 支全新风格的 15 秒片，目的是 **X 爆款、动效顶尖**；“第一帧是肯定要吸引人的”；token 要省，质量要保住。

**做法：一支片子一个云端会话，并行。** 总导演（开这一轮的那个会话）只做三件事：给每支片子写一页任务书、验收、把意见带进下一批。先做 3 支技术最不一样的先导片，主人看过之后再放另外 12 支——共用的东西（配乐骨架、外框、节奏）有通病的话，只赔 3 支。

## 先导批量到的事（排下一批之前先看）

- **瓶颈是用量，不是机器。** 3 个 Opus 会话 + 总导演同时跑，约一个半小时就用完了 5 小时额度，三支都停到额度恢复才接着做；一支片子的 Opus 用量大约是十几美元。一个额度窗口大约够 2—3 支，下一批要分窗口排，不能 12 支一起开。
- 会话撞上限会直接停住、不会自己恢复：额度恢复后要用 `send_message` 叫它接着做；任务书里要求“每到一个阶段就推一次”。
- `git fetch` 一次只拉一个分支（有一个分支还不存在，整条命令都会失败）。
- 仓库 `node_modules` 里的 Playwright 和预装的 Chromium 版本对不上，光绘用 `film/pw.cjs` 预加载绕开了；下一批直接抄它。

## 每支片子都一样的要求（任务书里没写的，按这里）

**目标**：X 爆款 → 动效顶尖 → 对设计师真的有帮助。底线是毛绒（`drafts/plush/film/plush-film.mp4`）。必须守的是 [`docs/DESIGN_NOTES.md`](../../docs/DESIGN_NOTES.md) 开头八条；做法见 skill `style-film`。

1. **第 0 帧先做。** 任务书第一段写的就是第 0 帧。先把这一帧单独做到全质量、自己看过（原图 + 宽 360 的缩略图），再写后面。片子从全片最抓人的那一刻开始，不从黑场、空舞台、淡入开始。
2. **只做一件事，做到头。** 任务书给了一条“只属于这种材料的物理”，全片的动作都从它推出来。**不做规则卡章、不做手机章**（除非任务书说要）；设计师要拿走的数，直接标在正在发生的画面上（小号等宽字 + 一根标注线），不单独开一章讲。
3. **同一批东西接力到尾，没有硬切。** 镜头从全景到特写也要连续推过去，不切。
4. **15—16 秒，1920×1080，60fps，一个速度。** 一拍的帧数取整数。每次出字都有声音；结尾一个动作 + 一个声音，最后一帧有片名和署名“观默”。
5. **每 1.5—2 秒有一个没见过的东西**；大动作有起势和收势，最快的一刻落在拍点上；动的东西身上总有更慢的东西（`kit/motion.js` 的 `springPoses`）。
6. **先测速再定画质；审片从便宜到贵**（低密度全片联系表 → 关键动作连续帧 → 全质量单帧 → 正片）。全片预览出来之后做一轮自查：**哪 2 秒最平？** 改掉它，只改一轮。
7. **交片前两个数字检查都要过**：`python3 drafts/_lib/smooth.py <成片>`（跳变逐个核对，死区 0）和 `python3 drafts/_lib/cover.py <成片>`（不能报“要改”）。

**省 token**：联系表宽 ≤ 320、一次 ≤ 12 帧；先打印数值再出图；小块改代码，不整文件重写；不开子代理；不读别的期的源码（除非要抄某个具体函数）。

**不要碰**：`CLAUDE.md`、`docs/`、`drafts/README.md`、`drafts/_lib/kit/` 和别的片子的目录（三支片子在并行做，会冲突）。要新的共用工具就在 `drafts/_lib/` 里**新加文件**。配乐可以 `import` `drafts/_lib/song.py`，但每支片子的音色、速度、情绪按任务书来，不要都长成同一首歌。

**交付**（都在 `drafts/<短名>/film/`，推到指定的分支）：

- `<短名>-film.mp4`（H.264、yuv420p、faststart，≤ 25 MB）、`<短名>-frame0.jpg`、`<短名>-frame0-thumb.jpg`、`contact.jpg`（每 30 帧一张、每格宽 320）
- `STORYBOARD.md`（第一行写第 0 帧）、`make.sh`（一条命令重出）、源码
- `../PROCESS.md`（短）：一帧多少秒、`smooth.py` 和 `cover.py` 的输出原文、哪 2 秒最没把握、没做和没验证的
- 推完之后，用 `send_message` 给总导演的会话发一段 ≤ 150 字的报告：分支、时长、两个检查的结果、自己最没把握的一处。

只用可免费商用的字体（`npm run fonts`）；不照搬某一件具体作品的造型。Claude 看不了播放、听不了声音——报告里别写“很丝滑”“很好听”，写量到的数。
