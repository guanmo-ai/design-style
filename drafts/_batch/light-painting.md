# 光绘 Light Painting · 任务书

短名 `light-painting` · 分支 `claude/film-light-painting` · 建议 100 BPM（一拍 36 帧）

**第 0 帧**：夜里，一片有水的地面（会倒映）。**用光写的「光绘」两个大字已经亮在画面正中**（暖白笔画、青色描边那样的两层光，慢的地方粗而过曝、快的地方细），光点还在写最后一笔；字的后面，**一圈钢丝棉的火花正甩到最大**：橙色火星沿切线飞出去、走抛物线、落地弹起来，全都倒映在地上。画面不能暗——光要占满大半个画面，地面倒影再给一倍。一眼看到：发光的大字 + 一圈炸开的火花。

**只属于它的物理**：**画面 = 快门开着的这段时间里所有光加起来。**
1. 光走过的地方都留着（加法混合，HDR 累加之后再做色调映射和泛光）。
2. **亮度 ∝ 1 / 速度**：按等时间间隔撒光，走得慢就叠得多。停一下 = 一个过曝的亮点；甩过去 = 一根细线。笔画的粗细轻重全是速度给的，不用另画。
3. **快门时间 T 是一个连续的旋钮**：画面 = 最近 T 秒的光。T 很长，整幅字都在；把 T 收短，最早的光先消失——字从起笔开始被“吃掉”，一路追到光点上，只剩一颗带短尾巴的光。这就是换章的办法：不切、不淡出，收快门。

每一帧 = f(帧号)：光源的轨迹是时间的函数，画第 f 帧就是把 [t − T, t] 里的样本全加起来（几万到十几万个加法片元，WebGL 很轻）。

**接力**：从头到尾同一颗光。可以演的工具（顺序自己定）：
- 光点写字（第 0 帧）；
- 收快门，字被吃掉，只剩光点；
- 光点拴在绳上转成一个圈，圈再绕竖轴转——一颗光球（orb）；
- 光点拉长成一根光棒（pixel stick）：棒上每个点随时间换颜色，**横着扫过去，时间就摊成了空间**——扫出一条彩带、一个穹顶、一幅图；
- 钢丝棉：光点炸成一把火星，甩成伞，落地弹跳，倒影；
- 结尾：T 重新拉长，所有光回来写成「光绘 LIGHT PAINTING」，一颗小光点一笔写出“观默”；快门“咔”一声合上。

**设计师能拿走的数**（标在画面上）：亮度 = 1 / 速度、快门 T（秒，实时变的那个数）、加法混合（CSS `mix-blend-mode: plus-lighter`）、发光 = 三层不同半径的模糊叠加、色温（火星 2700 K、LED 6500 K）、火星的重力和弹跳系数。

**渲染建议**：WebGL2，累加到 RGBA16F，`drafts/_lib/glkit.js` 里有泛光 + ACES。轨迹画成带宽度的连续带子（不是一串点，避免快的地方断成珠子）。地面倒影：镜像再画一遍 + 竖向模糊 + 一点水波。很淡的雾和地平线上的城市微光，让黑不是死黑。火星数量几千颗，每颗的轨迹是出生时间的闭式函数（抛物线 + 弹跳）。

**配乐**：夜里、开阔、有一点电子——琶音合成器 + 低音；光点甩过去的“呼”声音量跟速度走；火星是细碎的“滋啦”；快门声落在小节线上当打击乐。

**风险**：画面整体偏暗，手机上会糊成一团——`cover.py` 的亮度和对比要看；收快门的那几秒别让画面空掉（光点自己要够亮、够大、一直在动）；泛光别把字糊到读不出。
