# 模型来源

`AvatarSample_F.vrm`（角色名「ヴィータ」/ Vita）是 VRoid Studio（pixiv）早期 α 版附带、以 **CC0** 发布的样例模型。
下载自 OpenGameArt 的整理页 <https://opengameart.org/content/vroid-studio-cc0-models>（CC0；原始说明见 pixiv 帮助中心
“Do VRoid Studio's sample models come with conditions of use?”）。

- CC0：可以修改、再发布、商用，不需要署名；这里仍然注明出处。
- 注意：AvatarSample_A / B / C 和 VRoid Studio 正式版里同名的 D–Z 样例**不是** CC0，有单独的使用条件，本仓库没有用它们。
- 文件是 VRM 0.x（glTF 2.0 扩展），用 `vendor/` 里的 three.js r160 + @pixiv/three-vrm 2.1.0（均为 MIT）读取。
