# 像素风 Pixel Art · 5 秒小样

候选阶段的动效小样：320 × 180 的整数像素网格，最近邻放大 6 倍到 1920 × 1080，30 fps，带配乐和音效。成片 [`pixel-sample.mp4`](pixel-sample.mp4)。

## 先想三件事

**1. 像素自己会怎么动？** 一格一格地动，一阶一阶地变。

- **落格**：所有东西落在整数格上。形（灯泡点亮、云的漂移、窗的闪烁）按 12 fps 走阶梯，光、雨和火花按 30 fps 走满帧。两种节奏叠在一起，画面既有手绘逐帧的顿挫，又不卡。
- **卡帧**：闪电劈中招牌时，整个世界停 4 帧（0.13 秒）。第一帧是黑白反相的英雄帧，只剩城市剪影和灯泡的白点；之后三帧按整像素震（3、2、2、1 px）。
- **色阶冷却**：颜色只在色板里跳，不做渐变。每个灯泡点亮时白热，然后每 1/12 秒降一阶：白 → 浅粉 → 粉 → 霓虹。闪电自己也这样退：白 → 冰蓝 → 蓝 → 深蓝。亮度交给叠加光层，色板本身保持 23 色。

**2. 什么东西从头接力到尾？** 一股电。它在云里闪了四次（预兆），劈到避雷针上，顺着“像素”两个字的笔画逐格往下爬，跳过断开的笔画时拉一道电弧，最后在副标题的青色灯管上落下最后一个字母。收尾的一滴雨落进积水，霓虹倒影被水纹推开，招牌的灯从左往右扫过一遍。

**3. 设计师能拿走什么？**

| 项 | 数值 |
|---|---|
| 画布 | 320 × 180，最近邻 × 6 = 1920 × 1080 |
| 帧率 | 形 12 fps，光和粒子 30 fps |
| 卡帧 | 英雄帧 1 帧 + 冻结 3 帧，震幅 3 → 1 px |
| 色板 | 23 个不重复的颜色，排成 7 条色阶：夜空 5、云 4、雨 3、霓虹粉 6、青 4、暖窗 3、闪电 4；云和雨复用夜空的颜色，白色各条共用 |
| 灯泡 | 一个字的像素 = 一个 3 × 3 灯泡，间距 4 px；字用缝合像素字体 12 px |
| 倒影 | 地平线以下每行取上方 2.2 行处的像素，按整像素左右摆，每 5 行留一道暗缝；颜色压暗后吸回色板最近色 |

## 时间轴（真实时间）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0.00 | 云里刚闪过一次，暗着的招牌能读出“像素” | 雨、远雷 |
| 0.00–1.30 | 镜头从云里往下摇到招牌，整像素落定 | 远雷 × 3 |
| 1.40 | 先导：闪电三帧往下爬 | 电流往下滑 |
| 1.50 | 英雄帧：黑白反相 | 脆响、方波下坠、长雷 |
| 1.53–1.63 | 冻结 + 整像素震 | 雷声延续 |
| 1.63 | 松开 = 配乐第一拍（120 BPM） | 底鼓、贝斯、方波琶音 |
| 1.67–2.78 | 电流沿笔画点亮 114 个灯泡，14 组，每 1/12 秒一组 | 每组一声电流，音高一路往上；每个字点满一声“咔” |
| 3.13–4.01 | PIXEL ART 逐字母亮起，落在十六分音符上 | 方波“哔”，五声音阶往上 |
| 4.63 | 大雨滴落进积水，三圈水纹推开倒影，招牌跑马一遍 | “咚” + 叮，两次回声 |

## 怎么渲

```bash
bash drafts/pixel/film/make.sh
```

不用浏览器：Node 直接写像素缓冲，150 帧约 1.5 秒；声音用 numpy 合成。`smooth.py` 结果：跳变 2 处（第 45、46 帧，即英雄帧的进出，有意），死区 0。

## 来源

- 绘制层（color 不透明缓冲 + light 叠加光缓冲）、粒子和闪电路径来自 [pixelfx](https://github.com/patch-gg/pixelfx) 提交 `5294518` 的 `src/core`，MIT，原样放在 [`vendor/pixelfx/`](vendor/pixelfx/)，许可与署名见其中的 `LICENSE` 和 `NOTICE.md`。场景、招牌、雨、倒影、时间轴为本片自写。
- 中文和拉丁字形来自缝合像素字体 12 px（TakWolf，[OFL-1.1](fonts/OFL-fusion-pixel.txt)），由 [`glyphs.py`](glyphs.py) 转成点阵 [`glyphs.json`](glyphs.json)，仓库里不放字体文件。本次取到的是 2022 年的字体版本；做全片前换成官方最新版重新生成点阵，并核对字形。
