# 朋克复印机 Punk Xerox · 分镜（第一版）

18.75 秒 · 60fps。时间轴按拍写（`scene.mjs` 的 `B(拍)`），先按 160 BPM 排（一拍 22.5 帧，一小节 90 帧）；配乐生成回来后量实际拍子，只改 `BPM` 和 `OFF` 两个数。

## 开工前想的三件事

1. **这种材料自己怎么动？** 复印机的灯管扫过去。灯管扫过的地方变成“下一代”：灰色没了，只剩黑和纸色；黑往外渗，细线断掉，边起毛，纸上多出墨点，整张还歪一点。灯管后面的墨不是一下到位的：刚扫过的那一条先发白、发暖，约 5 帧后墨才“定”下来（跟随和滞后来自这里）。**全片只有这一种转场：灯管扫一次 = 复印一次。**
2. **什么东西从头接力到尾？** 同一张纸在复印机上被一遍遍复印。新贴上去的东西（胶带、贴纸、马克笔、照片）是干净的、彩色的、带影子的；灯管一扫，它们就被压平成黑。右上角的“第 N 代”一直在走。
3. **设计师能拿走什么？** 复印机上的四个旋钮就是这个风格的四个参数：**阈值**（灰色不存在）、**网点**（放大后点变成图形）、**代数**（复印一次糊一层，3 代以内最好看）、**纸色**（颜色在纸上，墨只有黑）。每个都写成数，并落到一张演出海报上。

这次没用默认骨架里的规则卡和手机章：四条规则都由复印机自己演示（旋钮转、灯管扫），应用落在贴满海报的墙上。

## 分镜

| 拍 | 发生什么 | 声音 |
|---|---|---|
| −1.1—1 | **封面**（第 0 帧）：灯管正扫到画面中间。右边是剪贴的原稿（白纸、剪下来的字带影子、灰的照片），左边已经是粉纸上的复印件 | 扫描声 + 全编制 |
| 1—6 | 往原稿上加东西：黄胶带“复印一次，糊一层”拉出来、“第1期”贴纸拍上、红马克笔写“1976 →” | 胶带、贴纸、马克笔 |
| 6—8 | 第二遍扫，把它们压平；镜头推向照片 | 扫描 |
| 8—16 | **01 阈值**：一张灰照片滑进来铺满，灯管扫成黄纸上的黑白；阈值旋钮 0.50 → 0.15 → 0.85 → 0.50，黑白的边界在画面里流动 | 旋钮咔哒 |
| 16—24 | **02 网点**：一扫变成 45° 网点；每两拍放大复印一次（200% → 400% → 800% → 1600%），最后一颗网点吞掉整个画面 | 每次放大一声 |
| 24—36 | **03 代数**：黑里扫出一张 zine 内页（第 1 代）；之后每拍复印一次，2、3、4、6、8 … 64 代，小字先死、照片结块、大字最后化成墨团 | 每拍一次扫描 |
| 36—44 | **04 纸色**：扫回第 1 代的演出海报“今晚不睡”；镜头拉远，它订在墙上，粉、黄、白、绿四张复印件一张张拍上去、订上 | 订书枪 |
| 44—50 | **收束**：片名海报拍在正中，灯管把整面墙复印成一张粉纸；最后一拍订书枪“咔嚓”，署名盖上 | 最后一击 |
