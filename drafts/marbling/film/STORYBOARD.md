# 湿拓 Marbling · 分镜（第二版：18 秒 · 1080 帧 · 90 BPM，一拍 40 帧）

主人 2026-11-14 看第一版：“动效可以做到顶尖一点，而且我希望至少有 3 个或者 4 个以上场景切换，你这只有一个太枯燥了。我要做推特爆款。”
第一版从头到尾是同一个俯视的盘子。第二版换成一台真的 3D 镜头在一间暗的摄影棚里走：**七个场景，全部是同一个镜头连续走过去的，没有硬切**；快的镜头带运动模糊。

## 先想的四件事

0. **第 0 帧**：见上（和第一版同一帧，`cover.py` 已经过）。
1. **这种材料自己怎么动**：颜色不混，只互相推开。每个动作保面积、有闭式公式，画法是倒着查（见 `marble.js` 开头）。第二版多了一个动作——**浸**：一个东西沉下去，吃掉面积 πρ₀² 的膜（包到它身上），四周的膜往里流 `|P′−C|² = |P−C|² − ρ₀²`；蛋上一点的颜色 = 水面上半径 ρ₀ = √(2a·(y+b)) 那一圈（阿基米德：球带面积 = 2πa·h，面积对得上）。
2. **接力**：同一张桌子、同一台镜头、同一池颜料：A 盘（第 0 帧）→ 甩到 B 盘从第一滴开始 → 推进去的那一处正是蛋浸下去的地方 → 蛋把那一圈膜带走。
3. **设计师能拿走的**：两条公式 + 浸的面积关系、r ∝ √t、动作顺序（滴 → 耙 → 梳 → 卷 → 浸）、耙 / 梳的齿距和拖动、卷的 R、七色色板；最后是这种花纹真的包在一个物件上的样子（水转印 / hydro dipping）。
