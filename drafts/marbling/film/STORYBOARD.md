# 湿拓 Marbling · 分镜（16 秒 · 960 帧 · 90 BPM，一拍 40 帧）

## 先想的四件事

0. **第 0 帧**：见上。缩到宽 360：大字「湿拓」读得出；左羽纹 / 中梳子 / 右靶子三块一眼分得开。
1. **这种材料自己怎么动**：颜色不混，只互相推开。水面上的颜料是一层不可压缩的膜，每个动作都保面积、都有闭式公式（Lu / Jaffer 的 mathematical marbling）：
   - 滴：`P′ = C + (P−C)·√(1 + r²/|P−C|²)`；同一个圆心连滴 n 滴的复合也是闭式（减去总面积），一个靶心只算一次；面积匀速流出，所以 r ∝ √t，不另设缓动。
   - 耙 / 梳：`P′ = P + z·u^d·M`（u^d = e^(−d/λ)，d 到最近一根齿的距离）；位移带前沿：齿尖前面 L2 内递减（颜料在齿前被挤密），后面不再动。
   - 卷：绕一点转 `θ₀·e^(−r²/R²)`，保面积。
   - 画法是倒着查：每个像素把动作表从后往前逆变换回去，落在哪一滴里就是哪个颜色 → 放大多少倍边缘都是锐的。
2. **接力**：同一盘水从头到尾。第一盘被一张纸带走（纸背面印着它），清水里从第一滴重新来；最后同一个动作（盖纸、揭纸）把第二盘带走，纸翻过来就是成品。镜头从全景推进一根羽纹 ×21 再拉回，全程不切。
3. **设计师能拿走的**：两条公式、r ∝ √t、动作顺序（滴 → 耙 → 梳 → 卷）、耙的齿距 300 / 拖 150、梳的齿距 28 / 拖 80 / λ 7、卷的 R 175 / θ₀、七色色板（标在画面上，跟着正在发生的动作走）；成品是一张环衬 / 海报。
