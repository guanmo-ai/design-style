## 1 · 定调：只有低多边形能做的动作

| 独有的动作 | 怎么做到“真” |
|---|---|
| **翻牌：纸翻成颜色** | 每个三角形以一条边为铰链转 180°（罗德里格斯旋转），背面画纸色、正面画颜色——低多边形的“面”第一次被当成一张张卡片 |
| **光一转，面就翻** | 每帧按面法线和光的方向重新算三档明暗；太阳绕一圈，所有面在三档之间跳，不是平滑过渡 |
| **减面** | 二十面体细分 3 / 2 / 1 次；每次减面都是一下“跳”，落在八分音符上 |
| **一张纸开始、一张纸结束** | 第 1 章从纸翻出来，片尾由远到近翻回纸，片名停在纸上 |

## 2 · 审片意见与修改

| 轮 | 主人的意见 | 改了什么 |
|---|---|---|
| 1 | “第二个分镜好像也是从下面到上面的……第二个分镜就从上到下” | 第 2 章改成三角面带着颜色从天上砸下来，由远到近一排排落（`slam_tris`），和第 1 章的“从纸翻起来”正好相反 |
| 1 | “结尾好像是突然中断的”“BGM 做得更好一点……电影级别的” | 加了真正的结尾（山谷翻回纸 + 片名）；配乐第二版换成合成管弦乐 |
| 2 | “低多边形就是 BGM 不好，而且结尾不用一定要跟首尾呼应的” | 配乐第三版重做（见下）；结尾不再接回开头，片名停到最后 |
| 3 | “以后视频结尾最后记得署名观默” | 片名下方加署名「观默」，写进设计笔记 |

## 3 · 配乐为什么重做两次

- **第一版**（钢片琴 + 拨弦的轻音乐）太素，撑不起“砸下来”的画面。
- **第二版**按“电影级别”做了合成管弦乐：钢琴、弦乐、合唱、竖琴、定音鼓。问题是 numpy 合成的弦乐和人声一听就假——越往“真乐器”靠，假的地方越明显。
- **第三版**换成本来就是合成器的音色：电子 future bass。合成器不需要“像”什么，所以每个声音都是对的；而且这种风格本来就是年轻人在听的。
  - **小节线挪到 0.5 秒。** 画面换章在 4.5 / 8.0 / 11.6 / 15.0 秒，和从 0 开始的小节线对不上；开头加半拍弱起，4.5 秒的 drop 就落在强拍上。
  - **降采样 = 减面。** 9.75 / 10.25 秒两次减面时，整条音乐跟着变糙（采样率和位深一起降，第二次更狠），下一小节弹回来——“面越少”被听见了。
  - **手机喇叭。** 第一次混音 60—70% 的能量在 80 Hz 以下，手机上会听着很薄；亚低音调低，加一层中低音的谐波，和弦和人声切片抬高。
  - **结尾回到主和弦。** 全片 IV–V–iii–vi 绕着走，直到片名那一下才第一次落在主和弦 D 上，然后自然收掉。
  - `Mixer.master` 加了 `loop` 参数：`loop=False` 时余音不折回开头，最后 0.3 秒淡出（默认 True，旧的各期不受影响）。

## 4 · 踩坑记录

| 问题 | 解决 |
|---|---|
| 相机左右镜像 | 右向量改成 `cross(f, up)`，上向量 `cross(r, f)` |
| 立方体有几个面朝里 | `Scene.box` 的绕序反了，修正后逐面检查法线 |
| 片尾最后几帧是空的 | `min(t − 20, −0.6)` 应为 `max` |
| 第二版配乐翻纸声刺耳 | 带通降到 1.5—5.5 kHz、音量降低 |
| SVG 里的字体不生效 | 用 `page.goto('file://…')` 打开，不用 `setContent` |
| 结尾片名下面还飘着火车的烟 | 烟的位置按发出时的火车位置算，火车开走烟还在；翻回纸时让烟一团团缩没 |
