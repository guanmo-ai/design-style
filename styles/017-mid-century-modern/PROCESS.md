# 017 · 中世纪现代 —— 制作过程

**中文** · [English](PROCESS.en.md)

这一期改得最多：风格图两版，短片的开场三版、配乐五版。下面按时间记下每一步怎么想、主人说了什么、怎么改的，最后是可以直接复用的做法。

## 1 · 选题

中世纪现代是主人排在“下周做”的那一个（候选见 `drafts/README.md` 的第一轮）。开工前读 `docs/BENCHMARKS.md`，把“这一期最有用的一招”定成 **剪刀代替尺子**，签名物理定成 **影子 = 高度**。

## 2 · 风格图

| 版本 | 做法 | 主人 |
|---|---|---|
| 第一版 | 橘、芥末、深孔雀绿 + 奶油纸；边是“一刀一段直线”；横向纤维纸纹 | “勉强吧……我还是比较喜欢孟菲斯那种颜色” |
| 第二版 | 换成中世纪现代里明亮的一支（Girard 织物、Mary Blair、Eames 挂衣架彩球）：暖白纸 + 番茄红 / 向日葵黄 / 粉 / 绿松石 / 钴蓝；叠印只让浅色压深色；边改成平滑的慢抖动；纸纹只留细颗粒；纸片左上加一道 0.8px 亮边；海报加 003 / 004 / 005 同款底部信息栏 | “这次颜色好多了” |

工具在 `images/cut.py`：剪刀边（两层周期取整的正弦，首尾闭合、尖角保留）、影子 = 高度（每个整数高度一个滤镜）、叠印（裁切区重新上色）、原子时代形状库。

## 3 · 短片

| 版本 | 做法 | 主人 |
|---|---|---|
| 开场 v1（7.5 秒） | 黑场里白纸条一根根扎进来 → 绕钟心旋成辐条、黑场按对数缩成钟心（黑边扫过处纸条翻成墨色）→ 球抛进来 → 手送最后一颗红球 → 片名 | “节奏有点慢；一开始有点黑，不知道能不能吸引人” |
| 开场 v2（5.5 秒） | 红场 + 彩色纸条，整体压缩 | “红色的背景不好看；动效还是没有很顶尖，节奏可以快一点；你看看我推荐的那几个” |
| 全片 v3 | 下载 003 / 004 成片逐帧看：满屏超大的主角、1.5 秒内出片名、开场先搭海报、每章换一种底色。推倒重做：开场 1.5 秒搭出海报；每章一张彩纸滑进来；同一批纸一路接力，翻面是主要动作；144 BPM | “丝滑倒是有点丝滑，但是没有震撼感……音效、BGM 太一般” |
| 全片 v4（定稿） | 加重击：镜头往落点冲 3.5—8% 再回来、大落地溅起 12 片彩纸碎片；换章的纸从右 / 上 / 左 / 下拍进来；换章落定全部对齐小节第一拍；修掉“下一章底色在纸刚开始滑时就铺满”（换章其实是硬切）的 bug | 画面通过，配乐另选 |

**丝滑是怎么做的：** 所有位置都是时间 t 的纯函数，速度连续；镜头走单调三次样条（Fritsch–Carlson，不过冲）；视频里只做平移 / 旋转 / 缩放，纸片在 `video/make_geometry.py` 里一次剪好（不逐帧重剪，边缘不抖）；按这一帧最快的东西每帧走多少 px 取 2—6 个子帧做运动模糊。曾想用“一秒 12 张”的定格感，和“丝滑”冲突，删掉了。

## 4 · 配乐

| 版本 | 做法 | 主人 |
|---|---|---|
| 1 | 120 BPM 摇摆冷爵士（叮叮镲、刷子、响指、低音提琴） | — |
| 2 | 144 BPM bebop | “BGM 不好，音乐噪音太多” |
| 3 | 去掉所有噪声类的声音，只剩钢琴 / 颤音琴 / 木琴 | “太一般” |
| 4 | 50 年代片头爵士（贝斯 + 萨克斯固定音型、铜管齐奏、军鼓滚奏） | “太急促，好难听；就要一个好听的 BGM” |
| 5 | 同时给两版二选一：A 波萨诺瓦 / B 明亮律动（照 015 第二版） | **选 B**：“明亮律动更喜欢，这样就触动人心一点” |

定稿：144 BPM · F 大调 · 四拍底鼓、八度跳的贝斯、反拍钢琴、钟琴主旋律（两小节一问一答）；每块纸落下对一个落在当前和弦上的音。

**教训：** 配乐在云端只能看频谱和时间点，听不到。拿不准的时候，直接给主人两三个方向完全不同的版本挑，比一版一版猜快得多。
