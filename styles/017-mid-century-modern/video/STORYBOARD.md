# 017 · 中世纪现代 —— 分镜（定稿：照 003 / 004 的骨架）

**这一期最有用的一招：** 剪刀代替尺子——每一块都是一张剪出来、能拿起来的纸。
**签名物理：** 影子 = 高度。纸离桌面 h px，影子往右下偏 (0.5h, h)、模糊 0.4h，纸本身放大 1 + 0.0032h。提起来影子就离开它，落下来影子和它合上，轻压 4%。
**换章：** 一整张彩纸带着剪出来的毛边和影子依次从右 / 上 / 左 / 下拍进来，盖住桌面（纸片版的“颜色接力”）；重击时镜头往落点冲一下，溅起彩纸碎片。
**接力链：** 辐条 → 折线手臂（翻面成白）→ 钢丝折线（翻回墨色）→ 蓝球 → 唱片（翻面）→ 落日（再翻面成黄）→ 玻璃盒子 → 手机（翻面成墨）→ 规则卡 → 海报重新落下 = 第 0 帧。
**丝滑：** 60 帧连续、速度连续；镜头走单调三次样条；按速度加运动模糊。
**节奏：** 144 BPM（1 拍 = 25 帧）；开场 1.5 秒搭出海报，每章约 1.6 秒，换章落定全部在小节第一拍；全片 15 秒（900 帧），首尾无缝。

## 改版记录

- 第一版（7.5 秒开场）：黑场 + 白纸条 + 球钟。主人：节奏慢、第一秒太黑。
- 第二版（5.5 秒）：红场 + 彩色纸条。主人：红色不好看，动效不够顶尖，再快一点，去看推荐的几期。
- 第三版：逐帧看了 003 / 004 成片——满屏、超大主角、1.5 秒内出片名、每章换一种底色。改成开场先搭海报、一章一张彩纸；144 BPM。配乐去掉所有噪声类的声音（主人：噪音太多）。
- 第四版（定稿画面）：重击（镜头冲击 + 碎片）、四个方向换章、换章对齐小节第一拍，全片 15 秒。配乐五版，最后主人在“波萨诺瓦 / 明亮律动”里选了明亮律动。
