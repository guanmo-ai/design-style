# 017 · 中世纪现代 —— 分镜

**这一期最有用的一招：** 剪刀代替尺子——每一块都是一张剪出来、能拿起来的纸。
**签名物理：** 影子 = 高度。纸离桌面 h px，影子往右下偏 (0.5h, h)、模糊 0.4h，纸本身放大 1 + 0.0032h。
提起来，影子就离开它；落下来，影子和它合上，轻压 3%（单向，不来回抖）。
**丝滑：** 所有动作 60 帧连续、速度连续；镜头走单调三次样条（不过冲、不折线）；快的地方按速度加运动模糊（最多 6 个子帧，快门半帧）。
**接力链：** 白纸条 → 辐条 → 小球 → 唱片 → 落日 → 播放键 → 回到第 0 帧。
**外框：** 左上章节标题（编号 · 领域 / 作者 作品 · 年份 / 这一章教什么）；左下 h 读数（一块小纸 + 它的影子，实时变）。
