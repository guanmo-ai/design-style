## 1 · 选题：年轻人喜欢、正在流行、动效能做到顶尖

前三轮候选（欧普艺术、抖动像素、拟物、迷幻海报、中世纪现代……）主人都觉得“一般”，给了两条方向：**适合年轻人、大家正在追捧的**；以及一段参考视频（浮空岛一块块搭起来）。从参考里提取的不是画面，而是“动作”：**世界从碎块里被搭出来**。第四轮按这个出了低多边形、体素、等距微缩三个候选，主人选了低多边形（→ 019）和微缩景观（→ 018）。

选题时按设计笔记先列“只有这个风格能做的动作”：

| 独有的动作 | 怎么做到“真” |
|---|---|
| **一块块砸下来搭好** | 几千块 InstancedMesh 碎块，每块有自己的起点、时长、类型；`slam` 物理：自由落体 → 压扁 → 以底面为原点回弹 |
| **底座四边切齐、露出地层** | 底座本身也是搭出来的：木框条从左推进，4 层土各切成 2×2 块，从中心往外一圈圈砸下 |
| **移轴让世界变小** | 后期 ShaderPass：清楚带 + 线性变虚；第 3 章专门“咔”一下打开做对比 |
| **天黑亮灯** | 天色三段插值，窗户自发光一盏盏亮，台灯是真的点光源 |

## 3 · 每一处为什么这样动

- **第 0 帧就在动。** 第一版前 1 秒多都在铺地板，主人说“大家就直接划走了”。第二版第 0 帧土块已经翻着砸下来、镜头更近更低，然后往后一拉；0.55 秒咖啡店已经升起来——地面的铺设压缩到 0.42 倍时间，和房子一起跑。
- **砸 = 自由落体 + 压扁。** 前 60% 用 `t²` 下落（越落越快），落地那一下压扁 16%，再用 `easeOutBack(1.2)` 弹回，过冲约 5%。缩放以底面为原点，所以压扁时块不会“陷进”地里。每次落地扬起一小圈灰。
- **镜头“咚”。** 每块底座第一下落地时镜头往下沉一点再回弹，像桌子被拍了一下；配乐同一拍有定音鼓。
- **一排底座，同一台镜头。** 三块底座摆在同一张桌上（x = 0 / 38 / 76），每章镜头横移到下一块；第 5 章拉远看到三块一起入夜，这是“世界被放上桌面”的证据。
- **整屏收成手机。** 第 4 章不是切到一张 App 截图：用 `setViewOffset` 把画面推到右边，再把一个奶油色的“洞”从整屏收成手机屏幕——模型一直在渲染，只是被框住了。
- **结尾。** 第一版结尾是突然切回开头。第二版留出 2.6 秒：推向房间亮着的窗，标题升起，弦乐全奏；18.6 秒台灯“咔”地关掉（太阳、半球光、bloom 一起压暗），最后一个钢片琴音。然后磁带停转，所有零件按时间倒放飞回天上，回到第 0 帧。

## 4 · 质检与渲染

- WebGL 在云端走 SwiftShader（CPU），很慢：预览用 `PR=0.5`（1920×1080 布局、半分辨率）、30fps、4 进程并行，约 20 分钟；正片 `PR=1` 约 1 小时。
- 文字层是 DOM，叠在 canvas 上一起截图：所以预览也必须用 1920×1080 的布局，只降像素比，不然字会挤。
- `render.cjs` 支持 `RESUME=1` 跳过已渲染的帧，单个进程崩了可以接着渲。

## 5 · 踩坑记录

| 问题 | 解决 |
|---|---|
| 房间和山谷的碎块全部看不见 | InstancedMesh 的包围球在“全部隐藏”时算的，被视锥剔除了：`frustumCulled = false` |
| 大平板在掠射角出现灰色方块 | GTAO 的伪影：底座搭好之前关掉 GTAO，之后再淡入 |
| 隐藏的物体还在投影 | 隐藏时把物体移到 y = −1e4，而不是只设 `visible` |
| 半分辨率预览字挤成一团 | DOM 文字层按 1920 宽排版：预览改成 1920×1080 + 像素比 0.5 |
| 截图偶尔 30 秒超时、进程退出 | 截图超时放到 300 秒，加 `RESUME=1` 续渲 |

## 6 · 下期沿用

- 先做 5 秒小样给主人看颜色和动作，再写全片；颜色问题在小样阶段就要解决。
- 第 0 帧必须已经在动，第一秒内要有“主角”出现。
- 结尾要有一个真正的收束（一个动作 + 一个声音），再接回开头。
- 云端 WebGL 正片超过 1 小时的，交给有显卡的机器（`--use-gl=angle`）。
