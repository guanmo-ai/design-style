DESIGN STYLE · NO.003 · MAKING OF

从 0 到 1：这支 15 秒短片是怎么做出来的

没有 Figma、没有 AE、没有素材库：画面、图片、配乐全部是代码。十步，按顺序做。
01
读仓库
看 001 / 002 的指南、过程和模板。抄结构，不抄画面。
git · README · PROCESS_TEMPLATE
02
选题定调
一句话定义 + 这期最有用的一招：把轴转 30°。
先写下来，再动手
03
研究
时间线、五条规则、广度清单（7 个领域 → 7 章）、误区。
README.md §1—§7
04
设计令牌
4 色 + 亮纸 · 2 款字体 · 2 条轴 · 144 BPM = 25 帧一拍。
tokens.ts / .css / .json
05
风格图先行
Python 写 SVG，字宽用真实字体度量；先把“定帧”做对。
make_svgs.py · fontTools · Chromium
06
时间轴
36 拍 × 25 帧：开场 4 · 七章各 3 · 规则 5 · 片尾 6。
timeline.ts · timeline.json
07
视频代码
每一帧是 React 组件的一个函数：f → 位置、角度、缩放。
Remotion 4 · React · TypeScript
08
配乐与音效
numpy 从零合成，音效直接写帧号，响度 −14 LUFS。
make_music.py · numpy · ffmpeg
09
质检循环
只导出要看的帧 → 拼图 → 改 → 再看。转场必看中间帧。
stills.mjs · contact_sheet.py · timeline_chart.py
10
渲染发布
母版 crf16 → 分享版 → 封面 → Release → 画廊上架。
remotion render · ffmpeg · git
看 → 改 → 再看：每改一处，只重看受影响的那几帧
