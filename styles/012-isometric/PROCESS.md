## 1 · 选题与定调

**为什么是等距：** 设计师真正要学的是空间语法（轴角、等比例、假 3D），不是“再来一套等距贴纸”。扁平卡片弹成体积，是 X 上最好传的前后对比。

**这一期最有用的一招：** *先锁轴角，再堆体积。*

**定调：**

- 一句话：*先锁轴角，再堆体积。*
- 质感：冷灰棚 + 陶土 / 青绿 / 靛蓝三轴 + 扁平的三面盒子（不是写实 3D）。
- 叙事：方法片——锁轴、证明三条规则、堆一座产品小城、对照三种变体、口诀收束。
- 接力：同一套投影和那只陶土立方贯穿全片。
- 边界：不碰 007 / 010 / 011 / Card Stack 的草稿分支。

## 2 · 研究

- 真等距：三轴等长，投影夹角 120°，常用 30°/30°。
- 像素 2:1：arctan(0.5) ≈ 26.6°，是斜二测，不是真等距。
- 军事投影：一轴水平，平面可量。
- 产品等距：仍是平行投影；圆角和柔阴影是材质。
- 与 003：构成主义锁的是平面构图的 30° 斜线；等距锁的是三根空间轴。

## 3 · 投影先于画面

`video/iso.ts` 把世界坐标投到屏幕，盒子输出三个可见面（背向剔除）和地面影子。`appear` 只压缩高度，体积从地面长出来。UI 用平行四边形 `matrix()` 贴在顶面上。

过关标准：截一帧，能读出 30° 轴，且远处的盒子不比近处小。

## 6 · 声音

`audio/make_music.py` 用 numpy 从零合成：

- 120 BPM，D 大调。开场软垫，轴锁定用木击 + 钟。
- 建造段落每一块落地一声轻叩。
- 变体换三种和弦色。片尾 D 大和弦。
- 响度 −14 LUFS，真峰值 < −1 dBTP。没有外部采样。

## 8 · 踩坑

| 问题 | 处理 |
|---|---|
| 军事投影下有的面会被剔除光 | 五个候选面做面积剔除，不写死“只画顶/右/左” |
| 镜头一停就像 PPT | `camOf` 全程正弦微移 + 建造段持续 yaw |
| 和 003 的 30° 混淆 | 指南和片里写明：这里是三根空间轴 |
| 运动模糊 × 许多 DOM | 世界合并进一张 SVG 多边形 |
| 平台顶面盖住上面的盒子 | 先画地面（薄板），再按深度画体积 |
| 军事 30°/0° 会把面拉成巨大折线 | 变体用 2:1 斜二测，不要水平轴 |
