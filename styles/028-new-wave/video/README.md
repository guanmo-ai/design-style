# 新浪潮 · 第二版源码 / Version-two source

[全片页面 / Canvas entry](../../../drafts/new-wave/film/film.html) · [场景 / Scenes](../../../drafts/new-wave/film/scenes.js) · [节拍时间轴 / Beat grid](../../../drafts/new-wave/film/timeline.js) · [音效 / Audio mix](../../../drafts/new-wave/film/audio.py) · [分镜 / Storyboard](../../../drafts/new-wave/film/STORYBOARD.md)

从项目根目录运行 `npm ci`、`npm run fonts`，并安装 Playwright Chromium、Python NumPy 和 ffmpeg。视频用 TeX Gyre Heros、Silkscreen 和 Noto Sans SC。执行 `bash styles/028-new-wave/video/make.sh` 重渲，或用 `PREVIEW=1` 生成预览。正式成片见 [day-28 Release](https://github.com/guanmo-ai/design-style/releases/tag/day-28)。

图解保留可编辑 SVG 文字与版式，选图来自第二版影片。安装 FontTools 后运行 `python3 styles/028-new-wave/images/make_svgs.py` 可重新生成。
