## 1 · 定调：只让这个风格独有的动作占画面

先按设计笔记的“检查表”第 1 条，列出只有未来主义才能做、别的风格做不了的动作，再让它们占满画面：

| 独有的动作 | 怎么做到“真” |
|---|---|
| **残影由真实轨迹生成** | `kit.tsx` 的 `Echoes`：第 k 层就是 `render(t − k·Δt)`——把“过去的自己”重新画一遍，而不是把本体往后平移。于是刹车时残影自己挤进本体、加速时自己拉开、停下时和本体重合（重合的那几层直接不画，免得边上留一圈彩色毛边） |
| **字宽 = 速度** | Archivo 的 `wdth` 轴 62—125；大字一个字母一个字母排（`metrics.ts` 存了每个字母在 6 个宽度上的前进宽度，中间线性插值），每个字母按自己那一刻的速度取宽度 |
| **惯性前倾** | 倾角 = −7 · 加速度，过一个二阶弹簧（`springOf`，ζ = 0.69）：刹车时字往前栽，停死那一刻弹回、过冲约 5% |
| **力线** | 楔形，尖端收向前方，长度 = 26 · (v − 4) px，停下就缩回去，最多 6 条 |
| **拟声排版** | 声音写成字，每远一级 ÷ 1.5；TA 的字号和字宽 = 轮子转到那一刻的速度 |

淡入、平移、缩放只做配角：全片没有一处淡入，出现靠“飞进来刹停”“长出来”“从遮罩里升起”。

## 2 · 骨架：一章一件代表作，一块块搭出来，接力换幕

标杆（003 / 004）的核心是“真实代表作 + 一块块搭出来 + 签名物理 + 元素接力”。这一期六章：

| 章 | 作品 | 搭出来的过程 | 接力到下一章 |
|---|---|---|---|
| 开场 | 马里内蒂《未来主义宣言》1909 | FUTURISM 刹车进场 → 未来主义晚 6 帧 → 一句话升起 | 起步冲走，只剩字母 **I** |
| 01 绘画 | 巴拉《拴着皮带的狗的动态》1912 | I 变成狗绳；身子落下 → 项圈 → 头 → 耳朵 → 尾巴 → 四条腿（十六分音符） | 镜头沿**狗绳**上摇到牵狗的人 |
| 02 雕塑 | 波丘尼《空间中连续性的独特形式》1913 | 迈步 → 定格 → 残影凝固 → 抬起 → 两块底座滑进来 | 底座喊出的 **TUMB** 冲向镜头 |
| 03 文学 | 马里内蒂《Zang Tumb Tuuum》1914 | TUMB 落进书页 → ZANG → TUMB / tumb → TUUUUUUM | 字母停下压窄、**长成塔** |
| 04 建筑 | 圣伊利亚《新城市》1914 | 塔 → 退台块 → 电梯井 → 天桥 → 电梯 | 电梯冲进**地下的黑** |
| 05 机器 | 塞维里尼《郊区火车抵达巴黎》1915 | 火车冲进来 → 棱面在车头经过处碎出来 → 烟一团团 → TA → PSSSH | **蒸汽**冲上天 |
| 06 天空 | 克拉利《俯冲进城市》1939 | 云盖满 → 破洞 → 城市冲上来 → 飞机 | 俯冲的灭点是**一块屏幕** |
| 07 今天 | 骑行 App + 网页 | 屏幕退出来成手机 → 速度起来 → 网页冲进来 → 滚动 → 代码 | 第一张规则卡**撞走**手机和网页 |

两段“同一个世界、同一台镜头”：01 + 02（狗和人在同一条街上，镜头从 2.4 倍拉回、跟拍、再拉远上摇），03 + 04（地面 = TUUUM 的基线，一页书就是一座城）。

## 3 · 每一处为什么这样动

- **开场的第一下。** 第 0 帧 FUTURISM 已经在动（封面就是它带着残影冲进来）。它一路匀减速（a = 1.0 px/帧²）：残影越靠近本体越密——观众第一眼读到的就是“在刹车”。字母像车厢一样一节晚 1 帧：刹车时后面的字挤上来，起步时前面的字先走。
- **残影在镜头里取样。** 01 章镜头跟拍：如果在世界坐标里取样，整条狗都会拖出 72px 一层的残影。改成在镜头里取样（render 时连镜头一起回到过去）后，身子几乎没有残影、摆动的腿残影最多——这正是巴拉画里的样子。腿旁的标注实时数“腿 6 层 · 身子 1 层”。
- **步态相位由走过的距离决定。** 停下时相位冻结、摆幅归零：腿上的残影在刹车时“自己”收拢，而不是靠关键帧收。脚也不打滑。
- **定格不是刹车。** 02 章要的是“残影凝固成形体”：如果先刹车，残影会先收掉。所以 f245 是时间停住——残影停在那一刻的样子，然后从钴蓝、0.6^k 过渡到实心的青铜色阶。定格那一刻正好是步子迈得最开的时候（反推步态相位的起点 `PHI0`）。
- **TUUUUUUM 记下了自己的减速。** TUM 三个字母以 100 px/帧 一起飞进来，T 和 U 撞停，M 带着同样的速度继续冲；M 的阻力是“速度和剩下的距离成正比”（指数减速），所以它经过的每个 U 的字宽从 125 线性缩到 80——这个词的形状就是它的速度曲线。
- **字长成塔。** 停下的字最窄（wdth 62），再以基线为原点一个接一个纵向拉伸；电梯井的位置拉开一道缝。字到建筑，用的是“字宽 = 速度”的另一面：停下 = 窄而高。
- **烟是速度表。** 烟每 4 帧冒一团，冒出来就留在空气里：间距 = 速度 × 4 帧，刹车时越来越密。TA 每半圈一声，字号和字宽 = 那一刻的速度。
- **俯冲的残影越近越大。** 飞机比镜头冲得快，“刚才的它”离镜头更近，所以残影一层比一层大；拉起时先刹住（残影收拢），再冲回镜头滑出画面。楼的边全部收向灭点——楼本身就是力线。
- **规则卡是牛顿摆。** 新卡匀减速冲进来，碰到旧卡的一瞬间旧卡以 1.15 倍速度被撞走，新卡刹停在正中。片尾那张卡自己起势冲走，并且在 1182 帧前连残影一起离开画面——第 1199 帧和第 0 帧之间不留任何残影。
- **首尾无缝。** 片尾最后 60 帧就是开场在 t − 1200 的样子：FUTURISM 从左边冲进来，第 1200 帧 = 第 0 帧；刹车尖啸从 1180 帧起、折回开头。

## 4 · 质检：只出关键帧、胶片条、曲线和草稿预览

按设计笔记的“高效流程”，云端不渲正片：

- **关键帧**：`node scripts/stills_batch.mjs S015-Futurism out/k 0 25 96 …`，每轮 15—20 帧，约 1 分钟。
- **胶片条**：`node scripts/stills_batch.mjs S015-Futurism out/k 330-372:3` + `strip.py`，查起势、交接、刹车。
- **剧本曲线**：`video/curves.ts` 导出每帧各主角的速度、右上角读数和运动模糊取样数，`scripts/plot_probe.py` 画图（[`process/02-curves.png`](process/02-curves.png)）。火车的速度曲线是一条直线（真的匀减速）；片尾标题的速度在第 1199 帧正好接上第 0 帧。
- **草稿预览**：`npm run preview:015`（30fps、step 2、blur 1、半分辨率）。这一期全片是 SVG，没有着色器，**云端 4 核也只要约 1 分钟**（014 的 WebGL 预览要 10 分钟）。

## 5 · 改版记录（开发中自查）

| 轮 | 发现 | 诊断 | 改了什么 |
|---|---|---|---|
| 1 | 第 0 帧发灰 | 运动模糊取了 t = −0.5 的子帧，那一刻开场还没“活” | 开场的时间窗从 −80 帧开始 |
| 1 | 狗出场时 FUTURISM 还压在狗身上飞 | 开场在屏幕坐标里，没跟着镜头拉远 | 开场在交接后套上同一台镜头的相对变换：标题跟着缩小、飞走 |
| 1 | 定格时人是并腿站着的 | 定格那一帧的速度读成了 0，步幅归零 | 速度在定格前半帧取；反推相位起点让定格落在步子最开的时候 |
| 2 | 腿上的残影还没收完，人就走了 | 刹车太晚、停顿太短 | 刹车提前到 150—162，留出 20 帧看收拢；镜头跟拍的滞后从 10 帧改 4 帧 |
| 2 | TUUUM 的 U 几乎一样宽 | 匀减速下大部分距离是高速走完的，字宽封顶 | M 改成指数减速；字宽公式的 vmax 从 40 改 60 |
| 2 | 城市像一排音叉 | 拉长的字挤在一起，没有建筑的体量 | 背后加三座铬银的退台楼；电梯井的位置拉开缝，天桥只跨缝 |
| 2 | TUMB 缩回书页时整屏发橙 | 90 倍大的残影 | 比 2.5 倍大的残影不画 |
| 3 | TUM 落地时 M 停了 2 帧又突然冲出去 | 曲线上的死区 + 无穷大的加速度 | TUM 一起匀速飞进来，只有 T 和 U 撞停，M 带着原速继续 |
| 3 | 规则 02 的 0.6^k 标签挤在一起 | 小球在减速 | 小球匀速：相邻两层永远隔 78px |

## 6 · 声音

- 144 BPM，全片不变速；A 弗里几亚：Am – B♭ – G – Am · Am – F – G – E……
- 音色向鲁索洛的噪音机致敬：嚎叫器（音高滑动的窄带噪声，TUUUUUUM 就是它一路往下滑）、轰鸣器、爆裂器（ZANG）、嘶声器（PSSSH）、噼啪器（车轮）。
- 定格那一刻整首歌“磁带停转”：音高往下掉、只剩余音，两声 TUMB 后乐队再进来。
- 脚步和 TA 的帧号是从轨迹算出来的（狗每走 45px 一步、轮子每半圈一声），不是手填的。
- 响度 −14 LUFS；余音折回开头，循环无缝。

## 7 · 踩坑记录

| 问题 | 解决 |
|---|---|
| 云端 `npm run fonts` 下载 403 | 代理拦了 `github.com/.../raw`；改从 `raw.githubusercontent.com` 直接下这一期要的字体 |
| `build_images.py` 转 PNG 时 Playwright 找不到浏览器 | 项目的 playwright 版本和云端预装的 Chromium 不一致：`CHROMIUM_PATH=/opt/pw-browsers/chromium` |
| SVG 里的 clipPath 在运动模糊的多层叠加里会串（同一个 id 被多层引用） | 遮罩一律用嵌套 `<svg overflow="hidden">`，不用 id |
| 中文没有宽度轴 | 只在动的时候横向拉宽（1 → 1.32），停下回到正常字宽 |

## 8 · 下期沿用的清单

- 先列“只有这个风格能做的动作”，再写分镜；每个动作找一个能让它“自己发生”的物理量（这一期是轨迹），而不是关键帧。
- 剧本全部写成时间的纯函数：残影、运动模糊、曲线导出都靠“在过去的时刻再算一遍”。
- 能用 SVG / Canvas 2D 做的就别上 WebGL：草稿预览 1 分钟，审片一轮能跑好几次。
- 关键帧 → 胶片条 → 曲线 → 草稿预览，四样都过了才交给 Codex 用显卡渲正片。
