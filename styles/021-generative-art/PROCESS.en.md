# 021 · Generative Art: production overview

[Guide](README.en.md) · [Detailed Chinese process](PROCESS.md)

## Approved master

The user approved both films on 2026-11-04. This release directly uses `drafts/generative/film/generative-film.mp4` from commit `ced34bf`, renamed for the release. No picture or audio was re-rendered. Provenance and SHA-256 are recorded in `process/approved-master.json`.

## Implementation

A deterministic absolute-frame Canvas 2D renderer supplies 1,080 frames at 60fps. `video/timeline.js` is shared by motion and sound. `video/events.json` records detailed animation events. Python, NumPy, the shared `Song` layer and `AudioKit` synthesize the entire soundtrack at 120 BPM.

## Reproduction

From the repository root, install the locked Node dependencies, NumPy and fonttools, Playwright Chromium, FFmpeg and the fonts, as described in the Chinese process. Then run:

```bash
bash styles/021-generative-art/video/make.sh
python3 styles/021-generative-art/images/make_svgs.py
python3 scripts/build_images.py styles/021-generative-art/images
```

The render script uses the stored approved event table, renders 1,080 frames into a temporary directory, synthesizes music and encodes `out/021-generative-art.mp4`. Temporary frames are cleaned on exit. The approved master remains the release artifact; different browser or encoder versions may change regenerated bytes.

## Delivery

The source includes the renderer, music, timeline, four editable diagrams, tokens and bilingual documentation. The English texts are concise companions; film and diagram labels remain Chinese. See [sources and font licenses](SOURCES.md).
