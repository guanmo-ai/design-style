# 021 · Generative Art

Flow-field ribbons relay into controlled disorder, Truchet tiles, a web generator and a branching tree. Seeds, palette weights, spacing and growth become practical phone-interface patterns.

[Watch the film](https://guanmo-ai.github.io/design-style/?lang=en#work-021-generative-art) · [Film and full source](https://github.com/guanmo-ai/design-style/releases/tag/day-21) · [Production overview](PROCESS.en.md) · [中文](README.md)

## Visual rules

1. Change a seed to vary an image within a visual family.
2. Repeatability requires the same generator, version and parameters.
3. Choose colours with weights.
4. Advance 4px at a time; use an occupancy grid and a 5px gap.
5. Place large forms first, then fill gaps with smaller ones.

## Interface applications

The last section demonstrates avatars, covers, loading, tickets and completion. These are motion studies: connect them to real application state and offer a reduced-motion version when reusing them.
