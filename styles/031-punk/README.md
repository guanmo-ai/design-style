# 朋克复印机 Punk Xerox

一支 18 秒的动效短片，用复印机演示朋克 zine 的视觉语言。剪贴字、胶带和荧光色纸组成封面，镜头钻进网点，从小志内页的黑色笔画里退出，最后拉远到贴满演出海报的墙。

## 四种复印手法

| 手法 | 画面表现 |
| --- | --- |
| 阈值 | 用亮度阈值把灰阶原稿分成墨与纸。进稿时轮换话筒、吉他、音箱和人群。 |
| 网点 | 用圆点、线条、方点和十字重建明暗。网角从 45° 旋至 15°。 |
| 复印代数 | 同一页连续复印，细线逐渐断裂，暗部连成墨团。片中并列展示第 1 至第 64 代。 |
| 纸色 | 保留黑墨，用粉、黄、白、绿四种纸改变海报的观感。 |
