POP!
DESIGN STYLE · NO.005 · MAKING OF

从 0 到 1：这支 18 秒短片是怎么做出来的

没有 Figma、没有 AE、没有素材库：画面、图片、配乐全部是代码。十步，按顺序做。
01
读仓库
看 001—004 的指南、过程和模板。抄结构，不抄画面。
git · README · PROCESS_TEMPLATE
02
选题定调
一句话定义 + 这期最有用的一招：网点代替渐变，黑线圈住颜色。
先写下来，再动手
03
研究
时间线、五条规则、广度清单（拼贴 · 汤罐 · 漫画 · 丝网 · 雕塑 · 今天）。
README.md §1—§7
04
设计令牌
新闻纸 + 红黄蓝 + 黑白 · 黑线 6 / 投影 12 · 网点点距 24 · 1 拍 30 帧。
tokens.ts / .css / .json
05
风格图先行
Python 写 SVG，字宽按真实字体度量算；先把“定帧”做对。
make_svgs.py · fontTools · Chromium
06
时间轴
30 拍：开场 4 · 六章各 3 · 规则 5 · 片尾 3；留一个 STRETCH 调节奏。
timeline.ts · timeline.json
07
视频代码
网点、爆炸框、对话框、网点转场：帧 → 半径、位置。
Remotion 4 · React · TypeScript
08
配乐与音效
numpy 合成冲浪摇滚；“砰”“啵”都写帧号。
make_music.py · numpy · ffmpeg
09
审片与质检
导出要看的帧 → 拼图 → 改。审片后整体放慢 1.2 倍。
stills.mjs · contact_sheet.py · timeline_chart.py
10
渲染发布
分享版 → 封面 → 源码包 → Release → 画廊上架。
remotion render · ffmpeg · git
看 → 改 → 再看：每改一处，只重看受影响的那几帧；节奏留一个旋钮，一行就能放慢
