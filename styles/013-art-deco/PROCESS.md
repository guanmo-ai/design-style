## 1 · 选题

装饰艺术是 009 选题时的三个候选之一，三张风格图已经做完放在 `drafts/`。这次直接接着做，省掉一轮候选。期号取 013：007、010、011、012 已有其他分支在做。

**定调：**

- 一句话：*先立一条中轴，所有东西从中轴往两边同时长。*
- 这一期对设计师最有用的一招：**中轴**。阶梯、放射、三线都只是“从中轴长出来的东西”。
- 和前几期的反差：001—009 大多是浅底、高饱和、平面；这一期是深底、金线、对称、隆重。

## 2 · 第一版为什么被打回来

第一版（git 历史里可以找到）也是“镜像”：所有东西从中轴 scaleX 打开、合回中轴，再加一个楼层指示盘当章节。主人审片的结论是**动效太普通**：

- 动作只有一种——平面上的“打开 / 合上”，没有纵深，没有光，像一页页幻灯片；
- 每章都是“东西长出来 → 停住 → 字幕”，节奏一样，信息密度低；
- 网页和手机那一段占了 3 秒，却没有新的动作。

主人的要求：**动效优先，至少和设计并重；网页 / 手机的展示可以不要。**

## 3 · 第二版：一镜到底的四个大动作

规矩还是**镜像**，但不再只用一种动作；金色从“颜色”变成“光”。

| 动作 | 做法 | 为什么是 Deco |
|---|---|---|
| **光顺着金线跑** | 一段 `pathLength=1` 的短虚线沿路径移动，外面裹两层宽而淡的同路径描边当光晕（不用滤镜）；落点上亮一颗十字星芒 | 金是材质：Deco 的金属线脚在灯下就是这样闪的 |
| **真纵深的隧道** | 每道拱门是一张放在 z 上的平面，缩放 = F / (z − 镜头 z)；镜头匀速前进，每半拍擦过一道 | 无线电城音乐厅一圈套一圈的金拱 |
| **万花筒** | 只画半个扇区（15°），镜像 + 旋转复制 24 份（`<use>`）；元素按指数往外流，看起来无限放大 | 1930 年代巴斯比·伯克利歌舞片的俯拍 |
| **城市与上升镜头** | 三层纵深 + 主楼，各自按自己的 z 投影；镜头 y 往上、z 往前推，远处的楼动得慢；窗户合成一条 path，几千扇也不慢 | 纽约摩天楼、探照灯首映夜 |

再加两个小的：规则牌子从纵深里**翻转**着飞来（scaleX = cos θ + skewY 假透视，转到背面时显示背板），片尾 ART / DECO **先描边再填金**（`<text>` 的 `stroke-dasharray` 对每个字形单独生效）。

换场全部是“同一个东西接力”：海报的拱窗 → 隧道 → 玫瑰窗 → 万花筒 → 太阳 → 天际线 → 牌子冲向镜头 → 海报。没有一次淡入淡出。

## 4 · 为推特做的事

- **第一帧 = 海报 = 最后一帧。** 0.03 秒光就开始顺着画框跑，0.8 秒镜头开始推进拱窗。
- **首尾无缝。** 片尾最后 0.9 秒完全静止在海报上；最后一记 F 大九和弦和混响尾巴折回开头。开场推进拱窗用到的遮罩只在需要时才挂上——挂着遮罩时 Chromium 的光栅化会有一点不同，第一帧就和最后一帧对不上。
- **静音能看懂。** 每条规则都写在画面下方的字幕牌上：规则名在中轴左边，说明在中轴右边。
- **镜头不抖。** 只推、升、拉。

## 5 · 风格图

前三张沿用草稿（期号改成 013）。第四张是**五步教程**：立中轴 → 一线变三线 → 阶梯收分 → 放射藏光 → 金只给线，每一步只加一样东西；最后一格是错误示范（圆角 + 满屏金底 + 粗密射线 = 土豪，不是 Deco）。

金色在 SVG 里统一用一条斜向多段渐变（`userSpaceOnUse`），线再细也有明暗；大面积低不透明度的金色楔形预先用 `mix()` 算成实色，避免 Chromium 分块色差。视频里沿用同一个函数。

## 6 · 分镜与节拍

![时间轴](process/04-timeline.png)

120 BPM，1 拍 = 30 帧，20 秒 = 10 小节。开场 3 拍、01 三线 6 拍、02 放射 7 拍、03 阶梯 10 拍、五条规则 6 拍、片尾 8 拍。隧道里每半拍（15 帧）擦过一道门；万花筒每拍一次脉冲；主楼落在拍点上；牌子相隔半拍飞到。

## 7 · 声音

- **摇摆爵士**：低音提琴走路贝斯（每拍一个音，换和弦前一拍半音靠近）、钢琴查尔斯顿式反拍（正拍 + 第二拍的反拍，反拍在 2/3 拍）、刷子军鼓、叮叮镲。全程不变速。
- **和弦**：Fmaj9（开场）→ Dm9 · Gm9 · C13（隧道）→ Fmaj9 · Dm9 · B♭maj9 · A7♭13（万花筒）→ Gm9 · C13（主楼落地）· Fmaj9 · B♭maj9 · A7（上升到尖顶）→ … → Fmaj9（回到海报）。
- **镜像写进声音**：左右成对的东西，音效也是一左一右各一份（声像 ±0.15—0.9）。隧道里每道门擦过时，门两边各一道风声；天际线成对升起时，钢琴声像从外往里收；规则牌子从中间往两边飞来，声音也从中间往两边走。
- **金色 = 钢片琴**：光顺着线跑是一串五声音阶上行；隧道里每道门上的光各一声，十一声连成一句旋律。
- **音效让出 BGM**：音效总线 −2 dB；风声、滴答都压在背景音乐下面。

## 8 · 渲染

```bash
npm run render:013     # 先合成配乐，再渲染 out/013-art-deco-master.mp4
npm run images:013     # 4 张风格图：preview/*.svg + png/*.png
```

整片是一张 SVG（一个 `<svg>` 里画所有东西，渐变和裁剪只定义一次）。运动模糊 8 次采样，快门 180°——隧道、上升和翻牌都很快，靠它把速度画出来。本机 1200 帧约 7 分钟，成片约 16 MB。

## 9 · 踩坑

- **SVG 字距会加在最后一个字后面。** 右对齐的左半句因此离中轴远了一个字距，左右看起来不对称。`T` 组件在 `text-anchor: end` 时把 x 往右补一个字距。
- **Poiret One 只有 400 一个字重。** 写成 600 会被浏览器假加粗，线条糊掉；镜像字幕遇到 Poiret 时强制 400。
- **同一个 id 的渐变 / 裁剪在多处使用。** 开场和片尾各有一张海报；`Scene` 加了 id 前缀。
- **发光不用滤镜。** `feGaussianBlur` 的滤镜区域按包围盒算，竖直细线的包围盒宽度是 0，光晕会被裁掉；放在缩放的组里还要换算坐标。改成同一条路径叠三层描边（宽而淡 → 细而亮），又快又稳。
- **几千扇窗户。** 每扇窗一个 `<rect>` 会拖慢每帧 8 次采样的运动模糊；改成每一级楼身只有两条 path（亮窗、暗窗），用 `M x y h w v h h -w Z` 拼起来。
- **万花筒只画半个扇区。** 内容放进 `<defs>`，用 24 个 `<use>` 旋转 / 镜像复制，每帧只算一份。
- **`CameraMotionBlur` 会把深色渐变量化成色带。** 它把每个采样以 1/n 不透明度用 `plus-lighter` 相加，每一层先量化到 8 位：黑曜 (14, 13, 11) 变成 (16, 16, 8)，背景的径向光晕变成 8 级一档、还偏绿的色环。改成自己的 `Blur`：普通叠加，第 k 层不透明度 1/k，逐层求平均——不动的地方逐像素不变，首帧与末帧也逐像素一致。成片同时标上 `--color-space=bt709`。
- **GitHub 的 `raw` 跳转在本环境被拦。** 字体改从 `raw.githubusercontent.com` 下载。
