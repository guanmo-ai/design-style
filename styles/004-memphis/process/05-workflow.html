DESIGN STYLE · NO.004 · MAKING OF

从 0 到 1：这支 15 秒短片是怎么做出来的

没有 Figma、没有 AE、没有素材库：画面、图片、配乐全部是代码。十步，按顺序做。
01
读仓库
看 001—003 的指南、过程和模板。抄结构，不抄画面。
git · README · PROCESS_TEMPLATE
02
选题定调
一句话定义 + 这期最有用的一招：一块一色，描黑边，歪一点。
先写下来，再动手
03
研究
时间线、五条规则、广度清单（唱片 · 家具 · 灯 · 椅子 · 贴面 · 今天）。
README.md §1—§7
04
设计令牌
纸 + 6 糖果色 + 黑 · 描边 5 / 投影 10 · 歪 6/12/18° · 120 BPM = 30 帧一拍。
tokens.ts / .css / .json
05
风格图先行
Python 写 SVG，字宽用 Fredoka 真实度量；先把“定帧”做对。
make_svgs.py · fontTools · Chromium
06
时间轴
30 拍 × 30 帧：开场 4 · 六章各 3 · 规则 5 · 片尾 3。
timeline.ts · timeline.json
07
视频代码
每块积木：掉下来 → 压扁 0.24 → 回弹。f → 位置、缩放。
Remotion 4 · React · TypeScript
08
配乐与音效
numpy 合成 Italo-disco，“咚”“嘣”“嘀”都写帧号，−14 LUFS。
make_music.py · numpy · ffmpeg
09
质检循环
只导出要看的帧 → 拼图 → 改 → 再看。转场必看中间帧。
stills.mjs · contact_sheet.py · timeline_chart.py
10
渲染发布
分享版 → 封面 → 源码包 → Release → 画廊上架。
remotion render · ffmpeg · git
