# 来源与说明

- 电影、主视觉与界面图：本仓库 `drafts/point-cloud/`，署名观默 @guanmo_ai。
- Stanford Bunny：Greg Turk、Marc Levoy，来源 http://graphics.stanford.edu/data/3Dscanrep/ 。仓库转换记录见 `drafts/point-cloud/data/make_bunny.py`；模型沿用来源条款，不额外赋予CC0或无条件商用许可。
- 图解中文字体：Noto Sans SC，SIL OFL 1.1；本次SVG内嵌字形子集。完整字体许可随附于 [OFL-notosanssc.txt](fonts/OFL-notosanssc.txt)，并嵌入可下载SVG的metadata；字体下载见仓库 `scripts/fetch_fonts.sh`。
