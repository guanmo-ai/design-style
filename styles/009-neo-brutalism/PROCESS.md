## 1 · 选题：三个候选，选一个

这一期先做了三套候选，每套三张图（海报、速查卡、App 概念），再由主人挑：

| 候选 | 对设计师的用处 | 动效潜力 | 结果 |
|---|---|---|---|
| 装饰艺术 Art Deco | 品牌、包装、酒店餐饮的“高级感”；上海外滩 | 金线中轴生长、折扇放射、摩天楼收分 | 留作后续（`drafts/art-deco`） |
| 欧普艺术 Op Art | 五种带参数的“让平面动起来”的方法 | 全片由公式驱动 | 留作后续（`drafts/op-art`） |
| **新粗野主义** | **今天做界面马上能用：一组能直接写进 CSS 的数字** | 砸、按、推、叠 | **本期** |

另外四个方向（极简、剪纸、粘土拟态、等距）已有其他分支在做，候选里都避开了。

**这一期最有用的一招：** *按下 = 元素滑到阴影的位置，阴影归零。* 所有画面围着这一招转。

**定调：**

- 一句话：*不讨好，只诚实。*
- 叙事：第一帧是片尾海报，一按就炸开，十三颗键帽浮上来；之后每一章一个主角（笔、阶梯、按钮网格），教一条规则。
- 发布目标是推特：第一帧要能当封面，0.2 秒内要有动作，静音也看得懂，首尾无缝循环。
- 接力：每一章都是一张整屏“卡片”，换章 = 推走 / 从上面砸下来 / 向上抽走 / 一张张叠上去。不淡入淡出。
- 动效只有一条物理：**阴影长度 = 高度 z**。抬起来阴影变长、往左上浮；落下去缩回 rest（接触时略短一下）；按下去归零。

## 2 · 研究

写进画面和指南之前核对过：

- 1952 马赛公寓（Unité d'Habitation）落成，清水混凝土 *béton brut*；阳台侧墙的红黄蓝绿是勒·柯布西耶的 polychromy。短片 1952 段的彩色窗侧墙就是这个。
- 1953—1955 史密森夫妇提出 New Brutalism；1955.12 Reyner Banham 在 *Architectural Review* 发表 *The New Brutalism*。
- 2014 brutalistwebsites.com（Pascal Deville）开始收集“粗野主义网页”：默认字体、蓝色下划线链接、表格、1px 线。
- 2021 前后 Gumroad 改版等产品把它做成界面系统，“Neo-Brutalism / Neubrutalism”成为通称。
- 对比度用 WCAG 相对亮度公式逐个算过（黑字在黄 14.5、粉 10.2、草绿 15.8、蓝 8.4、橙 8.1、暖白 19.6 : 1）。

## 3 · 先有“盒子”，再有画面

`video/ui.tsx` 的 `Box` 就是整个风格：黑描边 + `box-shadow: Npx Npx 0 #000` + 一个按下进度 `p`——`p = 1` 时元素位移 N、阴影归零。画面里所有按钮、卡片、筹码、色块、整屏章节卡片都是它。短片用的是真正的 CSS，不是“画出来的阴影”。

两条节奏函数：

- `press(f, at)`：4 帧线性压到底，停，6 帧线性弹回（≈100ms，和 `tokens.css` 的按钮一致）。
- `slam(f, at)` / `slamBig(f, at)`：落地弹簧。小元素允许约 15% 过冲；整屏卡片（上千像素的位移）用更大的阻尼，只过冲约 3%，在拍点上停稳。

## 6 · 声音

`audio/make_music.py` 用 numpy 从零合成，没有采样库：

- 120 BPM，E 小调（Em · C · G · D，每章一小节）→ 五个词每拍换一个和弦 → 片尾落到 G 大调。
- 多算 1.5 秒，再把 15 秒之后的余音（最后那记 G 大和弦和混响尾巴）折回开头：循环播放时，第一帧的海报接着上一遍的余音。
- 音色是“实心”的：只留奇次谐波的方波贝斯、反拍的方波和弦、909 式底鼓与拍手、木琴旋律。
- 音效对着画面写帧号：机械键盘逐字打 CSS、黑框“盖章”、阴影“啵”、滑块拉链声、按钮“咔嗒”、收银“叮”、混凝土落地、翻牌哗啦、二十个色块依次弹出。
- f870 所有阴影一起按下时，音乐压低 9 帧；f880 弹回 G 大和弦。
- 响度 −14 LUFS，真峰值 < −1 dBTP。

## 8 · 踩坑

| 问题 | 处理 |
|---|---|
| 快门 180° / 5 次采样的运动模糊，在整屏砸入时拖出一串残影，和“硬边”的风格冲突 | 快门收到 120°、采样加到 8；模糊只抹平最快的位移 |
| 整屏卡片用小弹簧砸入，过冲 300px，拍点那一帧还在晃 | 新增 `slamBig`（阻尼 22），提前 12 帧起跳，拍点上落稳 |
| 手机屏挡住右上角的章节筹码 | 手机整体下移 62px，余额卡、列表压缩，按钮仍在画内 |
| “SHADOW”在卡片里溢出 | 字宽从 125% 收到 112% |
| 偏移标注被砸下来的草绿卡片盖住 | 三张卡片重新排位，并把阴影改成 4 / 8 / 14，正好演示“层级 = 偏移量” |
| 容器里没有 Times New Roman | 用 Tinos（与 Times 等宽的开源替代）做“浏览器默认样式” |
| 第一版开头是一张白网页，划过去的人不会停；推特自动播放默认静音，第一帧就是封面 | 开场改成片尾海报：f10 一按，f16 炸开，再露出白网页。首尾同一帧（像素级一致），配乐把 15 秒之后的余音折回开头，循环无缝 |
| 每一次落地都用衰减正弦晃镜头，再加 15% 过冲的弹簧，整片一直在颤 | 去掉所有 `shake`，只在六个关键落地点用单向的 `thud`（往下沉一下、不来回）；弹簧阻尼 13 → 17，过冲降到约 5% |
| 第二版审片：中间的“没写 CSS 的网页”不好看；整体动效不如前几期惊艳 | 对照 002 / 004 / 008 抽帧：它们都有一个贯穿全片的接力元素、每一刻只有一个巨大的主角、镜头在动。重写为：键帽（开场）→ 一支笔（01）→ 抬起与阶梯（02）→ 同一面网格从按钮变混凝土、网页、再变回按钮（03—04）；全片改用“高度 z”一条物理；换章用钻进 O、整张画布甩过去、最高的卡撑满全屏 |
| 第三版审片：01 黑框右边的组件是事先摆好的，只有笔在动；节奏太快看不清；少了网页和 App 里的样子 | 01 改为画面全空，笔先画框，元素从框里一个个长出来，拼成注册表单；中间各章放到 2.5 秒，总长 15 → 19.5 秒；新增 05 应用：浏览器落地页 + 手机记账 App，一层层从高处落进来 |
| 第四版审片：节奏还是稍快，01 黑框里看不清 | 不改结构，只在信息最密的两章放慢：01 ×1.14、05 ×1.05，成片 19.5 → 20 秒 |
| 第五版审片：配乐在放慢的两章跟着变慢（约 105 / 114 BPM），前后不一致 | 节奏声部（鼓、贝斯、和弦、旋律）改为按成片时间排、全程 120 BPM；放慢只能按整拍：01 ×1.2（150 → 180 帧，多 1 拍），05 恢复原速，后面所有章节仍在拍点上；只有音效跟着画面走 |
| 发布版 4—5 秒音效偏密 | 原 `day-09` 中画框、盖章、打字、按钮叠在一起，压住了 BGM。2026-10-27 按主人授权，本地源码将 01 黑框（成片 2—5 秒）起音的音效及混响发送降低 3 dB；事件与配乐编排保持原样。已输出原画面搭配新音轨的试听版，尚待试听确认与发布；线上仍为原版，详见 [`docs/HANDOFF.md`](../../docs/HANDOFF.md) |
| 手机上看，代码和说明太小 | 代码从小编辑器改成黑底 40px 代码条；章节代码 30 → 40px、说明 34 → 42px、HUD 22 → 26px；打完字的光标不再闪 |
| 低透明度大面积色块在 Chromium 里分块 | 图里的半透明一律预先算成实色 |
