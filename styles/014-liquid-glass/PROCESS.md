## 1 · 选题

这一期按新流程先出三个候选，每个三张图，不做动效样片：

| 候选 | 一句话 | 动效的招牌动作 |
|---|---|---|
| **液态玻璃** ✓ | 玻璃不发光，只弯光 | 实时折射：一滴玻璃从头接力到尾 |
| 1-bit 抖动 | 灰，是点的密度 | 无限钻进一个像素，像素里又是整张画 |
| 未来主义 | 动的东西，留下它刚才的样子 | 残影由真实轨迹生成，刹车时自己收拢 |

没选上的两个放在 `drafts/`，说明见 [`drafts/README.md`](../../drafts/README.md)。质量标准：超过 001 包豪斯、002 瑞士、布局 01 便当盒、02 瀑布流。

## 2 · 第二版为什么被推翻

第二版是“六页内容排成一排 + 甩镜翻页”，玻璃留在屏幕上、页面从它底下滑过去。主人的评价：**动效很普通**。自己逐秒复盘，问题有四个：

1. **骨架还是幻灯片。** 每章同一个版式（左边大字、右边演示），甩镜只是更花哨的翻页。
2. **动作词汇太少。** 几乎所有动作都是“A → B 插值 + 弹簧”：没有起势、没有跟随与重叠、没有快慢反差、没有镜头纵深。
3. **没做只有玻璃能做的事。** 玻璃只是盖在静止内容上的一块镜片。
4. **只看静帧会骗自己。** 静帧和联系表只能检查构图，检查不了时间。

## 3 · 第三版：只做玻璃才能做的动作

| 新动作 | 做法 |
|---|---|
| **落下与涟漪** | 水滴先往上一收（起势），再加速落向墙面：离墙越近越小，影子与光池向它收拢；砸下去的那一帧压扁、光池猛亮，同时在着色器里放一圈往外跑的波包，把整张内容沿径向弯过去 |
| **甩出去的小水珠** | 落地时甩出三颗：飞行时是单独一组（有自己的高度、影子离得远），落地后并回主组，被拉回去的路上与主体的距离进入 smooth-min 半径，颈自然长出来 |
| **光池（影子 + 焦散）** | 每块玻璃有“离墙高度”：影子往光的反方向偏 10 + 70·高度 px、越高越散；影子里面有一圈聚焦的亮环和一张流动的光网（经典的水下焦散迭代；每层的时间倍数取整数，全片走一圈正好回到原样）。只有液态玻璃有光池，Aqua / 毛玻璃没有 |
| **穿过玻璃** | 镜片的取样可以在两张贴图之间混合：镜头推进镜片时，镜片里显示“下一个世界”（按推进的倍数缩放、中心对准镜片）；镜片盖满屏幕的那一帧换平面，盖满屏幕的镜片再收回成下一章的主角。全片用了两次 |
| **跳跃与空中变形** | 二十五年那一章，玻璃沿时间尺一跳一跳：起跳前压扁、空中划弧线（高度 = 抛物线，影子跟着分开又收拢）并换形状与材质、落地压扁回弹，镜头带滞后地跟拍 |
| **3D 设备** | 手机 / 浏览器屏幕各自先画、过一遍玻璃着色器进离屏缓冲，再用单应矩阵贴进透视四边形；设备一转，屏幕上的高光带滑过，设备里玻璃的光照方向也跟着转 |
| **运动模糊** | 每帧估计屏幕上最快的东西（镜头 + 每块玻璃），快的帧取 2—6 个子帧、按常量透明度 1/k 逐层平均；换平面的那一帧不跨子帧 |

**动作的基本件**（`video/motion.ts`）：起势 `anticLand`、约 5% 过冲的落地 `land`（阻尼比 0.69 的解析解）、液体抖动 `wobble`（衰减正弦，抖形状不抖位置）、抛物线 `ballistic`、带滞后的跟随 `follow`（对目标轨迹做指数加权平均，镜头跟拍用）。全部是时间的纯函数，子帧可以取小数。

## 4 · 给自己装上“看时间”的眼睛

只看静帧检查不了时间感，所以加了两样工具：

- **剧本曲线**：`node scripts/motion_curves.mjs styles/014-liquid-glass/video/scene.ts out/curves.json` 把每一帧的镜头和每块玻璃导出来，`python3 scripts/plot_curves.py out/curves.json OUT.png` 画出主角的位置、大小、速度、离墙高度与镜头速度，竖线是拍点。第一次画就查出三个静帧里看不出的错：穿过玻璃那一帧主角位置跳了一下（旧镜头多活了一帧）、换平面时运动模糊会把两个世界糊在一起、开场镜头跟得太慢，镜片跑出画面一半。
- **胶片条**：`node scripts/stills_batch.mjs <合成> <目录> 4-64:4` 一次打包、按步长出一段连续帧，`python3 scripts/strip.py` 拼成带帧号的胶片条，逐帧检查起势、过冲、节奏。“落下”一开始看起来几乎不动，就是在胶片条上发现的：改成水滴从更近处（更大）落下、缩小 38%，影子更深。

## 5 · 为推特做的事

- **第一帧就好看，0 帧就在动。** 第一帧是字墙海报，一滴玻璃挂在右上、在抖，光池落在 GLASS 上；第 12 帧开始落下。
- **首尾无缝。** 片尾水滴升回挂着的位置，抖动的周期（30 / 20 / 60 帧）是全片长度的约数，光网与彩色场的漂移也按全片周期走；配乐的余音折回开头。
- **静音能看懂。** 每章的规则用 52—104px 大字从遮罩里升起；bevel、chroma、gap 的读数跟着画面实时变；五个年代都写出配方；五条规则单独一章。
- **镜头不抖。** 只在两个落点往下“咚”一下（f30 落下、f510 落到 2025），单向，14 帧。

## 6 · 风格图

- **海报**：字墙 + 网格 + 彩色场，四块玻璃压上去——横跨 GLASS 的大胶囊、一颗大水滴、两滴正在融合的小水滴、压着一句话的胶囊。
- **速查卡**：一块玻璃拆成五层（内容 / 折射 / 底色 / 高光 / 投影）、截面与位移曲线、三种厚度并排、三条规则、CSS。
- **App 概念**：音乐播放页。返回 / 更多是薄玻璃，播放浮层是厚玻璃 + 磨砂，标签栏和搜索融成一块。
- **五步教程**：同一块胶囊、同一张背景，每步只加一层：形状 → 折射 → 色散 → 高光 → 投影；最后是误区（模糊 + 白边 = Glassmorphism）。

图里的玻璃也是真折射：`glass.py` 用 numpy 按形状算出位移贴图（2 倍密度），SVG 里用 `feImage` + `feDisplacementMap`，R / G / B 三个通道各做一次再合起来；贴图直接内嵌成 PNG data URI，避免被构建脚本转成有损 WebP。

## 7 · 分镜与节拍

![时间轴](process/04-timeline.png)

120 BPM，1 拍 = 30 帧，20 秒 = 10 小节。落下 5 拍（f30 = 第 2 拍砸下去）、01 弯光 5 拍、02 二十五年 8 拍（每 1.5 拍一跳）、03 融合 5 拍、04 界面 7 拍、五条规则 5 拍（放大镜每 0.8 拍一条）、回到开始 5 拍。

## 8 · 声音

- **玻璃拨奏**：FM 合成，调制比 3.5——不和谐的泛音听起来就是玻璃。十六分音符琶音。
- **和声**：Dmaj9 · Bm9 · Gmaj9♯11 · A6/9 · Dmaj9 · F♯m7 · Gmaj9 · A6/9 · Bm9 · Gmaj9 → 回到 Dmaj9（循环接上）。
- **鼓在 f120 进来、片尾水滴升起前退下**：开场和片尾只有铺底与玻璃铃的同一句动机，首尾在声音上也接得上。
- **音效对准画面**：落下是“吸气 → 下滑的哨音 → 砸进液体的‘啵’ + 亚低音 + 一道往下走的水声（涟漪）”；小水珠甩出去三声高铃、落回三声“啵”、被拉回去三声上扬的“啵”；穿过玻璃是倒放式的吸气 + 风声 + 一记闷响；五个年代各一个音色；两滴合一是一声黏稠的“咕”；点按钮是轻点 + 一小段水声；放大镜一拍一条，玻璃铃一级一级往上。音效总线 −4 dB，让出背景音乐。

## 9 · 渲染

```bash
npm run render:014     # 先合成配乐，再渲染 out/014-liquid-glass-master.mp4（WebGL：--gl=swangle）
npm run images:014     # 4 张风格图：preview/*.svg + png/*.png
```

没有显卡的环境用 SwiftShader（`--gl=swangle`）跑 WebGL2；涟漪、光池、多个子帧都在 CPU 上算，1200 帧要一个多小时。

## 10 · 踩坑

- **折射要“往里”取样。** 往外取样，边缘会出现玻璃外面的东西，看起来像破了；往里取样才是凸透镜。
- **光网别画成等高线。** 第一版光网是几层正弦取 `1 − |sin|` 的尖峰，出来是一圈圈“地形图”；换成水下焦散的迭代公式，才是一格一格的亮丝。
- **换平面那一帧不能做运动模糊。** 两个平面的坐标不连续：按坐标算速度会以为镜头飞了几千像素，取子帧又会把两个世界叠在一起。速度估计遇到换平面记 0，子帧不跨过那一刻。
- **缓冲的贴图要和画布同向。** 画到屏幕时翻转 y，画进离屏缓冲时不翻，这样设备屏幕和主内容的贴图坐标一致。
- **画布上传不预乘。** 压在玻璃上的字（带透明）上传时 `UNPACK_PREMULTIPLY_ALPHA` 关掉，合成时直接按 alpha 混合，不要再除。
- **Remotion 渲染时不能依赖上一帧。** 所有状态（弹簧、跟随、滚动、镜头）都是时间的纯函数；跟随用“对过去 6τ 帧的指数加权平均”代替积分。
- **字色自适应要读“玻璃后面”。** 读的是内容层（玻璃还没画上去）在字底下的平均亮度，0.42 以下转白、0.55 以上转黑，中间按比例过渡，不会闪。
- **SVG 位移贴图会被转成有损 WebP。** 直接写成 data URI 就不会被动到。
