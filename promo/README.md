# 宣传片：同一个圆 × 21 种样子

Design Style 这个仓库的 15 秒宣传片。1920 × 1080 · 60fps · 150 BPM（一拍 24 帧）· Remotion（SVG + Canvas 2D，不用 WebGL）· 配乐由 Python 合成。

```bash
npm ci && npm run fonts        # 依赖与开源字体
npm run render:promo           # 配乐 → 墙上的 21 张小图 → 正片 out/design-style-promo.mp4
npm run preview:promo          # 半分辨率草稿 out/promo-preview.mp4
npm run studio                 # 在浏览器里逐帧看（合成 Promo）
```

## 一句话

**风格是一套规则：同一个圆，换一套规则，就是另一种样子。**

所以全片只有一个主角——画面正中、半径 210 的一个圆，圆心和大小从头到尾不变。每一拍它被“盖”一次章，周围的世界整个换成下一种风格；19 种风格走完，镜头拉远，才发现每一个样子都是画廊墙上的一格，翻过来就是仓库里真实的那一期。

## 分镜

| 帧 | 段落 | 画面 |
|---|---|---|
| 0—96 | 开场 | 设计工具里刚画出来的一个圆：默认灰 `#D9D9D9`、蓝色选框、`420 × 420`。左下角打出 `<Circle style="none" />`，光标去点 `style` |
| 96—288 | 前四种，每种两拍 | 包豪斯（三角和方从圆背后滑出来）→ 红方块涨满全屏、收成瑞士风格的红圆 → 整张网格转 30°，接成构成主义的主轴，红楔子刺两次 → 孟菲斯落地压扁，黄色网点长满 |
| 288—624 | 十四种，每种一拍 | 波普 · Y2K · 孔版印刷 · 新粗野主义 · 装饰艺术 · 液态玻璃 · 未来主义 · 中世纪现代 · 微缩景观 · 低多边形 · 字符画 · 生成艺术 · 点云 · 液态金属 |
| 624—672 | 水墨，两拍 | 全片唯一一次留白：音乐停，一笔画出圆相，一滴落进圆心，盖一枚“墨” |
| 672—768 | 画廊墙 | 从水墨那一格拉远（对数插值）：5 × 5 的墙，21 个圆 + 一格字标。翻牌的波从水墨往外传，露出 21 期真实的封面；镜头再推进字标格 |
| 768—900 | 片尾 | 圆缩成字标 `Design.style` 里的那个点，两个词从点的背后滑出来；六件套一拍半一个弹出；最后盖章“观默” |

固定外框：左上字标，右上 `0N / 21`，左下 `<Circle style="…" />`（每次换章先乱码再落定），右下中文名和年代，底部 21 颗进度点。

## 每种风格里，圆是什么

| 期 | 圆 | 那一期的规则（数值取自各期 `tokens`） |
|---|---|---|
| 001 包豪斯 | 蓝色的圆 | 康定斯基 1923：三角黄、方红、圆蓝；三个形状站在同一条线上 |
| 002 瑞士 | 红色的圆 | 12 × 6 网格、模块 122、间距 24；字压在圆上的部分反白 |
| 003 构成主义 | 被红楔子刺中的白圆 | 主轴 −30°、副轴 60°；先往回抽 9 帧再刺 |
| 004 孟菲斯 | 糖果色的球 | 黑描边 + 硬投影；落地压扁 0.24，以底边为原点 |
| 005 波普 | 印出来的红球 | 网点代替渐变，粗黑线 + 偏移的黑 |
| 006 Y2K | 果冻球 | Aqua 高光上半截硬边，铬环用 `tokens` 里的六个色标 |
| 008 孔版 | 粉版 × 黄版 | 同一个圆印两次，偏 30 × 20；正片叠底，每 4 帧“沸腾”一次 |
| 009 新粗野 | 按钮 | 阴影 26px；按下去 = 5 帧线性滑到阴影的位置 |
| 013 装饰艺术 | 日出徽章 | 三线（4 / 1.6 / 1.6），一切从中轴打开，过冲约 5% |
| 014 液态玻璃 | 透镜 | 逐像素折射：偏移 = 内法线 × 坡度^2.4，三个通道弯得不一样多 |
| 015 未来主义 | 急刹的轮子 | 6 个残影、间隔 3 帧；字宽 = 62 + 63 × 速度 |
| 017 中世纪现代 | 星芒钟的钟面 | 剪纸的抖边 + 落在桌面上的影子 |
| 018 微缩景观 | 圆形底座 | 平面斜轴测（底座还是正圆）；积木砸下来压扁 0.16；远近两排发虚 |
| 019 低多边形 | 80 面的小星球 | 一个面一个颜色，三档明暗，没有渐变 |
| 020 字符画 | 甜甜圈 | 亮度 → 12 个字符；先乱码，再落定 |
| 021 生成艺术 | 流场里的障碍 | 势流绕圆柱：ψ = U(r − a²/r)sinθ |
| 022 点云 | 9000 个点的球 | 从散开聚回来；扫描面扫过的按高度上色 |
| 023 液态金属 | 镜面球 | 逐像素反射一个手写的摄影棚；形状不动，世界在转 |
| 024 水墨 | 圆相 | 30 根笔毛，越往后越干 |

## 签名物理

全片只有一种：**盖章**。每个拍点，圆 7 帧从 1.3 倍压回 1；换章前 5 帧先缩到 0.93 吸一口气（`kit.tsx` 的 `pulse`）。配乐里每次换章是同一个“章”的声音，音高跟着和弦走。

## 文件

```
promo/
├─ timeline.json          # 时间轴：画面和配乐读同一份
├─ video/
│  ├─ Promo.tsx           # 主合成：分段、运动模糊（子帧不跨硬切）、外框、颗粒
│  ├─ kit.tsx             # 缓动、盖章、随机数、字体、画布
│  ├─ hook.tsx            # 开场 + 固定外框
│  ├─ scenes/a—e.tsx      # 19 种风格
│  └─ wall.tsx            # 画廊墙 + 片尾 + 两种布局的小图
├─ audio/make_music.py    # 配乐（C 大调，−14 LUFS）；check_music.py 出对齐检查图
├─ make_tiles.mjs         # 把 21 个圆定格成墙上的小图
└─ make.sh                # 一条命令出片
```

墙背面的 21 张封面直接用各期的 `video/cover.jpg`。字体全部是仓库已有的开源字体；片尾字标用画廊的 Newsreader。
