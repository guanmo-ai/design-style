# 设计笔记：主人对短片的要求

新一期开工前先读这份。下面是做 009 新粗野主义时，主人审片给出的反馈，适用于以后每一期。

## 目标

- **推特爆款。** 设计师看了觉得真有用，动效要做到让人觉得“做得非常好”。
- **对设计师有用。** 给能直接拿走的东西：规则、数值、CSS、配色、字体，以及落到真实界面里的样子。

## 短片

1. **第一帧就要好看。** 推特静音自动播放，第一帧就是封面；0.2 秒内要有动作。首尾同一帧，配乐的余音折回开头，循环播放看不出接缝。
2. **镜头不要一直抖。** 只在少数关键落地点往下“咚”一下（单向，不来回颤）；落地弹簧的过冲控制在 5% 左右。
3. **动效要惊艳，不要“老实”。** 主人审片时说过“太老实”的反例：东西事先摆好、只有局部在动，整片像幻灯片。怎么做到惊艳，不设规则，放开发挥。

   下面只是做过、效果不错的参考，可以用、可以混搭，也鼓励完全换一种思路：
   - 元素一个个长出来、落进来；
   - 某一刻让一个巨大的主角占满画面；
   - 用同一个东西接力换章（钻进字母的孔、整张画布甩过去、一张卡撑满全屏、同一面网格变形）；
   - 镜头本身在动；
   - 给整片定一条物理规则（009 用的是“阴影长度 = 高度”）。

4. **节奏宁可慢一点，让人看得清。** 总长 15—20 秒，按内容定，不必卡死 15 秒。信息密的章节多留时间。
5. **一定要有落到网页和手机 App 里的样子。** 让设计师看到风格用在真实界面里的效果。
6. **手机上要看得清。** 代码和说明用大字，静音也能看懂，每条规则都写在画面上。

## 013 装饰艺术留下的经验

- **主人对第一版的评价是“动效太普通”。** 只有平面上的“从中轴打开 / 合上”（scaleX、淡入淡出），没有纵深、没有光，像幻灯片。第二版改成一镜到底：真纵深的隧道（每层按 F / (z − 镜头 z) 缩放）、光顺着线跑 + 星芒、万花筒（半扇区 + `<use>` 镜像复制）、三层视差的城市 + 贴着主楼上升的镜头。主人：“比刚才好一点，但还不算顶尖。”**动效优先级不低于设计；网页 / 手机展示可选，没有新动作就不要占时间。**
- **不要用 `@remotion/motion-blur` 的 `CameraMotionBlur`。** 它用 plus-lighter 叠加 1/n 不透明度的采样，深色渐变会被量化成偏绿的色带。用 013 的 `Blur`（`styles/013-art-deco/video/ArtDeco.tsx`）：普通叠加，第 k 层不透明度 1/k；静止像素不变，首尾帧逐像素一致。渲染加 `--color-space=bt709`。
- **成片直接发布，不用 Codex 重新渲染。** 在 `release-assets` 分支建 `day-NN/`（mp4 + 源码 zip + SHA256SUMS + release.json + notes.md，照 day-09 / day-13），推送后 `publish-release.yml` 自动建 Release。
- **字体：** 云端环境里 `github.com/.../raw/` 会 403，改用 `raw.githubusercontent.com/google/fonts/main/ofl/...`。

## 配乐

- **全片一个速度，不变速。** 画面要放慢只能按整拍放，后面的剪辑点仍要落在拍点上；不要让某一段的 BGM 跟着变慢。
- **音效别盖过 BGM。** 一段里音效太密时先降音量或删掉一部分（009 的 4—5 秒出过这个问题，已在 day-09-audio-v2 调小音效）。

## 流程

- **先出候选。** 先给三个候选风格，各做三张图（海报、速查卡、App 概念）；主人选定后再做全套。没选上的放进 `drafts/`，留着以后做。
- **先看前几期。** 新一期动效的完成度要不低于 002 瑞士、004 孟菲斯、008 孔版印刷。拿不准时下载它们的 Release 成片逐帧对比。
- **分工。** Claude 只做设计（选题、风格图、画面、配乐）；工程、发布、部署交给 Codex，写进 `docs/HANDOFF.md`。
