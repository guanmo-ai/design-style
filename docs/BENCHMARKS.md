## 1 · 五期共有的骨架

它们看起来各不相同，其实是同一副骨架。下面每一条，五期里至少有四期做到了。

| # | 做法 | 例子 |
|:-:|---|---|
| 1 | **开工前先写“这一期最有用的一招”**，一句话，所有画面和图都围着它转 | 003「把轴转 30°，版面就开始动」；004「一块一色，描一圈黑边，再歪一点」；005「用网点代替渐变，用粗黑线圈住每块颜色」 |
| 2 | **一章 = 一件真实的代表作**，每章换一个领域，证明风格不只是一种画风 | 003：海报《书》→ 电影海报 → 塔特林塔 → 印花布 → 舞台 → 书；004：唱片 → Carlton 书架 → Tahiti 台灯 → First 椅 → Bacterio 纹样 → 手机；001：色环 → 字体 → 海报 → 校舍 → 钢管椅 → 台灯 → 织物 → 舞者 |
| 3 | **每章只有一个主角 + 一个动作 + 一行标签，1 秒内看懂** | 001 v1 只讲“红黄蓝 + 圆方三角”，被反馈“没有把各种风格展示出来”，v2 改成一章一件作品，之后每期沿用 |
| 4 | **代表作是一块块“搭”出来的**，零件落在八分 / 十六分音符上。观众看的是“它是怎么做成的”，不只是“它长什么样” | 004 书架：底座落下、立柱长高、隔板一对对弹出；003 舞台：梁、坡道、斜撑按十六分音符搭起来，先“长”再“铆” |
| 5 | **整片只用一种“签名物理”**，每个零件都按它动；这种物理就是这个风格的材料感 | 003 盖章：7 帧从 1.5 倍压到 1 + 冲击抖动；004 落地压扁 0.24、以底边为原点、再回弹；005 Slap：7 帧从 1.35 倍拍到 1，软雕塑压扁 0.34；L02 两种：落下（重力 + 4.5% 弹）和流动 |
| 6 | **换幕用风格自己的元素接力，全片不硬切**，上一章最后一拍的东西就是下一章的开头 | 003 形状接力：嘴 → 镜头 → 瞳孔 → 斜带 → 圆 → 红轮 → 红页 → 红方块；004 颜色接力：糖果色带波浪边扫过来；005 网点接力：下一章底色以网点长出来连成一片；001 用圆 / 方 / 三角擦除；L02 从头到尾是同一批 26 张卡片在重排 |
| 7 | **固定外框**：左上章节标题（编号 + 名称 + 年份 + 作品名 + 一句话），底栏 `0N / 0M` 进度。快切时观众始终知道自己在哪 | 五期都有 |
| 8 | **五条规则 = 五张卡片，每张卡用自己的方法演示自己**，一拍一张砸下来 | 003「斜线」斜放、「大字」大到出血；004「黑描边」一个圆先只有颜色，再描线，再滑出投影；005「网点」长出一片由大到小的红点；L02 规则段音乐被低通“闷住”，每条一声钟 |
| 9 | **前 0.5 秒就有“哇”**，第一下重击就是整片的定调 | 003 f25 红楔子击中 + 铁砧；004 f14 第一块积木砸下；005 f2 起网点长满、f70 爆炸框砸下 |
| 10 | **结尾回到开场的构图**，首尾呼应 | 003 再刺一次；004 积木再砸一次；005 爆炸框再砸一次；001 九章缩成九宫格当封面 |
| 11 | **一整首配乐 + 每个零件一个声音**，音色是这个风格时代的乐器，时间点直接写帧号 | 003 莫索洛夫《铁工厂》式工厂节奏 + 铁砧 / 打字机 / 盖章；004 Italo Disco + 卡通“咚”；L02 卡片落地的水滴声按列摆声像 |
| 12 | **第四张图做“怎么改”的教程**：同一张普通海报，四步改成这个风格，每步只改一件事 | 003、004、005 都是；设计师最常拿去用的就是这一张 |

**节奏：** 15—18 秒，60fps；开场 4 拍，每章 3 拍（约 1.25—1.5 秒），规则 5 拍，片尾 3—6 拍。005 被反馈“节奏有点快”，整体放慢 1.2 倍（`STRETCH`，一行改动，画面和配乐一起变慢）——**信息多的章节至少 1.5 秒。**

## 2 · 每一期最值得学的一点

### 003 构成主义（最高）

- **令牌里有一条“轴”**：主轴 −30°、副轴 60°、信息 0°。所有斜的东西都用同一个函数 `P(o, d, n)` 定位，视频和图片共用。这让画面“乱中有序”：斜的是主角，平的是信息，一眼分得清。
- **把原作的方法变成公式**：海报里的字号 = 0.36 × 到嘴的距离，下一个字远 1.56 倍；字母是被“喊出来”的，不是摆上去的。
- **开场同一组元素换三次轴**（0° → −30° → 双轴），右上角的角度标签跟着跳：用 3 秒直接把“这一期最有用的一招”演示出来。
- **推镜用对数插值**（每帧放大同样的倍数），扎进瞳孔、扎进齿轮，速度均匀，不会最后几帧突然冲脸。
- 质感：旧新闻纸、印刷黑、朱红占 15%，网点照片，6% 胶片颗粒；只有实色，没有渐变和阴影。

### 004 孟菲斯

- **材料感就是动作**：所有东西都像能拿起来的塑料积木，掉下来会压扁、会回弹；压扁以底边为原点，积木“站”在地上，不会陷进地里。
- **不用半透明**：台灯光束淡入时发灰，改成从灯头按比例“长出来”。出现靠“长出来 / 弹出来”，不靠淡入。
- **颜色接力**：每次换幕是一块糖果色带着波浪边扫过来，上一章最后的颜色就是下一章的底色。
- 每个音效都和动作一一对应，音高跟着和弦走（落地的“咚”是调过音的）。

### 001 包豪斯

- **一所学校，九种样子**：九章覆盖色彩、形与色、字体、海报、建筑、家具、灯具、纺织、舞台。第一行字就是论点：「包豪斯，远不止红黄蓝。」
- **背景色轮换**（纸 / 黑 / 蓝 / 红），每次切换都有翻页感；擦除形状带 16px 黄描边，相邻两章同色时也看得出转场。
- **字体一章是教学**：参考线先出来，再用圆和竖条拼出 bauhaus，再打出 a—z。观众看到的是“怎么设计的”。

### 布局 02 瀑布流

- **全片只有 26 张卡片，从第一帧到最后一帧都是同一批**，在 13 种排法之间流动。观众看到的是“同一批内容换了一种排法”，正是瀑布流的本质：**动效本身就是内容。**
- **算法讲得懂**：每列底部一颗高度读数，最短的一列变红，虚线框标出下一张的位置；前 3 张每拍一张慢放，后 5 张每 7 帧一张连放——先教会，再加速。
- **最快的一刻落在鼓点上**：转场从拍点前 12 帧开始，卡片速度峰值正好在下一个拍点。
- **被打断也不跳**：新转场从卡片此刻真实所在的位置接着走。
- **先有容器，再倒进去**：进手机、进浏览器时裁切框先到位，卡片像倒进屏幕里。

### 005 波普

- **镜头讲道理**：从 9 倍拉远，几颗红点变成一张哭泣的脸——一个镜头讲清“网点就是颜色”。
- **工艺过程就是动作**：丝网章刮板往右刮出颜色版、往左刮出黑版，黑版错开 (12, −8)，“对不准”就是手感。
- **尺度反差**：地板汉堡旁边站一个 1.7 米的人和两把尺子。
- 汤罐翻面 = 横向缩放 `|cos|`，翻到侧面那一刻换配色。

## 3 · 013 / 014 为什么只算“正常”（我的判断）

主人没有逐条说原因，下面是对照上面那副骨架看出来的差距，供参考：

- **013 装饰艺术**：技术不差（真纵深、沿线跑的光、首尾无缝），但内容是**母题**（拱门、万花筒、天际线），不是**作品**；没有一章一个领域的广度，观众学到的是“金线 + 对称”，不是装饰艺术做过什么。一镜到底也就没有了“每章一秒看懂”的停顿。
- **014 液态玻璃**：主角是材料效果（折射、焦散、涟漪），没有“代表作”可以搭；时代只是几个年份。它留下的是流程和工具。
- 欧普没有入库，不做判断。

**结论：** 标杆的核心不是哪一种动效，而是**“真实代表作 + 一块块搭出来 + 风格自己的签名物理 + 元素接力”**这个组合。动效再好，主角如果只是抽象母题或材料，也只能算“正常”。

## 4 · 怎么超过它们（不被限制）

骨架保留（真实代表作、一章一个领域、搭出来、接力、规则卡、首尾呼应、四步改造图），在三个方向上超过：

1. **动作的物理更讲究**：标杆的动作多是“A → B + 弹簧”。按 [`DESIGN_NOTES.md`](DESIGN_NOTES.md) 的“动效做到顶尖的检查表”加上起势、过冲、附属元素晚几帧跟上、慢—慢—啪的节奏反差、镜头自己在动。
2. **让设计师在画面上看到参数**：003 的角度标签、L02 的高度读数和代码是最好的例子。新一期的关键动作旁边，直接标出数值（角度、比例、色值、网格）。
3. **落到今天的界面**：标杆的“今天”一章都只有 1.5 秒。可以把 App / 网页那一章做得更完整，并和四步改造图互相呼应。
