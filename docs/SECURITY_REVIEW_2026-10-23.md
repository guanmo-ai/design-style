# 安全修复与对抗复审记录

基线：`540b416`。修复范围是 PostCSS 本地文件读取、浏览器 ZIP 越界写入、本地预览空文件崩溃。

## 修复结果

1. 所有 Remotion 包统一为 4.0.538；根锁文件实际解析 PostCSS 8.5.31、ws 8.21.0，移除 extract-zip。根与画廊依赖审计均为 0 项已知漏洞。
2. 对抗复测发现，新版 renderer 自带解压器仍能写穿符号链接，不能仅根据移除 extract-zip 或 audit 为零认定修复。项目补丁同时覆盖 CommonJS / ESM，检查目标、真实祖先与按真实父目录解析的链接目标，并以独占创建方式写文件。
3. 空文件直接返回长度为 0 的响应；错误处理在响应头已发送时销毁连接，避免重复写响应头导致进程退出。

补丁安装方式及升级边界见 [安全维护说明](SECURITY.md)。

## 失败到通过的证据

- 原预览代码在 `GET /empty.txt` 后出现未捕获的 `ERR_HTTP_HEADERS_SENT`；回归用例失败。修复后 GET、HEAD、Range 和后续正常请求全部通过。
- 未补丁的 4.0.538 解压器在恶意 ZIP 测试中改写临时目录外侧的标记文件，且会在拒绝路径前创建外部目录；回归用例失败。补丁后均被拒绝，标记文件不变，外部目录不产生。
- 复审进一步构造目录别名改变相对链接层级的用例，捕获第一版补丁的遗漏。改为使用真实父目录后，该用例通过。
- 正常文件、可执行权限、目录内相对链接和安全的向前引用均保留。

所有攻击输入都只针对一次性 localhost 服务或本次创建的临时标记文件；没有访问个人文件或攻击真实线上目标。
