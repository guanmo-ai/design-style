## 1 · 选题与定调

**为什么做它：** 布局 01 用面积排主次，布局 02 用最短列往下淌。卡片层叠是第三种：用**前后**说“现在只处理这一张”。它也是普通人每天会碰到的：iOS 底部弹层、支付详情、待办队列。

**定调：**

- 一句话：*3–4 张圆角卡片叠在一起，同一时刻只有最上面那张在被读。*
- 气质：iOS sheet / Stripe dashboard，干净高级，不是特效堆砌。
- 受众：设计师拿去就能用（张数、抬起、旋转、压暗、CSS）；普通人看完能说出“原来底部弹层是一叠卡片”。

## 2 · 研究

1. **名字：** card stack = 一叠卡片。中文“层叠”说的是前后，不是左右。
2. **时间线：** 扑克/名片 → 2012 Tinder → 2013 iOS 7 的层 → Wallet → 2020s 的 sheet / 抽屉 / 队列。
3. **规则：** 3–4 张 / 一张焦点 / 轻抬 / 微旋 / 后层压暗。
4. **广度：** 定义、焦点、换页、iOS、Stripe、规则、误区 → 视频 7 段。
5. **误区：** 叠太多、没有焦点、当 PPT 字卡、和标签页/走马灯/便当盒用混。

## 3 · 设计令牌

- **颜色：** 纸 `#F4F5F7`，卡片 `#FFFFFF`，墨 `#0F172A` / `#64748B`，蓝 `#2563EB` 只给焦点和标注。
- **字体：** Inter Display + Inter + Noto Sans SC + Geist Mono。全部 OFL。
- **层叠：** 760×428，圆角 28，抬起 14，旋转 −1.2°，每层向左上露出 24 / 38px，暗 11%。
- **节拍：** 120 BPM，1 拍 = 30 帧，全片 18 秒 = 1080 帧。
- **缓动：** 进场 / 递补用 `SMOOTH` 弹簧；离开用 `bezier(0.22, 1, 0.36, 1)`。

## 4 · 动效设计

**核心想法：全片只有 4 张卡片。** 它们换的是槽位和皮，不是“下一页换一批”。

![动效分解](process/02-motion.jpg)

1. **弹进**（0–1s）：从下方、更远的 Z 弹进槽位，错开 8 帧。
2. **抬起**（2s）：只有槽位 0 获得 lift / 微旋，后层按层压暗，露出左上角。
3. **换页**（4.0s、5.5s）：顶卡沿弧线向右上离开并淡出，其余弹簧递补；离开的那张从底层淡入。
4. **换皮**（7s、8.5s）：同一叠变成 iOS grabber / Stripe 顶条，不切镜头。
5. **线框 + 测量**（10s）：五条规则逐条出现，标注打在真实几何上。
6. **误区**（13.5s）：先多出 3 张空卡，再铺平（不抬、不暗），再弹簧回到正确的 4 张。
7. **镜头：** 轻微透视 `rotateX(9.5°→8°)` + 极慢推近，全片 2.8% 胶片颗粒。

## 6 · 声音

`audio/make_music.py` 用 numpy 从零合成，**没有外部采样**：

- **编排：** F 大调，Fmaj9 → Dm9 → Bbmaj9 → Csus … 在章节拍点换和弦。
- **对位：** 四张卡进场各一声玻璃叮；两次换页 = 上滑 + 新焦点叮；规则段鼓停、低通变薄；误区一层层闷响；片尾收束。
- **响度：** ffmpeg `loudnorm` → −14 LUFS，时长 18.0 秒。

## 8 · 质检

1. `npx remotion bundle` + `scripts/stills.mjs` 导出关键帧。
2. `contact_sheet.py` 从成片抽帧做分镜。
3. `timeline_chart.py` 核对拍点。
4. `ffprobe` 核对 1920×1080 · 60fps · ≈18s · H.264。
